🔧 任务创建弹窗修复验证页面

📋 修复内容总结

  • 问题1：弹窗内容超出屏幕高度时无滚动条
  • 解决：设置maxHeight为90vh，添加overflow-y: auto
  • 问题2：下拉选项不显示
  • 解决：提高下拉框z-index到1050，高于Modal的550

🎯 桌面端测试清单

  • 打开任务创建弹窗（点击"创建任务"按钮）
  • 检查弹窗高度是否限制在90vh以内
  • 当内容较多时，查看是否出现清晰的滚动条（8px宽度）
  • 点击"任务状态"下拉框，确认选项正常显示
  • 点击"优先级"下拉框，确认选项正常显示
  • 点击"截止时间"日期选择器，确认日期面板正常显示
  • 滚动弹窗内容，确认滚动流畅
  • Hover滚动条，确认颜色变深（交互反馈）

📱 移动端测试清单 (< 768px)

  • 缩小浏览器窗口到768px以下
  • 弹窗宽度自适应屏幕（calc(100vw - 16px)）
  • 弹窗最大高度限制在calc(100vh - 40px)
  • Header和Footer固定，Body可滚动
  • 所有下拉框正常显示
  • 触摸滚动流畅（iOS优化）

🔍 关键修改点

1. TaskModal组件 (TaskModal.tsx)

<Modal destroyOnClose // 关闭时销毁，避免状态残留 style={{ maxHeight: '90vh' }} // 限制最大高度 ... >

2. useUnifiedModal Hook

maxHeight: isMobile ? 'calc(100vh - 200px)' : 'calc(90vh - 180px)', overflowY: 'auto', WebkitOverflowScrolling: 'touch' // iOS优化

3. CSS滚动条样式

.ant-modal-body::-webkit-scrollbar { width: 8px !important; // 增加宽度，更易见 } .ant-modal-body::-webkit-scrollbar-thumb { background: rgba(0, 0, 0, 0.3) !important; } .ant-modal-body::-webkit-scrollbar-thumb:hover { background: rgba(0, 0, 0, 0.5) !important; // hover反馈 }

4. 下拉框z-index修复

.ant-select-dropdown, .ant-picker-dropdown { z-index: 1050 !important; // 提高到1050，高于Modal的550 }

📊 z-index层级说明

当前层级架构：

  • Modal遮罩层：549
  • Modal容器：550
  • Modal内容：551
  • Modal内下拉框（兼容）：560
  • 全局下拉框（最终方案）：1050
