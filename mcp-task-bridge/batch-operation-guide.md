# 批量父任务更改功能 - 用户操作指南

## 📍 功能位置和访问方式

### 🎯 页面入口
1. 打开浏览器，访问 `http://localhost` (或您的部署域名)
2. 登录系统
3. 导航到项目详情页面：`项目 → 选择具体项目 → 任务列表`
4. 或直接访问：`http://localhost/projects/1` (项目ID根据实际情况调整)

### 🖥️ UI位置说明
批量父任务更改功能位于**项目任务列表页面**的以下位置：
- **页面**: ProjectTaskList 组件
- **触发区域**: 任务表格上方的操作栏
- **显示条件**: 当您选择了一个或多个任务后，批量操作按钮会自动出现

## 🚀 详细操作步骤

### Step 1: 选择任务
1. **进入项目任务列表页面**
   - 在左侧导航栏点击"项目"
   - 选择要操作的项目
   - 进入项目详情页面

2. **选择要批量更改的任务**
   - 在任务列表表格中，勾选任务行前面的**复选框**
   - 可以选择多个任务（支持批量操作）
   - 选择后，表格上方会显示："已选择 X 项"

### Step 2: 启动批量操作
1. **找到批量操作按钮**
   - 选择任务后，在表格上方右侧会出现批量操作区域
   - 显示格式：`已选择 X 项` `[取消选择]` `[批量操作 ▼]`

2. **点击批量操作下拉菜单**
   - 点击"批量操作"下拉按钮
   - 选择"**更改父任务**"选项（图标：🔗）

### Step 3: 配置父任务更改
1. **打开批量更改父任务弹窗**
   - 弹窗标题：`🔗 批量更改父任务 [已选择任务数量徽章]`
   - 弹窗大小：800px 宽度，居中显示

2. **选择目标父任务**
   - **选项A**: 点击"**设为根任务**"按钮 → 将选中任务移动到项目根级别
   - **选项B**: 使用父任务选择器：
     - 在下拉选择框中搜索或选择目标父任务
     - 支持按任务标题搜索
     - 显示格式：`#任务ID 任务标题`
     - **注意**: 已选中的任务不会出现在可选父任务列表中（防止循环依赖）

3. **查看批量操作预览**
   - 选择父任务后，系统会自动生成**预览数据**
   - 预览区域显示：
     - 📋 **操作摘要**: 将要更改的任务数量和目标
     - ⚠️ **警告信息**: 如果有潜在问题会显示警告
     - ❌ **验证错误**: 如果操作不被允许会显示错误
     - 📊 **受影响任务列表**: 详细的任务信息

### Step 4: 确认并执行
1. **检查预览信息**
   - 仔细查看预览区域的信息
   - 确认操作的正确性
   - 注意警告信息（黄色提示）

2. **执行批量更改**
   - 如果预览验证通过，"**确认**"按钮会变为可点击状态
   - 点击"**确认**"按钮执行批量更改
   - 系统会显示加载状态

3. **操作完成**
   - 成功后会显示："成功更新 X 个任务的父任务"
   - 弹窗自动关闭
   - 任务列表自动刷新，显示更新后的层级结构
   - 选中状态自动清空

## ⚠️ 重要注意事项

### 🔒 系统限制和验证
1. **循环依赖检查**: 不能将父任务设置为其子任务的子任务
2. **权限验证**: 只能操作有权限的任务
3. **数据完整性**: 系统会验证所有选中任务的有效性
4. **层级深度限制**: 任务层级深度有最大限制（通常不超过4级）

### 💡 操作建议
1. **批量操作前预览**: 始终仔细查看预览信息
2. **分批处理**: 对于大量任务，建议分批进行操作
3. **备份考虑**: 重要数据建议先备份
4. **测试环境**: 复杂操作建议先在测试环境验证

### 🚨 常见问题排查
1. **看不到批量操作按钮**: 
   - 确认已选择了至少一个任务
   - 检查是否有操作权限

2. **确认按钮不可点击**: 
   - 查看预览区域的错误信息
   - 确认选择了有效的父任务
   - 检查是否存在循环依赖等问题

3. **操作失败**: 
   - 检查网络连接
   - 确认登录状态未过期
   - 查看系统错误提示信息

## 🔧 开发者调试信息

### 组件位置
- **主组件**: `/frontend/src/components/ProjectTaskList.tsx`
- **预览组件**: `/frontend/src/components/BatchOperationPreview.tsx`
- **服务层**: `/frontend/src/services/TaskService.ts`

### API端点
- **批量预览**: `POST /api/v1/projects/:id/tasks/batch/preview`
- **批量更新**: `PATCH /api/v1/projects/:id/tasks/batch`

### 状态管理
- `selectedRowKeys`: 选中的任务ID数组
- `showBatchParentModal`: 弹窗显示状态
- `batchPreviewData`: 预览数据
- `batchParentLoading`: 加载状态
