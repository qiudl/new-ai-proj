# 父子任务状态联动功能使用指南

## 📖 功能概述

父子任务状态联动功能允许在任务管理系统中建立任务的层级关系，并实现自动的状态同步。当子任务状态发生变化时，父任务状态会自动更新；当父任务状态变化时，用户可以选择是否同时更新所有子任务。

## ✨ 核心特性

### 🔄 双向状态同步
- **向上自动联动**: 子任务状态变更 → 自动更新父任务状态
- **向下询问联动**: 父任务状态变更 → 询问是否更新子任务

### 🧠 智能状态计算
- **全部完成** → 父任务自动标记为"已完成"
- **部分进行中** → 父任务自动标记为"进行中" 
- **混合状态** → 父任务智能计算最合适的状态

### 🔗 多层级支持
- 支持无限层级的任务嵌套（祖父 → 父 → 子 → 孙...）
- 状态变更可递归向上传播至所有祖先任务

## 🛠️ 操作指南

### 创建父子任务关系

#### 方法1: 通过任务创建
1. 选择一个现有任务作为父任务
2. 点击任务旁的"更多"按钮 (⋯)
3. 选择"创建子任务"
4. 填写子任务信息并保存

#### 方法2: 通过任务编辑
1. 编辑现有任务
2. 在"父任务"字段中选择要设为父级的任务
3. 保存更改

### 状态联动操作

#### 子任务 → 父任务（自动）
1. **操作**: 更改任何子任务的状态
2. **触发**: 系统自动计算父任务状态
3. **结果**: 父任务状态立即更新
4. **反馈**: 显示"状态联动更新成功 ✨"消息

#### 父任务 → 子任务（询问）
1. **操作**: 更改父任务状态
2. **触发**: 弹出确认对话框
3. **选择**: 
   - "是，同时更新子任务" - 批量更新所有子任务
   - "否，只更新父任务" - 仅更新父任务
4. **结果**: 根据选择执行相应操作

## 📋 状态计算规则

### 向上联动规则（子 → 父）

| 子任务状态组合 | 父任务结果状态 | 说明 |
|----------------|----------------|------|
| 全部为"已完成" | 已完成 | 所有工作都完成了 |
| 全部为"待办" | 待办 | 还没开始工作 |
| 全部为"已取消" | 已取消 | 整个任务组被取消 |
| 包含"进行中" | 进行中 | 有工作正在进行 |
| 混合状态 | 进行中 | 部分完成，部分待办 |

### 向下联动规则（父 → 子）

| 父任务新状态 | 子任务更新规则 |
|--------------|----------------|
| 已完成 | 所有子任务 → 已完成 |
| 已取消 | 所有子任务 → 已取消 |
| 待办 | 已完成的子任务 → 待办 |
| 进行中 | 不进行批量更新 |

## ⚠️ 注意事项

### 性能优化
- **防抖机制**: 快速连续操作会被合并处理
- **乐观更新**: UI立即反映变更，提供流畅体验
- **批量处理**: 多个子任务更新会被批量执行

### 错误处理
- **网络错误**: 提供重试选项
- **权限错误**: 显示明确的权限不足提示
- **数据错误**: 提供具体的错误说明

### 边界情况
- **循环引用**: 系统防止创建循环的父子关系
- **深层嵌套**: 支持任意层级，但建议不超过5层
- **大量子任务**: 超过50个子任务时会有性能提示

## 🔧 高级功能

### 1. 全局模式支持
在全局任务视图中，父子任务联动功能同样有效，支持跨项目的任务关系。

### 2. 批量操作
可以通过父任务一次性更新大量子任务的状态，适合项目里程碑管理。

### 3. 状态追踪
系统会记录每次状态联动的历史，可在任务时间线中查看。
