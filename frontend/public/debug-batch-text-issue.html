🐛 奇葩问题排查：批量操作文本不显示

🎯 问题现象确认

用户反馈：选择任务后有反应，但是"批量操作"这4个字就是不出现

预期：应该显示"批量操作 ⌄"按钮

实际：按钮可能存在但文本不显示

console.log('=== 基础状态检查 ==='); // 选择第一个任务 const checkbox = document.querySelector('.ant-table-selection-column .ant-checkbox-input'); if (checkbox && !checkbox.checked) { console.log('点击复选框选择任务...'); checkbox.click(); } setTimeout(() => { // 检查选择状态文本 const selectedText = Array.from(document.querySelectorAll('*')).find(el => el.textContent && el.textContent.includes('已选择') ); console.log('✅ 选择状态文本:', selectedText ? selectedText.textContent : '❌ 未找到'); // 检查取消选择按钮 const cancelButton = Array.from(document.querySelectorAll('button')).find(btn => btn.textContent && btn.textContent.includes('取消选择') ); console.log('✅ 取消选择按钮:', cancelButton ? '找到' : '❌ 未找到'); }, 1000);

console.log('=== 查找所有按钮 ==='); // 获取页面上所有按钮 const allButtons = Array.from(document.querySelectorAll('button')); console.log('页面按钮总数:', allButtons.length); // 显示每个按钮的文本内容 allButtons.forEach((btn, index) => { const text = btn.textContent.trim(); const visible = btn.offsetParent !== null; console.log(`按钮${index + 1}: "${text}" (可见: ${visible})`); // 特别关注包含"批量"或"操作"的按钮 if (text.includes('批量') || text.includes('操作')) { console.log('🎯 找到相关按钮!', btn); console.log(' - 文本:', text); console.log(' - 可见性:', visible); console.log(' - 样式:', getComputedStyle(btn)); } });

🔍 步骤D: 深度DOM树搜索

console.log('=== 深度DOM树搜索 ==='); // 递归搜索包含"批量操作"的元素 function findElementsWithText(text) { const walker = document.createTreeWalker( document.body, NodeFilter.SHOW_TEXT, null, false ); const results = []; let node; while (node = walker.nextNode()) { if (node.textContent.includes(text)) { results.push({ text: node.textContent, element: node.parentElement, visible: node.parentElement.offsetParent !== null }); } } return results; } const batchElements = findElementsWithText('批量操作'); console.log('包含"批量操作"的元素:', batchElements.length); batchElements.forEach((item, index) => { console.log(`元素${index + 1}:`); console.log(' - 文本:', item.text); console.log(' - 元素:', item.element); console.log(' - 可见:', item.visible); console.log(' - 标签名:', item.element.tagName); console.log(' - 类名:', item.element.className); });

🤔 可能的原因假设

  1. CSS样式问题：文本颜色与背景相同，或者font-size为0
  2. 字体问题：字体文件缺失导致中文字符无法显示
  3. 文本溢出：overflow:hidden 隐藏了文本
  4. z-index问题：文本被其他元素遮盖
  5. React渲染问题：组件渲染不完整
  6. Ant Design版本问题：组件库的bug
