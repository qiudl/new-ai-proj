📝 学习心得与关键发现

  • 工具差异：FigJam (白板) 使用 get_figjam，设计稿使用 get_design_context
  • 信息提取：FigJam 返回结构化 XML，包含位置、尺寸和名称信息
  • 代码生成：FigJam 不会自动生成完整 UI 代码，需要手动根据尺寸创建
  • 设计演化：从简单原型 → 添加内容 → 增强交互 → 优化样式
  • 最佳实践：对于 UI 设计转代码，应使用 Figma Design 而非 FigJam Board
  • URL 格式：/board/ (FigJam) vs /design/ (设计稿)，nodeId 需转换为 x:y 格式
