📊 预期调试结果

如果批量操作正常：
• 选择任务后应该看到"已选择 X 项"文本
• 应该出现"批量操作"按钮
• 点击批量操作按钮应该显示下拉菜单
如果批量操作异常：
• 选择任务后没有"已选择"文本 → React状态管理问题
• 有"已选择"但没有"批量操作"按钮 → 条件渲染逻辑问题
• 有按钮但点击无反应 → 事件处理问题
