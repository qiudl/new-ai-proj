🚀 增强的批量操作功能测试

📋 新增功能列表

  • 批量更新状态 - 一键将选中任务设置为待开始/进行中/已完成/已阻塞
  • 批量设置优先级 - 统一设置选中任务的优先级（低/中/高/紧急）
  • 更改父任务 - 批量修改任务的父任务归属
  • 批量删除 - 一次性删除多个选中的任务
  • 统一下拉菜单 - 所有批量操作集中在一个下拉菜单中
  • 视觉优化 - 添加下拉箭头图标，更清晰的操作提示
📍 测试入口：访问项目任务页面
🎯 打开项目1任务页面
1

选择任务

在任务列表中选择一个或多个任务，点击任务行前的复选框

2

查看批量操作

选择任务后，应看到"已选择 X 项"和"批量操作 ⌄"按钮

3

测试下拉菜单

点击"批量操作"按钮，查看下拉菜单中的所有选项

4

验证功能

尝试每个批量操作选项，确认功能正常工作

🔍 具体测试项目

测试1：批量更新状态
  1. 选择2-3个任务
  2. 点击"批量操作" → "批量更新状态"
  3. 选择新状态（如"进行中"）
  4. 确认更新，检查任务状态是否改变
测试2：批量设置优先级
  1. 选择多个任务
  2. 点击"批量操作" → "批量设置优先级"
  3. 选择优先级（如"高"）
  4. 确认设置，检查优先级列是否更新
测试3：更改父任务
  1. 选择要移动的子任务
  2. 点击"批量操作" → "更改父任务"
  3. 在弹出的对话框中选择新父任务
  4. 确认更改，检查任务层级关系
测试4：批量删除
  1. 选择一些测试任务（谨慎选择！）
  2. 点击"批量操作" → "批量删除"
  3. 确认删除操作
  4. 检查任务是否被删除
