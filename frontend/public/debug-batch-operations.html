❓ 常见问题及解决方案
问题1: 复选框点击无反应

原因：可能是rowSelection配置问题或React状态更新问题

解决：

1. 检查浏览器Console是否有JavaScript错误 2. 刷新页面重试 3. 清除浏览器缓存
问题2: 选择了任务但按钮不出现

原因：selectedRowKeys状态没有正确更新

解决：

1. 在开发者工具Console中检查: React DevTools → ProjectTaskList组件 → selectedRowKeys 2. 确认selectedRowKeys.length > 0 3. 检查CSS样式是否隐藏了按钮
问题3: 样式或布局问题

原因：CSS冲突或响应式布局问题

解决：

1. 检查浏览器窗口宽度（小屏幕可能隐藏按钮） 2. 尝试不同的浏览器 3. 检查是否有CSS样式覆盖
