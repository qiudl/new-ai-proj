## 🔧 如果遇到问题

### 常见问题解决

#### 1. Google 认证失败
```bash
# 检查环境变量
echo $REACT_APP_GOOGLE_CLIENT_ID
echo $REACT_APP_GOOGLE_API_KEY
```

**解决方案**：
- 确认 `.env` 文件配置正确
- 检查 Google Cloud Console 中的域名授权
- 使用配置检查器进行诊断

#### 2. API 调用失败
**可能原因**：
- Google API 配额限制
- 网络连接问题
- API 权限不足

**解决方案**：
- 检查 Google Cloud Console 的 API 使用情况
- 确认已启用 Google Docs API 和 Google Drive API
- 检查浏览器开发者工具的网络请求

#### 3. 功能异常
**调试步骤**：
1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签页的错误信息
3. 在 Network 标签页查看 API 请求状态
4. 使用系统内置的配置检查器

### 获取帮助

如果问题持续存在：

1. **使用配置检查器**：
   - 点击 **"Google API 配置检查"** 按钮
   - 运行完整的诊断测试
   - 查看详细的错误信息和修复建议

2. **查看详细文档**：
   - [Google API 设置指南](./GOOGLE_API_SETUP.md)
   - [使用示例](./USAGE_EXAMPLES.md)

3. **调试模式**：
   ```bash
   # 在 .env 文件中启用调试
   REACT_APP_DEBUG_MODE=true
   REACT_APP_LOG_LEVEL=debug
   ```
