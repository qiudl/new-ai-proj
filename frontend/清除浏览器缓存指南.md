# 生产环境部署 - 清除浏览器缓存指南

## 问题说明

部署了新的前端版本后，浏览器可能会继续使用旧的缓存文件，导致：
1. API请求仍然发送到 `localhost:8080` 而不是 `https://proj.joylodging.com`
2. 显示错误的环境标识（同时显示开发环境和生产环境）

## 解决方案

### 方法1：硬刷新（推荐，最简单）

#### Chrome / Edge / Firefox (Windows/Linux)
```
Ctrl + Shift + R
```
或
```
Ctrl + F5
```

#### Chrome / Edge / Firefox (macOS)
```
Command + Shift + R
```
或
```
Command + Option + R
```

#### Safari (macOS)
```
Command + Option + E  (清空缓存)
然后
Command + R  (刷新页面)
```

---

### 方法2：手动清除缓存（更彻底）

#### Chrome / Edge
1. 打开开发者工具 (`F12` 或 `Command+Option+I`)
2. 右键点击地址栏的刷新按钮
3. 选择 "**清空缓存并硬性重新加载**"

或者：
1. 打开设置 → 隐私和安全 → 清除浏览数据
2. 选择"**时间范围: 全部**"
3. 勾选"**缓存的图片和文件**"
4. 点击"**清除数据**"

#### Firefox
1. 打开历史记录 → 清除最近的历史记录
2. 选择"**时间范围: 全部**"
3. 勾选"**缓存**"
4. 点击"**立即清除**"

#### Safari
1. 开发 → 清空缓存
2. 或 Safari → 清除历史记录 → 选择"**全部历史记录**"

---

### 方法3：无痕/隐私浏览模式（测试用）

打开无痕窗口访问 https://proj.joylodging.com
- Chrome/Edge: `Ctrl+Shift+N` (Windows) 或 `Command+Shift+N` (Mac)
- Firefox: `Ctrl+Shift+P` (Windows) 或 `Command+Shift+P` (Mac)
- Safari: `Command+Shift+N`

---

## 验证修复

清除缓存后，打开浏览器开发者工具（F12）：

1. **切换到 Network 标签页**
2. **勾选 "Disable cache"** (禁用缓存)
3. **刷新页面**
4. **检查请求URL**：

### ✅ 正确的请求
```
Request URL: https://proj.joylodging.com/api/v1/daily-focus-tasks
Request URL: https://proj.joylodging.com/api/v1/user/timer/current
Request URL: https://proj.joylodging.com/api/v1/projects
```

### ❌ 错误的请求（表示缓存未清除）
```
Request URL: http://localhost:8080/api/v1/daily-focus-tasks
Request URL: http://localhost:8080/api/v1/user/timer/current
```

## 环境标识验证

清除缓存后，页面顶部应该：
- ✅ **只显示红色的"生产环境"标签**
- ❌ 不应该同时显示绿色"开发环境"和红色"生产环境"

---

## 如果问题仍然存在

如果清除缓存后问题仍然存在，可能是以下原因：

1. **Service Worker缓存**
   - Chrome: chrome://serviceworker-internals/
   - 找到 `proj.joylodging.com` 并点击 "Unregister"

2. **本地存储和Cookies**
   - 打开开发者工具 → Application → Storage
   - 点击 "Clear site data"

3. **DNS缓存**
   - Windows: `ipconfig /flushdns`
   - macOS: `sudo dscacheutil -flushcache`
   - Linux: `sudo systemd-resolve --flush-caches`
