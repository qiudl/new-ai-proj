# 任务评论系统演示指南 🎯

## 🚀 快速开始

### 前置条件
- ✅ 后端服务运行在 `http://localhost:8081`
- ✅ 前端服务运行在 `http://localhost:3000`
- ✅ 已登录系统

### 访问评论功能
1. 打开浏览器访问: `http://localhost:3000`
2. 登录系统
3. 进入任意任务详情页
4. 点击顶部标签栏的 **"评论"** 标签
5. 开始使用评论功能!

---

## 📸 功能演示

### 1. 查看评论列表

**位置**: 任务详情页 → "评论" 标签页

**功能**:
- 显示所有评论列表
- 每条评论显示:
  - 👤 用户头像和用户名
  - 📝 评论内容
  - 🕒 发布时间 (相对时间,如"2小时前")
  - 🗑️ 删除按钮 (仅自己的评论或管理员可见)

**统计信息** (顶部卡片):
```
📊 评论统计
共 5 条评论  |  3 人参与  |  最后评论: 2 小时前
```

---

### 2. 添加新评论

**位置**: 评论列表底部

**操作步骤**:
1. 在输入框中输入评论内容
2. 右下角显示字符计数: `0 / 2000`
3. 两种提交方式:
   - 点击 **"评论"** 按钮
   - 使用快捷键 **Ctrl + Enter**

**输入验证**:
- ✅ 空白内容无法提交 (按钮禁用)
- ✅ 超过 2000 字符时字符计数变红
- ✅ 提交时显示加载状态
- ✅ 成功后显示成功提示并清空输入框

**示例**:
```
┌─────────────────────────────────────────┐
│  添加评论...                             │
│                                         │
│  [在此输入评论内容]                       │
│                                         │
│                        23 / 2000        │
├─────────────────────────────────────────┤
│  [清空]           [📤 评论 (Ctrl+Enter)] │
└─────────────────────────────────────────┘
```

---

### 3. 删除评论

**权限控制**:
- ✅ 用户可以删除自己的评论
- ✅ 管理员可以删除任何评论
- ❌ 普通用户无法删除他人评论

**操作步骤**:
1. 找到要删除的评论
2. 点击右上角的 **🗑️ 删除** 按钮
3. 确认删除弹窗中点击 **"确定"**
4. 评论被删除,列表自动刷新

**确认弹窗**:
```
┌─────────────────────────────────┐
│  ⚠️  确认删除                     │
├─────────────────────────────────┤
│  确定要删除这条评论吗?             │
│  此操作不可恢复。                 │
├─────────────────────────────────┤
│       [取消]      [确定]          │
└─────────────────────────────────┘
```

---

### 4. 分页浏览

**当评论数量超过 20 条时**:
- 自动显示分页控制
- 显示当前页和总数: `显示 2 / 30 条评论`
- 点击"加载更多"按钮加载下一页

## 🐛 故障排查

### 问题 1: 评论无法提交
**症状**: 点击提交按钮无反应

**排查步骤**:
1. 检查浏览器控制台是否有错误
2. 检查 Network 面板 API 请求状态
3. 确认后端服务是否正常运行
4. 检查用户是否已登录

**解决方案**:
```bash
# 检查后端服务
curl http://localhost:8081/api/health

# 检查用户登录状态
# 在浏览器控制台执行
localStorage.getItem('token')
```

### 问题 2: 评论列表不显示
**症状**: 评论标签页空白

**排查步骤**:
1. 检查 Network 面板 API 请求
2. 查看浏览器控制台错误信息
3. 确认任务 ID 是否正确

**解决方案**:
```bash
# 直接调用 API 测试
curl -H "Authorization: Bearer YOUR_TOKEN" \
  http://localhost:8081/api/tasks/1/comments
```

### 问题 3: 无法删除评论
**症状**: 删除按钮不显示或点击无效

**排查步骤**:
1. 检查评论的 `can_delete` 字段
2. 确认当前用户是否是评论作者
3. 检查用户是否有管理员权限

**解决方案**:
- 确保后端正确返回 `can_delete` 字段
- 检查权限配置
