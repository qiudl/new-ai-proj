## 用户交互流程

### 展开文档
1. 用户点击表格某行的 📄 按钮
2. 该行的 📄 按钮变为蓝色高亮
3. 表格下方展开蓝色边框的文档预览卡片
4. 加载并显示该任务的文档内容

### 切换文档
1. 用户点击另一行的 📄 按钮
2. 上一行的 📄 按钮恢复默认样式
3. 新点击行的 📄 按钮变为蓝色高亮
4. 预览区域切换显示新任务的文档

### 关闭预览
1. 用户再次点击高亮的 📄 按钮，或
2. 用户点击预览卡片右上角的"✕ 关闭"按钮
3. 📄 按钮恢复默认样式
4. 预览区域消失

## 样式特点

- 预览卡片:
  - 边框: 2px solid #1890ff (蓝色)
  - 圆角: 8px
  - 上边距: 16px
  - 标题: 📄 任务文档预览

- 文档区域:
  - 高度: 600px
  - 支持滚动
  - 显示工具栏
  - 显示文档列表
  - 默认预览模式
