## 🎯 任务目标

将任务详情页右侧的文档管理组件从"显示完整文档内容"的设计，重构为"显示版本更新记录摘要"的时间线界面，提供更好的版本管理和历史追溯能力。

### 原设计问题
- 右侧面板显示完整文档内容，占用大量空间
- 缺少版本历史可视化
- 无法快速查看文档变更历史
- 版本对比和恢复功能不直观

### 新设计目标
- 以时间线形式展示版本历史
- 每个版本显示关键信息摘要
- 支持版本详情查看、对比、恢复
- 优化空间利用，提升用户体验
