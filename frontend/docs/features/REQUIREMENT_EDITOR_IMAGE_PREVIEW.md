# 需求管理编辑器 - 图片预览功能

## 功能概述

需求管理编辑器现在支持**强大的图片预览功能**，双击任何图片即可打开全屏预览，支持放大、缩小、旋转等多种操作。

## 🎯 核心功能

### 1. 一键预览
- **双击图片**：打开全屏预览模态框
- **悬停提示**：鼠标悬停在图片上显示"双击预览"提示
- **快速关闭**：按 ESC 键或点击关闭按钮

### 2. 图片操作

#### 缩放功能
- **放大**：点击 ➕ 按钮或按 `+` 键
- **缩小**：点击 ➖ 按钮或按 `-` 键
- **实时显示**：工具栏显示当前缩放比例（50% - 300%）
- **平滑过渡**：缩放动画流畅自然

#### 旋转功能
- **左旋转**：点击 ↶ 按钮，逆时针旋转 90°
- **右旋转**：点击 ↷ 按钮，顺时针旋转 90°
- **连续旋转**：可多次点击旋转到任意角度

#### 重置功能
- **一键重置**：点击 ↺ 按钮或按 `R` 键
- **恢复默认**：缩放和旋转同时重置到初始状态

#### 全屏功能
- **全屏切换**：点击 ⛶ 按钮或按 `F` 键
- **沉浸体验**：全屏模式下隐藏浏览器界面，专注查看图片

### 3. 键盘快捷键

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `+` / `=` | 放大 | 增加 20% 缩放比例 |
| `-` | 缩小 | 减少 20% 缩放比例 |
| `R` | 重置 | 恢复默认状态 |
| `F` | 全屏 | 切换全屏模式 |
| `ESC` | 关闭 | 退出预览 |

### 4. 视觉反馈

#### 工具栏
- **半透明背景**：黑色毛玻璃效果，不遮挡图片
- **居中悬浮**：始终显示在顶部中央
- **图标按钮**：清晰的 Ant Design 图标
- **悬停效果**：按钮悬停时放大并高亮

#### 提示信息
- **底部提示条**：显示所有可用的快捷键
- **缩放百分比**：实时显示当前缩放比例
- **鼠标提示**：悬停时显示操作提示

## 🎨 交互设计

### 双击 vs 单击
- **双击图片**：打开预览（主要操作）
- **单击图片**：选中图片（用于删除或编辑）

### 工具栏位置
- **顶部居中**：便于鼠标快速访问
- **响应式设计**：移动端自动调整大小

### 动画效果
- **打开动画**：淡入 + 轻微放大（300ms）
- **缩放动画**：平滑过渡（300ms）
- **旋转动画**：跟随缩放一起过渡

### 颜色方案
- **深色背景**：黑色背景衬托图片
- **白色图标**：高对比度，易于识别
- **蓝色高亮**：遵循 Ant Design 规范

## 🔧 技术实现

### 组件结构

```
ImageComponent.tsx (编辑器中的图片)
    ↓ 双击触发
ImagePreviewModal.tsx (预览模态框)
    ├── 工具栏 (缩放、旋转、重置、全屏)
    ├── 图片容器 (CSS Transform 实现)
    └── 提示条 (快捷键说明)
```

### 核心技术

**CSS Transform**：
```css
transform: scale(${scale}) rotate(${rotate}deg);
transition: transform 0.3s ease;
```

**事件监听**：
```tsx
// 双击检测
if (event.detail === 2) {
  setPreviewVisible(true);
}

// 键盘快捷键
window.addEventListener('keydown', handleKeyDown);
```

**状态管理**：
```tsx
const [scale, setScale] = useState(1);        // 缩放比例
const [rotate, setRotate] = useState(0);      // 旋转角度
const [isFullscreen, setIsFullscreen] = useState(false); // 全屏状态
```

## 🐛 已知限制

1. **缩放范围**：限制在 50% - 300%，防止过度缩放
2. **移动端触摸**：不支持双指缩放（使用按钮操作）
3. **图片质量**：放大超过 200% 可能出现模糊（取决于原图分辨率）
