# 需求管理编辑器 - 图片粘贴功能

## 功能概述

需求管理编辑器现在支持**直接粘贴图片**功能，无需通过上传按钮，极大提升了编辑体验。

## 支持的粘贴方式

### 1. 截图工具粘贴
支持所有主流截图工具的直接粘贴：
- **Snipaste**：截图后直接 `Ctrl+V` / `Cmd+V`
- **QQ截图**：`Ctrl+Alt+A` 截图后粘贴
- **微信截图**：`Alt+A` 截图后粘贴
- **Windows截图工具**：`Win+Shift+S` 截图后粘贴
- **macOS截图**：`Cmd+Shift+4` 截图后粘贴

### 2. 从其他网页复制图片
- 在任何网页上右键点击图片 → 复制图片
- 在需求编辑器中 `Ctrl+V` / `Cmd+V` 粘贴

### 3. 从本地文件管理器复制
- 在文件管理器中复制图片文件
- 在编辑器中粘贴

## 技术特性

### 自动上传 / 本地预览
- **优先上传**：如果配置了图片上传服务，自动上传到服务器
- **降级预览**：上传失败或未配置时，自动转为 Base64 本地预览
- **无感切换**：用户无需关心背后的实现，体验一致

### 文件验证
- **类型检查**：仅支持常见图片格式（PNG、JPEG、GIF、WebP、SVG）
- **大小限制**：默认最大 10MB，可配置
- **友好提示**：验证失败时给出清晰的错误提示

### 性能优化
- **异步处理**：不阻塞编辑器操作
- **进度提示**：显示"正在处理粘贴的图片..."加载状态
- **内存管理**：处理完成后及时释放资源

## 使用示例

### 场景 1：产品需求截图
1. 在设计稿/原型图上截图（Snipaste）
2. 切换到需求编辑器
3. `Ctrl+V` 粘贴
4. ✅ 图片自动插入到光标位置

### 场景 2：复制参考图片
1. 在竞品网站上右键复制图片
2. 切换到需求编辑器
3. `Ctrl+V` 粘贴
4. ✅ 图片自动插入

### 场景 3：批量插入图片
1. 截图或复制第一张图片 → 粘贴
2. 截图或复制第二张图片 → 粘贴
3. 继续重复...
4. ✅ 快速构建图文并茂的需求文档

## 实现细节

### 核心插件：PasteImagePlugin

位置：`frontend/src/components/LexicalEditor/plugins/PasteImagePlugin.tsx`

**工作流程：**
```
用户粘贴 (Ctrl+V)
    ↓
检测剪贴板内容
    ↓
发现图片文件？
    ↓ 是
验证类型和大小
    ↓ 通过
尝试上传到服务器
    ↓
上传成功？→ 是 → 使用服务器URL
    ↓ 否
降级为Base64本地预览
    ↓
插入图片节点到编辑器
    ↓
完成
```

### 集成方式

在 `LexicalEditor.tsx` 中自动启用：

```tsx
<PasteImagePlugin onUpload={onUploadImage} />
```

### 配置参数

```tsx
interface PasteImagePluginProps {
  onUpload?: (file: File) => Promise<string>;  // 上传函数
  maxSize?: number;                             // 最大10MB
  acceptTypes?: string[];                       // 支持的图片类型
}
```

## 常见问题

### Q: 粘贴后看到"本地预览模式"提示是什么意思？
A: 说明图片暂时存储为 Base64 格式（未上传到服务器）。这通常发生在：
- 未配置图片上传服务
- 服务器暂时不可用
- 网络连接问题

### Q: 为什么有的图片粘贴不了？
A: 可能的原因：
1. 文件格式不支持（只支持常见图片格式）
2. 文件过大（超过10MB限制）
3. 剪贴板内容不是图片

### Q: 粘贴的图片会自动保存吗？
A: 是的。粘贴后的图片会：
1. 立即显示在编辑器中
2. 在你保存需求时一起保存
3. 如果配置了自动保存，会自动保存到草稿

### Q: 可以粘贴 GIF 动图吗？
A: 可以！支持所有常见图片格式，包括 GIF、PNG、JPEG、WebP、SVG。
