# 需求管理编辑器 - 完整功能指南

## 📖 概述

需求管理编辑器是基于 Lexical 富文本编辑器构建的强大文档编辑工具，专为产品需求管理场景优化，提供了完整的图片处理能力。

---

## 🎯 核心功能总览

### 1. 基础编辑功能
- ✅ 富文本编辑（粗体、斜体、下划线等）
- ✅ 标题层级（H1-H6）
- ✅ 有序/无序列表
- ✅ 引用块
- ✅ 超链接
- ✅ 代码块
- ✅ 撤销/重做

### 2. 图片功能（新增）

#### 📤 图片上传
- **按钮上传**：点击工具栏的图片按钮
- **拖拽上传**：直接拖拽图片到编辑器
- **自动优化**：支持服务器上传或本地预览

#### 📋 图片粘贴 ⭐
- **截图工具**：Snipaste、QQ截图等直接粘贴
- **网页图片**：右键复制后粘贴
- **文件复制**：从文件管理器复制后粘贴
- **快捷键**：`Ctrl+V` / `Cmd+V`

#### 🔍 图片预览 ⭐⭐
- **双击预览**：双击任何图片打开全屏预览
- **放大缩小**：支持 50% - 300% 缩放
- **旋转功能**：左右旋转 90°
- **全屏模式**：沉浸式查看体验
- **键盘操作**：完整的快捷键支持

## 🔧 技术规格

### 支持的图片格式

| 格式 | 支持 | 说明 |
|------|------|------|
| PNG | ✅ | 推荐，支持透明 |
| JPEG/JPG | ✅ | 照片格式 |
| GIF | ✅ | 支持动图 |
| WebP | ✅ | 现代格式 |
| SVG | ✅ | 矢量图 |
| BMP | ❌ | 不推荐 |

### 大小限制

- **单张图片**：最大 10MB
- **建议大小**：< 2MB（最佳性能）
- **超出处理**：自动提示错误

### 存储方式

| 模式 | 条件 | 优缺点 |
|------|------|--------|
| **服务器存储** | 配置了上传接口 | ✅ 节省流量<br>✅ 跨设备访问 |
| **Base64 本地** | 上传失败或未配置 | ✅ 即时可用<br>❌ 增大文档体积 |

## 🐛 常见问题

### Q1：粘贴图片没反应？
**A**：检查剪贴板中是否有图片数据，尝试重新复制。

### Q2：图片显示"本地预览模式"？
**A**：说明图片以 Base64 存储，功能正常，保存时会一起保存。

### Q3：双击图片无法预览？
**A**：确保不是在选中状态，先点击空白处取消选中，再双击。

### Q4：预览时图片模糊？
**A**：放大倍数过大或原图分辨率低，建议使用更高质量的图片。

### Q5：能否批量删除图片？
**A**：目前需要逐个选中删除（单击选中，按 Delete 键）。
