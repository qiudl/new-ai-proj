## 🎯 问题背景

### 原因
在前端服务统一化项目（Phase 10-11）中，删除了以下组件：
- `SimpleTaskDocumentViewer.tsx` (308行) - 已删除
- `TaskDocumentFileEditor.tsx` (469行) - 已删除

这两个组件的删除导致任务详情页失去了文档编辑查看能力。

### 影响
用户无法：
1. 直接编辑任务主文档内容

5. 访问版本历史功能

## ✅ 解决方案

### 方案选择
**方案A**: 使用UnifiedTaskDocumentArea替换TaskDocumentWidget

**选择理由**:
- 功能最完整（2,403行，包含编辑/预览/管理/统计4种模式）
- 已验证的实现（在TaskDetailPageRefactored.tsx中使用）
- 开发时间最短（预计2小时，实际40分钟）
- 风险最低（使用现有组件，无需开发）
- ROI最高（一次性恢复所有功能）

### 技术实现

**文件**: `src/pages/TaskDetail/components/Content/TaskDetailContent.tsx`

**修改内容**:

1. **导入语句修改** (Line 57-60):
```tsx
// Before
import TaskDocumentWidget from '../../../../components/TaskDocumentWidget';

// After
import UnifiedTaskDocumentArea from '../../../../components/UnifiedTaskDocumentArea';
```

**关键修复**: 使用default export而非named export（这是TypeScript编译错误的根源）

2. **组件替换** (Line 354-379):
```tsx
// Before: TaskDocumentWidget (功能受限)
<TaskDocumentWidget
  taskId={task.id}
  projectId={projectId}
  compact={false}
  showTitle={false}
/>

// After: UnifiedTaskDocumentArea (功能完整)
<UnifiedTaskDocumentArea
  projectId={projectId}
  taskId={task.id}
  defaultViewMode="edit"      // 默认编辑模式
  showToolbar={true}           // 显示工具栏
  showDocumentList={true}      // 显示文档列表
  compactMode={false}          // 完整功能
  headerVisible={false}        // 隐藏头部（Tab已有）
  onDocumentChange={(docs) => {
    onDocsChange?.();
  }}
  onViewModeChange={(mode) => {
    console.log('[TaskDetailContent] View mode changed to:', mode);
  }}
/>
```

**配置说明**:
- 8个Props参数精确配置
- 2个回调函数用于状态跟踪
- 默认进入编辑模式（edit）符合用户习惯
- 完整功能模式（compactMode=false）

## 🐛 遇到的问题与解决

### 问题1: TypeScript导入错误 (CRITICAL)

**错误信息**:
```
error TS2724: '"../../../../components/UnifiedTaskDocumentArea"' has no exported member named 'UnifiedTaskDocumentArea'
```

**根本原因**:
- 初次使用了named export语法: `import { UnifiedTaskDocumentArea }`
- 但UnifiedTaskDocumentArea使用的是default export

**解决方案**:
1. 检查UnifiedTaskDocumentArea.tsx的导出方式
2. 确认Line 2403使用`export default`
3. 修改导入为: `import UnifiedTaskDocumentArea from ...`
4. 重新运行type-check确认修复

**影响**: 🔴 高（阻塞编译）
**解决时间**: ~5分钟
**状态**: ✅ 已解决
