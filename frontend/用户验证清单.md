# 生产环境修复 - 用户验证清单

## 🎯 您需要做什么

修复已完成并部署到生产服务器。**您只需要清除浏览器缓存即可看到修复效果。**

---

## ✅ 验证步骤（5分钟）

### Step 1: 清除浏览器缓存 🔄

选择您的浏览器和操作系统:

**Chrome/Edge (Windows)**:
- 按 `Ctrl + Shift + R`

**Chrome/Edge (macOS)**:
- 按 `Cmd + Shift + R`

**Firefox (Windows)**:
- 按 `Ctrl + Shift + R`

**Firefox (macOS)**:
- 按 `Cmd + Shift + R`

**Safari (macOS)**:
- 按 `Cmd + Option + R`

### Step 2: 打开开发者工具 🔧

- 按 `F12` 键
- 或右键点击页面 → 选择"检查"

### Step 3: 检查网络请求 🌐

1. 在开发者工具中，点击 **Network** (网络) 标签页
2. 刷新页面 (`F5` 或点击刷新按钮)
3. 在网络请求列表中查找任意API请求

**✅ 正确示例（应该看到这样的URL）**:
```
https://proj.joylodging.com/api/v1/daily-focus-tasks
https://proj.joylodging.com/api/v1/user/timer/current
https://proj.joylodging.com/api/v1/tasks
```

**❌ 错误示例（不应该看到这样的URL）**:
```
http://localhost:8080/api/v1/...
```

### Step 4: 检查环境标识 🏷️

查看页面**右上角**用户头像左侧:

- **✅ 应该看到**: 仅一个红色的 **"生产环境"** 标签
- **❌ 不应该看到**: 橙色的 **"开发环境"** 标签

---

## 🐛 如果问题仍然存在

### 选项1: 手动清除所有缓存

1. **Chrome/Edge**:
   - 点击右上角三个点 → 设置 → 隐私和安全 → 清除浏览数据
   - 选择"缓存的图片和文件"
   - 点击"清除数据"

2. **Firefox**:
   - 菜单 → 设置 → 隐私与安全 → Cookies和网站数据
   - 点击"清除数据"
   - 选择"缓存的Web内容"

3. **Safari**:
   - 菜单 → 设置 → 高级 → 显示"开发"菜单
   - 开发 → 清空缓存

### 选项2: 使用隐私/无痕模式测试

- **Chrome/Edge**: `Ctrl + Shift + N` (Windows) 或 `Cmd + Shift + N` (macOS)
- **Firefox**: `Ctrl + Shift + P` (Windows) 或 `Cmd + Shift + P` (macOS)
- **Safari**: `Cmd + Shift + N`

在隐私模式下访问 `https://proj.joylodging.com`，检查是否正常。

### 选项3: 清除Service Worker

1. 在浏览器地址栏输入:
   - **Chrome**: `chrome://serviceworker-internals/`
   - **Edge**: `edge://serviceworker-internals/`
   - **Firefox**: `about:serviceworkers`

2. 找到 `proj.joylodging.com` 相关的Service Worker

3. 点击 **Unregister** (注销)

4. 刷新页面
