🔍 任务文档全屏预览功能测试

🎯 测试目标

验证任务文档点击全屏后，默认切换到markdown预览模式。

预期行为：

  • 点击全屏按钮 → 进入全屏模式
  • 如果文档是markdown类型 → 自动切换到预览模式
  • 预览模式 → 显示渲染后的markdown内容
  • 全屏布局 → 居中显示，优化阅读体验

🔧 功能实现

✅ 完成

已实现以下功能：

1. 全屏按钮集成

// 在工具栏菜单中添加全屏按钮 { key: 'fullscreen', label: isFullscreen ? '退出全屏' : '全屏查看', icon: isFullscreen ? <ShrinkOutlined /> : <ArrowsAltOutlined />, onClick: toggleFullscreen }

2. 切换全屏逻辑

const toggleFullscreen = useCallback(() => { const newFullscreenState = !isFullscreen; setIsFullscreen(newFullscreenState); // 全屏模式下默认切换到预览模式 if (newFullscreenState && selectedDocument && selectedDocument.type === 'markdown') { setViewMode('preview'); onViewModeChange?.('preview'); } }, [isFullscreen, selectedDocument, onViewModeChange]);

3. 增强预览渲染

// 支持markdown基本语法渲染 - 标题 (# ## ###) - 粗体 (**text**) - 斜体 (*text*) - 代码块 (```code```) - 行内代码 (`code`) - 链接 ([text](url)) - 列表 (- item) - 分割线 (---)

4. 全屏样式优化

// 全屏模式特殊样式 - 居中布局，最大宽度900px - 增大字体至16px，行高1.8 - 增加内边距和圆角 - 添加文档元信息显示 - ESC键退出提示

✅ 验收标准

功能实现应满足以下要求：

  • ✅ 全屏按钮可以找到并点击
  • ✅ 点击全屏后成功进入全屏模式
  • ✅ Markdown文档自动切换到预览模式
  • ✅ Markdown语法正确渲染（标题、粗体、代码等）
  • ✅ 全屏布局美观，内容居中显示
  • ✅ 显示文档元信息（类型、日期、字符数）
  • ✅ ESC键可以退出全屏
  • ✅ 退出全屏后回到正常视图

🐛 已知问题

当前版本可能存在的问题：

  • 复杂markdown语法可能渲染不完整（如表格、图片等）
  • 某些CSS样式可能与全屏模式冲突
  • 非Markdown文档的全屏体验待优化
