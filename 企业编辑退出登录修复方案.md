## 企业详情页编辑退出登录问题修复方案

### 🔍 问题诊断结果

经过系统分析，发现了以下关键问题：

1. **PrivateRoute组件问题**: 只检查token存在性，未验证有效性
2. **API拦截器问题**: 使用`window.location.href`强制跳转，可能干扰React路由
3. **后端服务端口不匹配**: 前端期望3001端口，后端运行在8080端口

### 🛠️ 修复步骤

#### 第一步：修复PrivateRoute组件

创建增强版的PrivateRoute组件，支持token有效性验证：

```typescript
// frontend/src/components/PrivateRoute.tsx
import React from 'react';
import { Navigate } from 'react-router-dom';

interface PrivateRouteProps {
  children: React.ReactNode;
}

const isTokenValid = (token: string): boolean => {
  try {
    const parts = token.split('.');
    if (parts.length !== 3) return false;
    
    const payload = JSON.parse(atob(parts[1]));
    const now = Date.now() / 1000;
    
    // 检查是否过期
    if (payload.exp && payload.exp < now) {
      return false;
    }
    
    return true;
  } catch (error) {
    return false;
  }
};

const PrivateRoute: React.FC<PrivateRouteProps> = ({ children }) => {
  const token = localStorage.getItem('token');
  
  if (!token || !isTokenValid(token)) {
    // 清除无效token
    localStorage.removeItem('token');
    return <Navigate to="/login" replace />;
  }
  
  return <>{children}</>;
};

export default PrivateRoute;
```

#### 第二步：修复API拦截器

更新API拦截器，使用React Router导航：

```typescript
// frontend/src/services/api.ts (替换401处理部分)

// 在文件顶部添加
let navigateFunction: ((path: string) => void) | null = null;

// 提供设置导航函数的方法
export const setNavigateFunction = (navigate: (path: string) => void) => {
  navigateFunction = navigate;
};

// 在401错误处理中修改为：
case 401:
  appError = new AppError(
    '认证失败，请重新登录',
    ErrorType.AUTHENTICATION,
    401
  );
  // 清除认证数据
  localStorage.removeItem('token');
  
  // 使用React Router导航，避免强制页面跳转
  if (navigateFunction) {
    setTimeout(() => navigateFunction('/login'), 100);
  } else {
    // 备用方案：仍使用window.location，但延迟执行
    setTimeout(() => {
      if (window.location.pathname !== '/login') {
        window.location.href = '/login';
      }
    }, 1000);
  }
  break;
```

#### 第三步：在App.tsx中设置导航函数

```typescript

function App() {
```

#### 第五步：增强CompanyEditPage错误处理

```typescript
// frontend/src/pages/CompanyEditPage.tsx (loadCompany函数修改)
const loadCompany = async () => {
  if (!companyId || companyId <= 0) {
    message.error('无效的企业 ID');
    navigate('/companies');
    return;
  }

  try {
    setLoading(true);
    const companyData = await companyService.getCompany(companyId);
    setCompany(companyData);
  } catch (error) {
    console.error('加载企业信息失败:', error);
    
    // 检查是否是认证错误
    if (error instanceof AppError && error.type === ErrorType.AUTHENTICATION) {
      // 认证错误由API拦截器处理，不需要手动跳转
      console.log('认证失败，API拦截器将处理跳转');
      return;
    }
    
    // 其他错误的处理
    if (error instanceof AppError) {
      message.error(`加载失败: ${error.message}`);
    } else if (error instanceof Error) {
      message.error(`加载失败: ${error.message}`);
    } else {
      message.error('加载企业信息失败');
    }
    navigate('/companies');
  } finally {
    setLoading(false);
  }
};
```
