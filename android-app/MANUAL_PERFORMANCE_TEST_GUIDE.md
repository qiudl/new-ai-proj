# AI功能手动性能测试指南

## 概述

本指南用于手动执行AI功能性能测试，测量响应时间和内存使用情况。

## 测试环境准备

### 1. 设备要求
- Android设备或模拟器（Android 8.0+）
- 确保设备已启用USB调试
- 连接到测试服务器网络

### 2. 工具安装
```bash
# 安装adb命令行工具
# macOS (使用Homebrew)
brew install android-platform-tools

# 验证adb连接
adb devices
```

### 3. 应用安装
```bash
# 构建并安装Debug版本
cd /Users/johnqiu/coding/www/projects/new-ai-proj/android-app
./gradlew installDebug
```

## 测试执行步骤

### 测试1: AI Description生成性能

#### 1.1 短描述性能测试
**目标**: < 3秒

**步骤**:
1. 打开应用，登录账号
2. 进入任意任务详情页
3. 点击"AI生成描述"按钮
4. 选择"短描述"选项
5. 点击"开始生成"
6. **开始计时** (从点击到显示结果)
7. 记录响应时间

**预期结果**: 响应时间 < 3秒

#### 1.2 中等描述性能测试
**目标**: < 5秒

**步骤**: 同上，选择"中等描述"

**预期结果**: 响应时间 < 5秒

#### 1.3 长描述性能测试
**目标**: < 8秒

**步骤**: 同上，选择"长描述"

**预期结果**: 响应时间 < 8秒

#### 1.4 内存监控
使用Android Studio Profiler监控内存:

1. 打开Android Studio
2. 选择 Run → Profile 'app'
3. 在Profiler中选择Memory
4. 记录生成前的内存基准
5. 执行AI描述生成
6. 记录生成后的内存峰值
7. 计算内存增长

**预期结果**: 内存增长 < 5MB

1. 生成5个子任务后
2. 点击"创建全部"
3. 记录从点击到完成的时间

- 5个子任务: < 2秒
- 10个子任务: < 4秒

#### 4.1 连续生成20次
**目标**: 内存增长 < 50MB，响应时间不变慢

**步骤**:
1. 打开Android Studio Profiler
2. 开始记录内存和CPU
3. 连续执行20次AI描述生成
4. 每次生成后记录:

   - 当前内存使用
5. 比较前10次和后10次的平均响应时间

**预期结果**:
- 总内存增长 < 50MB
- 响应时间变慢 < 20%

## 使用Android Studio Profiler

### 内存监控步骤

1. **启动Profiler**:
   - 在Android Studio中选择 View → Tool Windows → Profiler
   - 或者使用 Run → Profile 'app'

2. **记录内存基准**:
   - 点击Memory行
   - 点击"Force garbage collection"图标 (垃圾桶)
   - 记录当前内存值作为基准

3. **执行测试操作**:
   - 在应用中执行AI生成操作
   - 观察内存曲线变化

4. **记录内存峰值**:
   - 操作完成后再次点击"Force garbage collection"
   - 记录内存峰值
   - 计算内存增长 = 峰值 - 基准

5. **导出数据**:
   - 右键点击Memory timeline
   - 选择 Export → Selection as .hprof file
   - 保存堆转储文件用于分析

### CPU监控步骤

1. **启动CPU Profiler**:
   - 点击CPU行
   - 选择"Sample Java Methods"

2. **记录CPU使用**:
   - 点击Record按钮
   - 执行AI生成操作
   - 点击Stop按钮

3. **分析结果**:
   - 查看Flame Chart
   - 找出CPU热点
   - 检查是否有主线程阻塞

### 网络监控步骤

1. **启动Network Profiler**:
   - 点击Network行
   - 观察网络请求

2. **记录请求时间**:
   - 执行AI生成操作
   - 查看Request Details
   - 记录:
     - Request sent time
     - Response received time
     - Total duration

## 使用ADB命令监控

### 监控内存使用
```bash
# 实时监控内存
watch -n 1 'adb shell dumpsys meminfo com.aiproj.mobile | grep TOTAL'

# 详细内存信息
adb shell dumpsys meminfo com.aiproj.mobile

# 触发GC
adb shell am broadcast -a com.android.internal.intent.action.REQUEST_GC
```

### 监控CPU使用
```bash
# 查看应用CPU使用率
adb shell top -n 1 | grep com.aiproj.mobile
```

### 监控网络
```bash
# 查看网络流量
adb shell dumpsys netstats detail full | grep com.aiproj.mobile
```

## 优化建议

根据测试结果，如果发现性能问题，请参考以下优化方向：

### 响应时间慢
- 检查网络请求是否可以缓存
- 优化API响应数据结构
- 实现请求合并和批处理
- 添加Loading状态提示用户

### 内存泄漏
- 检查ViewModel是否正确清理
- 确保Coroutines正确取消
- 使用LeakCanary检测泄漏源
- 及时释放大对象引用

### UI卡顿
- 避免主线程阻塞
- 使用LazyColumn优化列表
- 减少重组范围
- 使用remember缓存计算结果
