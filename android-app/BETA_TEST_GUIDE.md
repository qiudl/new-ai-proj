# Beta测试者指南

欢迎成为AI Project Mobile的Beta测试者！本指南将帮助您快速上手测试。

## 📥 安装应用

### 方法1: 直接下载APK (推荐)

1. 在手机上点击您收到的APK下载链接
2. 下载完成后点击安装
3. 如果提示"未知来源"，请按照以下步骤:
   - 打开"设置" → "安全" → 启用"未知来源"
   - 或者"设置" → "应用" → "特殊访问权限" → "安装未知应用" → 允许浏览器安装

### 方法2: Android Studio安装 (开发者)

```bash
adb install -r app-debug.apk
```

### 方法3: Google Play 内测 (后续开放)

加入Google Play内测组后，在Play商店更新。

## 📖 功能导览

### 1. AI描述生成

**在哪里找到**:
- 进入任意任务详情页
- 点击"描述"区域的"✨ AI生成"按钮

**如何测试**:
1. 选择长度: 短/中/长
2. 选择风格: 技术/业务/简洁
3. (可选) 输入自定义提示词
4. 点击"开始生成"
5. 等待3-8秒
6. 查看生成的描述
7. 点击"应用"或"重新生成"

**重点测试**:
- 不同长度的描述质量
- 不同风格的区别
- 自定义提示词的效果
- 生成速度是否可接受
- 描述是否准确反映任务

### 2. AI子任务生成

**在哪里找到**:
- 任务详情页 → "子任务"标签
- 点击"✨ AI生成子任务"按钮

**如何测试**:
1. 调整子任务数量 (1-10个)
2. 选择是否包含工时预估
3. (可选) 输入自定义提示词
4. 点击"开始生成"
5. 等待5-12秒
6. 预览生成的子任务列表
7. 可以编辑标题、描述、优先级
8. 点击"创建全部"批量创建

**重点测试**:
- 子任务拆分是否合理
- 数量控制是否准确
- 工时预估是否有参考价值
- 优先级分配是否合理
- 批量创建是否流畅

### 3. AI文档生成

**在哪里找到**:
- 任务详情页 → "文档"标签
- 点击"✨ AI生成文档"按钮

**如何测试**:
1. 选择文档类型:
   - 技术设计文档
   - API文档
   - 功能需求文档
   - Bug报告
   - 测试计划
2. 选择AI模型 (gpt-4o/deepseek-chat)
3. (可选) 输入自定义需求
4. 选择生成选项:
   - 包含子任务信息
   - 包含代码示例
5. 点击"开始生成"
6. 等待10-20秒
7. 预览文档内容
8. 点击"保存文档"

**重点测试**:
- 文档内容完整性
- 格式和结构是否清晰
- 代码示例是否有用
- 不同模型的质量差异
- 保存和查看是否正常

## 🐛 如何报告Bug

### 应用内报告 (推荐)

1. 点击右上角菜单 → "帮助与反馈"
2. 选择"报告问题"
3. 填写信息:
   - 问题类型: Bug/建议/体验问题
   - 严重程度: P0/P1/P2/P3
   - 详细描述
4. (可选) 上传截图
5. 点击"提交"

### 邮件报告

发送至: bugs@aiproject.com

邮件格式:
```
主题: [Bug] 简短描述

### 问题描述
[清晰描述问题]

### 复现步骤
1. [步骤1]
2. [步骤2]
3. [步骤3]

### 预期行为
[应该发生什么]

### 实际行为
[实际发生了什么]

### 设备信息
- 设备: [型号]
- Android版本: [版本]
- App版本: [版本]

### 截图
[附加截图]
```

### Bug严重程度分级

- **P0 - 紧急**: 应用崩溃、数据丢失、无法使用
- **P1 - 严重**: 主要功能不可用、严重性能问题
- **P2 - 中等**: 次要功能bug、UI问题
- **P3 - 轻微**: 文案错误、轻微UI问题

### 常见问题

**Q: 应用闪退怎么办？**
A: 请通过应用内反馈或邮件报告，并提供崩溃日志。可以在"设置" → "高级" → "导出日志"获取。

**Q: 生成速度太慢？**
A: 这可能与网络有关。请尝试切换WiFi，或在网络良好时测试。如持续缓慢，请报告。

**Q: 生成的内容不准确？**
A: 请报告具体的任务和生成结果，我们会优化AI模型。您也可以尝试使用自定义提示词。

**Q: 我的反馈会被采纳吗？**
A: 我们认真对待每一条反馈。如果建议合理且符合产品方向，会在后续版本中实现。

**Q: 积分什么时候到账？**
A: 提交反馈和报告bug后，积分会在24小时内到账。
