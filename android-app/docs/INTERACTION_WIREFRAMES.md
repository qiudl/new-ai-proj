## 🎯 交互动作详解

### 1. 展开/收起动画时序

```
初始状态: ▶ (箭头朝右)
     ↓
用户点击
     ↓
箭头旋转动画 (90度, 300ms)
     ↓
子任务淡入 + 向下滑动 (300ms)
     ↓
父任务进度条更新 (200ms)
     ↓
结束状态: ▼ (箭头朝下)
```

**动画参数**:
```kotlin
// 箭头旋转
animateFloatAsState(
    targetValue = if (isExpanded) 90f else 0f,
    animationSpec = tween(
        durationMillis = 300,
        easing = FastOutSlowInEasing
    )
)

// 子任务展开
AnimatedVisibility(
    visible = isExpanded,
    enter = expandVertically(
        animationSpec = tween(300),
        expandFrom = Alignment.Top
    ) + fadeIn(tween(200))
)
```

### 2. 复选框状态切换

```
┌─────────────────┐
│ [○] 未完成      │  点击
│                 │   ↓
│ [⊙] 加载中...   │  200ms
│                 │   ↓
│ [●] 已完成      │  成功
│                 │
│ [⚠] 失败，重试  │  失败时显示
└─────────────────┘
```

**状态颜色**:
- `[○]` 未完成: 灰色边框
- `[⊙]` 加载中: 蓝色旋转
- `[●]` 已完成: 绿色填充
- `[⚠]` 失败: 红色警告

### 3. 长按菜单

```
用户长按任务卡片
     ↓
震动反馈 (50ms)
     ↓
卡片背景变暗

底部弹出菜单 (Sheet)

┌─────────────────────────────────────────┐
│               快捷操作                  │
├─────────────────────────────────────────┤
│  📝 编辑任务                            │
│  ➕ 添加子任务                          │

```

```kotlin
when {
    completed == 0 -> Color.Gray
    completed == total -> Color.Green
```

## 🔄 状态流转图

```
待办 (TODO)
    ↓ ↑
进行中 (IN_PROGRESS)
    ↓ ↑
已完成 (COMPLETED)

阻塞 (BLOCKED) ←→ 待办/进行中
已取消 (CANCELLED) ← 任意状态
```

**操作权限**:
- 创建者: 所有状态
- 负责人: 除"已取消"外的所有状态
- 成员: 仅能将自己的任务标记为完成

## ⚡ 性能优化策略

### 1. 虚拟滚动
```kotlin
LazyColumn {
    items(
        items = visibleTasks,  // 仅渲染可见任务
        key = { it.id }        // 稳定的key避免重组
    ) { task ->
        TaskItem(task)
    }
}
```

### 2. 懒加载子任务
```
只在展开时才加载子任务
    ↓
本地缓存已加载的子任务
    ↓
下次展开直接从缓存读取
```

### 3. 分页加载
```
初始加载: 20条任务
    ↓
滚动到底部
    ↓
自动加载下一页 (20条)
    ↓
缓存所有已加载任务
```
