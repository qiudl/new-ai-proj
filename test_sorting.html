任务列表排序功能测试

测试说明

这个测试页面用于验证任务列表的排序功能是否正常工作。

请确保：

  • 前端服务运行在 http://localhost:3001
  • 后端服务运行在 http://localhost:8081

API 排序测试

前端页面测试

请打开 http://localhost:3001/tasks 并尝试：

  1. 点击表头的 "ID" 列，检查是否可以按 ID 排序
  2. 点击表头的 "任务名称" 列，检查是否可以按标题排序
  3. 点击表头的 "状态" 列，检查是否可以按状态排序
  4. 点击表头的 "截止时间" 列，检查是否可以按截止日期排序
  5. 点击表头的 "最后更新" 列，检查是否可以按更新时间排序
  6. 点击表头的 "创建时间" 列，检查是否可以按创建时间排序

刷新页面后，排序状态应该被保存（通过 localStorage）
