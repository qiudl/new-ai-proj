原始问题描述

修复方案实施

// TaskDocumentEditor.tsx 第444行 overflow: 'auto', // 原来是 'hidden' // TaskDocumentEditor.tsx 第510行 overflow: 'auto', // 原来是 'hidden' // 新增CSS规则支持 body.fullscreen-editor-active .ant-input { overflow: auto !important; }

  • 检查全屏模式下是否出现滚动条
  • 验证可以滚动查看所有内容
