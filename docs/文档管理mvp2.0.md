交互流程
✨ 创建文档流程

点击"新建文档"
选择文档类型（影响图标和模板）
选择存放文件夹
填写文档标题
进入富文本编辑器

🔍 浏览文档流程

左侧选择文档类型筛选
左侧选择文件夹定位
主区域显示对应文档列表
点击文档进入查看/编辑


🗄️ 数据结构设计
文档数据模型
文档对象:
- id: 文档唯一标识
- title: 文档标题
- content: 富文本内容(HTML)
- type: 文档类型ID
- folder_path: 文件夹路径
- creator: 创建者
- created_at: 创建时间
- updated_at: 更新时间
- status: 状态(草稿/发布)
文件夹数据模型
文件夹对象:
- id: 文件夹唯一标识
- name: 文件夹名称
- parent_id: 父文件夹ID
- path: 完整路径
- type_scope: 允许的文档类型
- created_at: 创建时间
文档类型数据模型
类型对象:
- id: 类型唯一标识
- name: 类型名称
- icon: 图标标识
- color: 主题色
- template: 默认模板
- parent_type: 父类型(用于树形结构)
