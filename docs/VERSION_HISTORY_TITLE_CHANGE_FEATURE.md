# 版本历史标题变更功能

## 功能描述

在文档版本历史弹窗中新增了**标题变更显示**功能，当对比两个版本时，如果文档标题发生了变更，会在Diff视图的头部显示标题的变化。

## 功能特性

### 1. 自动检测标题变更

- 系统自动对比选中的两个版本的标题
- 只在标题确实发生变化时才显示标题变更区域
- 如果标题未变更，不显示额外内容

### 2. 清晰的视觉呈现

**标题变更区域包含**:
- 🟣 "标题变更" 标签（紫色）
- 🔴 旧标题（红色背景，删除线）
- 🟢 新标题（绿色背景，加粗）

**视觉设计**:
```
┌─────────────────────────────────────┐
│ [标题变更]                           │
│                                     │
│ [-] 旧标题文本（红色，删除线）        │
│ [+] 新标题文本（绿色，加粗）          │
└─────────────────────────────────────┘
```

### 3. 响应式设计

- 支持长标题自动换行
- 在移动设备上自适应调整显示
- 保持良好的可读性

## 使用场景

### 场景1：查看文档重命名历史

当文档标题被修改时，可以清楚地看到标题的变更：

```
旧标题: "测试-1761365140"
新标题: "手工测试更新 - Version 35555"
```

### 场景2：追踪文档演变

通过标题变更可以快速了解文档的演变过程：
- v1: "解决任务文档2130显示2129内容的问题 - 排查方案"
- v2: "任务描述 - 解决任务文档2130显示2129内容的问题"
- v6: "测试-1761365140"
- v10: "手工测试更新 - V10"

### 场景3：回滚前的确认

在回滚文档之前，可以通过标题变更确认是否选择了正确的版本。

## 技术实现

### 修改的文件

1. **DiffHeader.tsx** (组件逻辑)
   - 增加标题对比逻辑
   - 添加标题变更渲染区域

2. **DiffHeader.css** (样式)
   - 新增 `.title-change-section` 样式
   - 新增 `.title-old` 和 `.title-new` 样式
   - 添加响应式适配

### 核心代码

#### 标题变更检测

```typescript
// 检查标题是否发生变更
const hasTitleChange = oldVersion && newVersion && oldVersion.title !== newVersion.title;
```

#### 标题变更渲染

```tsx
{hasTitleChange && (
  <div className="title-change-section">
    <div className="title-change-label">
      <Tag color="purple" style={{ margin: 0 }}>标题变更</Tag>
    </div>
    <div className="title-change-content">
      <div className="title-old">
        <Tag color="red" style={{ marginRight: 8 }}>-</Tag>
        <span className="title-text removed-text">{oldVersion.title}</span>
      </div>
      <div className="title-new">
        <Tag color="green" style={{ marginRight: 8 }}>+</Tag>
        <span className="title-text added-text">{newVersion.title}</span>
      </div>
    </div>
  </div>
)}
```

### 样式设计

#### 旧标题样式
```css
.title-old {
  background-color: #fff1f0;  /* 浅红色背景 */
  border-left: 3px solid #ff4d4f;  /* 红色左边框 */
}

.removed-text {
  color: #cf1322;  /* 深红色文字 */
  text-decoration: line-through;  /* 删除线 */
}
```

#### 新标题样式
```css
.title-new {
  background-color: #f6ffed;  /* 浅绿色背景 */
  border-left: 3px solid #52c41a;  /* 绿色左边框 */
}

.added-text {
  color: #389e0d;  /* 深绿色文字 */
  font-weight: 500;  /* 加粗 */
}
```

## 数据流

### 1. API数据获取

```bash
GET /api/v1/projects/{projectId}/tasks/{taskId}/documents/{documentId}/versions
```

**响应数据包含标题**:
```json
{
  "versions": [
    {
      "id": 384,
      "version_number": 10,
      "title": "手工测试更新 - V10",
      "created_at": "2025-10-25T04:35:30.49274Z"
    },
    {
      "id": 383,
      "version_number": 9,
      "title": "手工测试更新 - Version 35555",
      "created_at": "2025-10-25T04:12:56.934319Z"
    }
  ]
}
```

### 2. 组件数据流

```
VersionHistoryModal
  ↓ 加载版本数据（包含title字段）
  ↓ 用户选择两个版本
  ↓ 传递给DiffViewPanel
  ↓
DiffViewPanel
  ↓ 传递给DiffHeader
  ↓
DiffHeader
  ↓ 对比oldVersion.title和newVersion.title
  ↓ 渲染标题变更区域
```
