# 企业客户页面功能说明

## 🎯 功能概述

企业客户页面已经全面升级，新增了列自定义、排序操作和视图切换等高级功能，为用户提供了更加灵活和个性化的数据管理体验。

## ✨ 主要功能

### 1. 列自定义功能

#### 📋 可配置列（共12列）
| 列名 | 默认显示 | 必需列 | 描述 |
|------|----------|--------|------|
| 企业名称 | ✅ | ✅ | 企业的名称和基本信息 |
| 行业 | ✅ | ❌ | 企业所属行业领域 |
| 联系方式 | ✅ | ❌ | 企业的联系电话和邮箱 |
| 状态 | ✅ | ❌ | 企业当前的状态 |
| 优先级 | ✅ | ❌ | 企业的优先级等级 |
| 规模 | ✅ | ❌ | 企业的规模和员工数量 |
| 地址 | ❌ | ❌ | 企业的所在地址 |
| 年度合同金额 | ✅ | ❌ | 企业年度合同金额 |
| 总合同金额 | ❌ | ❌ | 企业总合同金额 |
| 创建时间 | ✅ | ❌ | 企业在系统中的创建时间 |
| 更新时间 | ❌ | ❌ | 企业信息最后更新时间 |
| 操作 | ✅ | ✅ | 查看、编辑、删除操作 |

#### 🛠 自定义操作
- **显示/隐藏列**: 点击眼睛图标控制列的显示状态
- **拖拽排序**: 拖拽列项调整显示顺序（如果支持拖拽）
- **自动保存**: 所有设置自动保存到localStorage
- **重置功能**: 一键恢复默认配置
- **批量操作**: 全部显示/全部隐藏快捷操作

### 2. 排序功能

#### 🔄 排序操作
- **点击排序**: 点击任意列标题进行排序
- **方向切换**: 再次点击切换升序/降序
- **状态显示**: 实时显示当前排序字段和方向
- **智能排序**: 不同数据类型使用相应的排序算法

#### 📊 排序算法
- **文本字段**: 使用中文本地化排序（`localeCompare('zh-CN')`）
- **优先级**: 按等级排序（高 > 中 > 低）
- **数值字段**: 按数值大小排序
- **日期字段**: 按时间戳排序

### 3. 视图切换功能

#### 📋 列表视图
- **完整表格**: 显示所有可见列
- **列自定义**: 支持列设置功能
- **排序功能**: 支持点击列标题排序
- **紧凑布局**: 适合大量数据浏览

#### 🎴 卡片视图
- **美观展示**: 卡片式布局展示企业信息
- **响应式设计**: 不同屏幕尺寸自适应
- **完整信息**: 显示企业的详细信息
- **操作按钮**: 查看、编辑、删除操作

#### 📱 响应式布局
```
- xs (< 576px): 1列卡片
- sm (≥ 576px): 2列卡片  
- lg (≥ 992px): 3列卡片
- xl (≥ 1200px): 4列卡片
```

## 📱 用户操作指南

### 使用列自定义
1. 点击"列设置"按钮打开配置面板
2. 使用眼睛图标控制列的显示/隐藏
3. 拖拽列项调整显示顺序（如果支持）
4. 使用快捷按钮进行批量操作
5. 点击"重置默认"恢复初始配置

### 使用排序功能
1. 在列表视图下点击任意列标题
2. 再次点击切换升序/降序
3. 查看页面右上角的排序状态提示

### 切换视图模式
1. 使用视图模式切换按钮
2. 列表视图：完整表格功能
3. 卡片视图：美观卡片展示

## 🔍 搜索和筛选

- **全文搜索**: 企业名称、邮箱、电话
- **实时搜索**: 输入即时筛选
