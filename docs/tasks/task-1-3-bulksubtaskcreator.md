# 批量子任务创建功能使用指南

## 功能概述

批量子任务创建功能允许用户通过表格形式快速创建多个遵循统一命名规范的子任务，大幅提升项目管理效率。

### 核心特性

- 📊 **表格式批量输入**: 支持9个字段的完整配置
- 🏷️ **自动任务名称生成**: 按照 `{周数}周-#{父任务ID}-{序号}：标题` 格式
- ✅ **实时数据验证**: 即时错误提示和数据校验
- 🔄 **动态行管理**: 增删改查、复制、清空操作
- ⚡ **并行API调用**: 高效批量创建，支持进度显示
- 🎨 **响应式UI设计**: 支持桌面和移动端

## 快速开始

### 1. 打开批量创建界面

**方法一：通过任务列表**
1. 进入项目的任务页面
2. 找到要创建子任务的父任务
3. 点击任务行右侧的 🌿 **批量创建子任务** 按钮

**方法二：通过层级视图**
1. 切换到层级视图模式
2. 在任务操作区域点击蓝色的 🌿 图标

### 2. 填写任务信息

界面包含以下字段：

| 字段 | 必填 | 说明 | 限制 |
|------|------|------|------|
| **序号** | - | 自动生成，显示任务顺序 | 只读 |
| **任务标题** | ✅ | 输入任务的简短描述 | 1-100字符 |
| **生成名称预览** | - | 显示最终的任务名称 | 只读 |
| **任务描述** | - | 详细的任务说明 | 最多500字符 |
| **状态** | ✅ | 任务的当前状态 | 待办/进行中/已完成/已取消 |
| **优先级** | - | 任务重要程度 | 低/中/高/紧急 |
| **预计工时** | - | 完成任务需要的时间 | 0-999小时 |
| **截止日期** | - | 任务的最后期限 | 不能早于今天 |
| **负责人** | - | 任务执行者 | 最多50字符 |

### 3. 任务名称规则

系统会自动按照以下规则生成任务名称：

```
{当前周数}周-#{父任务ID}-{序号}：{您输入的标题}
```

**示例：**
- 当前是第31周，父任务ID为139
- 您输入标题"实现用户登录功能"
- 生成的任务名称：`31周-#139-01：实现用户登录功能`

## 详细操作指南

### 行操作

#### 添加新行
- 点击 **"添加任务行"** 按钮
- 支持最多50行任务
- 新行会自动填充默认值

#### 复制行
- 点击行右侧的 📋 **复制** 按钮
- 复制的行标题会自动添加"(副本)"后缀
- 其他字段值完全相同

#### 删除行
- 点击行右侧的 🗑️ **删除** 按钮
- 至少需要保留1行
- 删除操作不可撤销

#### 清空所有行
- 点击 **"清空所有"** 按钮
- 会重置为3行空白模板
- 操作前会显示确认提示

### 数据验证

系统会实时验证输入数据：

#### 必填项检查
- **任务标题**: 不能为空
- **任务状态**: 必须选择

#### 长度限制
- **任务标题**: 1-100字符
- **任务描述**: 最多500字符  
- **负责人**: 最多50字符

#### 数值验证
- **预计工时**: 0-999小时之间的数字

#### 日期验证
- **截止日期**: 不能早于今天

### 错误处理

#### 验证错误
- 错误字段会显示红色边框
- 字段下方显示具体错误信息
- 底部显示错误统计

#### 创建失败
- 显示详细的失败原因
- 支持重试失败的任务
- 保留已成功创建的任务

## 高级功能

### 进度监控

创建过程中会显示：
- 实时进度条
- 当前创建的任务编号
- 成功/失败统计

### 批量操作模式

支持两种创建模式：

#### 串行模式（推荐）
- 逐个创建任务
- 显示实时进度
- 便于错误定位

#### 并行模式
- 同时创建多个任务
- 速度更快
- 适合网络稳定环境

### 快捷键支持

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Enter` | 添加新行 |
| `Delete` | 删除当前行 |
| `Ctrl + S` | 开始批量创建 |
| `Esc` | 关闭对话框 |

## 最佳实践

### 1. 任务规划
- 在创建前先规划好任务层次结构
- 保持任务标题简洁明确
- 合理估算工时和设置截止日期

### 2. 命名规范
- 任务标题使用动宾结构（如：实现xxx功能）
- 避免使用特殊符号和emoji
- 保持团队统一的命名风格

### 3. 批量操作
- 建议每次创建不超过20个任务
- 复杂任务可分批创建
- 创建后及时检查和调整

### 4. 错误处理
- 仔细阅读验证错误信息
- 保存重要数据后再尝试修复
- 网络不稳定时避免大批量操作

## 故障排除

### 常见问题

#### Q: 任务名称预览不显示？
A: 请确保已输入任务标题，预览会实时更新。

#### Q: 创建按钮无法点击？
A: 检查是否有验证错误，必须修复所有错误才能创建。

#### Q: 部分任务创建失败？
A: 查看错误详情，通常是网络问题或权限不足，可以重试失败的任务。

#### Q: 页面加载缓慢？
A: 减少同时创建的任务数量，或检查网络连接。

### 性能优化建议

1. **合理控制数量**: 建议单次创建不超过30个任务
2. **网络环境**: 在稳定的网络环境下操作
3. **浏览器性能**: 使用现代浏览器，定期清理缓存
4. **数据准备**: 提前准备好任务信息，减少填写时间
