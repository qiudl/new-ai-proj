# 可拖拽工作台使用指南

## 功能特性

### 🎯 核心功能
- **拖拽调整布局**: 点击并拖拽任意组件卡片标题区域来重新排列布局
- **尺寸调整**: 鼠标悬停在组件右下角，出现调整手柄可改变组件大小
- **布局自动保存**: 所有布局更改自动保存到浏览器本地存储
- **一键重置**: 点击"重置布局"按钮恢复到默认布局
- **响应式设计**: 在不同屏幕尺寸下自适应布局

### 📱 响应式断点
- **Large (≥1200px)**: 12列网格，完整功能
- **Medium (≥996px)**: 10列网格，垂直排列
- **Small (≥768px)**: 6列网格，单列显示

## 组件说明

### 📊 统计卡片 (stats)
- 显示项目总数、已完成任务、进行中任务、待办任务
- 包含逾期任务警告标识
- 默认位置：顶部，全宽度

### 📈 效率统计 (productivity)
- 本周完成任务、创建任务、效率提升指标
- 实时数据更新
- 默认位置：统计卡片下方

### ⚡ 快速操作 (quickActions)
- 项目管理、批量导入、任务管理、数据分析快捷入口
- 点击可直接跳转到对应页面
- 默认位置：左侧中部

### 📅 最近活动 (recentActivities)
- 显示最近6条任务活动记录
- 包含活动类型图标和时间戳
- 默认位置：右侧中部

### 📋 项目进度 (projectProgress)
- 各项目完成进度条
- 任务数量统计
- 进度颜色编码（绿色/橙色/红色）
- 默认位置：左侧下部

### 👥 团队工作负载 (userWorkload)
- 团队成员任务分配情况
- 工作量状态指示器
- 预估工时统计
- 默认位置：右侧下部

### 📊 汇总统计 (summary)
- 总任务数、完成率、平均项目进度
- 关键指标概览
- 默认位置：底部，全宽度

## 使用技巧

### 🖱️ 拖拽操作
1. **移动组件**: 点击卡片标题区域，拖拽到目标位置
2. **调整大小**: 悬停到组件右下角，拖拽调整手柄
3. **查看预览**: 拖拽时会显示半透明预览位置

### 💾 布局管理
- **自动保存**: 每次调整都会自动保存到 localStorage
- **重置布局**: 点击工具栏"重置布局"按钮恢复默认
- **跨设备同步**: 同一浏览器不同窗口共享布局设置

### 🔄 数据刷新
- **手动刷新**: 点击工具栏"刷新"按钮
- **自动缓存**: 各组件数据有不同的缓存时间
- **增量加载**: 支持部分数据加载失败的处理

## 技术实现

### 📦 主要依赖
- `react-grid-layout`: 拖拽网格布局引擎
- `react-resizable`: 组件尺寸调整功能
- `ant-design`: UI组件库

### 🏗️ 架构设计
- **模块化组件**: 每个仪表板功能作为独立渲染函数
- **响应式网格**: 支持多种屏幕尺寸的自适应布局
- **状态管理**: 布局状态持久化到本地存储
- **性能优化**: 使用 useMemo 和 useCallback 优化渲染

### 🎨 样式系统
- **CSS模块**: 独立的样式文件 `draggable-dashboard.css`
- **动画效果**: 拖拽时的视觉反馈和过渡动画
- **主题适配**: 与现有 Ant Design 主题保持一致

## 故障排除

### 常见问题
1. **布局错乱**: 尝试点击"重置布局"按钮
2. **拖拽不响应**: 检查鼠标是否在卡片标题区域
3. **数据不更新**: 点击"刷新"按钮手动更新数据

### 浏览器兼容性
- Chrome/Edge: 完全支持
- Firefox: 完全支持  
- Safari: 基本支持（部分动画效果可能不同）
- 移动端: 支持触摸拖拽

## 扩展指南

### 添加新组件
1. 在 `renderXXXComponent()` 中定义新组件
2. 在 `defaultLayouts` 中添加布局配置
3. 在主渲染函数中添加组件调用

### 自定义布局
```typescript
// 修改默认布局
const customLayout = {
  lg: [
    { i: 'newComponent', x: 0, y: 0, w: 6, h: 3 }
  ]
};
```
