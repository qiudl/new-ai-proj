# 任务 #475 执行记录

标题：修复“最近任务”：补充执行日期时间并按最近时间倒序排列

## 实施内容
- 后端补齐路由（routes/timer_routes.go）：
  - GET /api/v1/timer/stats → handlers.TimerHandler.GetTimerStats
  - GET /api/v1/timer/recent-tasks → handlers.TimerHandler.GetTimerRecentTasks
  - 注：数据源为 PostgresTimerRepository.GetRecentTasksByUserWithPagination，统一查询项目任务与个人计时任务，ORDER BY last_timed_at DESC。
- 前端展示增强：
  - frontend/src/components/HistoryTimedTasks.tsx：相对时间旁新增 Tooltip（YYYY-MM-DD HH:mm:ss），并新增精确时间一行展示。
  - frontend/src/components/SimpleHistoryTasks.tsx：相对时间加 Tooltip，并增加精确时间一行展示。
  - frontend/src/components/CompactHistoryTasks.tsx：相对时间加 Tooltip。

## 验收标准
- 最近/历史任务按 last_timed_at 倒序显示；
- 相对时间 + 精确时间（YYYY-MM-DD HH:mm:ss）显示完整，提供 Tooltip；
- 删除任务仍有可读占位信息；
- /api/v1/timer/recent-tasks 支持 limit/offset，按 last_timed_at 倒序；
- /api/v1/timer/stats.recent_tasks 含 last_timed_at 且结构与前端对齐。
