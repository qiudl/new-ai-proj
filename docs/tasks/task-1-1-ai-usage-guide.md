# AI辅助任务生成功能使用指南

## 概述

AI辅助任务生成功能是一个智能化的项目管理工具，能够根据您的需求描述自动生成结构化的子任务列表。该功能支持多个AI提供商（OpenAI、Claude、DeepSeek），具备成本控制、历史记录管理和使用统计等高级功能。

## 核心功能特性

### 🤖 智能任务生成
- **多AI提供商支持**：集成OpenAI、Claude、DeepSeek三大AI平台
- **智能任务分解**：基于父任务和关键词描述生成3-10个具体子任务
- **质量评估系统**：对生成的任务进行自动质量评分和优化建议
- **灵活配置选项**：支持简单/详细模式、任务数量控制等

### 📊 成本管理与统计
- **Token使用追踪**：实时监控输入输出Token消耗
- **成本估算显示**：精确计算每次生成的预估费用
- **预算预警功能**：月度预算监控和超支提醒
- **使用统计分析**：多维度统计和趋势分析

### 📝 历史记录管理
- **生成历史保存**：自动保存每次生成的详细记录
- **配置复用功能**：一键复用历史生成配置
- **模板系统**：保存常用配置为模板
- **数据导出功能**：支持历史记录和统计数据导出

## 快速开始

### 1. 环境准备

首先确保您已经配置了至少一个AI提供商：

1. 访问系统设置 → AI配置管理页面
2. 配置OpenAI、Claude或DeepSeek的API密钥
3. 测试连接确保配置正确

### 2. 基础使用流程

#### 步骤一：选择父任务
1. 进入项目的任务管理页面
2. 点击"批量导入"或"AI辅助生成"按钮
3. 在任务选择器中选择要添加子任务的父任务

> **提示**：建议选择较为复杂的、需要进一步分解的任务作为父任务

#### 步骤二：描述任务需求
在关键词描述框中输入您希望生成的子任务内容，例如：

**前端开发项目示例：**
```
前端界面开发、组件设计、状态管理、API接口对接、用户交互优化、响应式布局、测试用例编写
```

**后端API项目示例：**
```
数据库设计、API接口开发、权限验证、数据验证、错误处理、文档编写、单元测试、部署配置
```

**产品设计项目示例：**
```
用户需求分析、原型设计、UI设计、交互设计、用户体验优化、设计规范制定、可用性测试
```

#### 步骤三：配置生成选项
在高级选项中可以调整：

- **AI提供商**：选择特定提供商或让系统自动选择
- **生成复杂度**：
  - 简单模式：生成3-5个基础任务
  - 详细模式：生成5-8个详细任务
- **最大任务数**：控制生成的任务数量（3-10个）

#### 步骤四：生成和编辑
1. 点击"AI智能生成子任务"按钮
2. 等待AI分析和生成（通常需要3-10秒）
3. 查看生成结果，包括：
   - 任务列表预览
   - 质量评分
   - Token使用统计
   - 成本信息
4. 如需调整，可以：
   - 直接编辑任务内容
   - 重新生成
   - 调整配置后再次生成

#### 步骤五：导入任务
确认生成的任务满足需求后，点击"导入这些任务"完成批量添加。

## 高级功能详解

### AI提供商选择指南

#### OpenAI (GPT)
- **适用场景**：通用任务分解、创意类项目
- **特点**：响应速度快、通用性强
- **成本**：中等（约0.002-0.02元/1000tokens）
- **推荐用于**：文档写作、创意设计、通用开发任务

#### Claude (Anthropic)
- **适用场景**：复杂分析、技术项目、详细规划
- **特点**：分析能力强、逻辑清晰、回答详细
- **成本**：较高（约0.01-0.08元/1000tokens）
- **推荐用于**：技术架构设计、复杂业务分析、详细项目规划

#### DeepSeek
- **适用场景**：成本敏感项目、大量任务生成
- **特点**：性价比最高、响应速度快
- **成本**：最低（约0.001-0.002元/1000tokens）
- **推荐用于**：日常开发任务、简单任务分解、批量生成

### 智能提供商选择
系统会根据以下因素自动选择最佳提供商：
1. **成本效益**：优先选择性价比高的DeepSeek
2. **任务复杂度**：复杂任务自动选择Claude
3. **可用性**：确保选择的提供商当前可用
4. **历史表现**：基于历史成功率选择

### 质量评估系统

系统从以下维度评估生成任务的质量：

#### 评分标准
- **90-100分**：优秀 - 任务清晰具体、逻辑合理、可执行性强
- **80-89分**：良好 - 任务基本合理、需要小幅调整
- **70-79分**：一般 - 任务可用但需要较多调整
- **60-69分**：较差 - 建议重新生成
- **60分以下**：不及格 - 自动拒绝并重新生成

#### 优化建议
系统会自动分析生成的任务并提供优化建议：

- **任务颗粒度**：任务过大或过小的提醒
- **优先级分布**：建议合理的优先级分配
- **工时估算**：检查工时估算的合理性
- **任务依赖**：识别潜在的任务依赖关系
- **完整性检查**：确保任务覆盖完整的工作流程

### 成本控制功能

#### 预算设置
1. 在成本预警区域设置月度预算
2. 系统会基于历史使用情况预测月度成本
3. 当接近或超过预算时显示预警

#### 成本优化建议
- **提供商选择**：基于成本效益推荐合适的AI提供商
- **Token优化**：建议优化关键词描述以减少Token消耗
- **批量生成**：建议一次性生成多个相关任务以提高效率

#### 成本监控指标
- **每次生成成本**：单次任务生成的费用
- **平均Token使用**：每次生成的平均Token消耗
- **提供商成本分布**：不同提供商的成本占比
- **时间趋势分析**：成本变化趋势和使用模式

### 历史记录与模板管理

#### 历史记录功能
- **自动保存**：每次生成都会自动保存详细记录
- **搜索过滤**：支持按关键词、提供商、时间范围搜索
- **详情查看**：查看完整的生成参数和结果
- **配置复用**：一键复用历史配置重新生成

#### 模板系统
1. **保存模板**：将满意的生成配置保存为可复用模板
2. **模板管理**：管理已保存的模板，支持编辑和删除
3. **标签分类**：为模板添加标签便于分类管理
4. **使用统计**：跟踪模板的使用频率和效果

#### 数据导出
- **历史记录导出**：JSON格式导出完整历史数据
- **统计报告导出**：导出使用统计和成本分析报告
- **模板备份**：批量导出模板配置用于备份

### 使用统计与分析

#### 概览统计
- **总生成次数**：累计生成任务的次数
- **成功率**：生成成功的比例
- **平均质量评分**：生成任务的质量指标
- **总成本统计**：累计消费金额

#### 提供商分析
- **使用分布**：各提供商的使用比例
- **成本对比**：不同提供商的成本效益分析
- **性能对比**：响应时间和成功率对比
- **质量对比**：各提供商生成任务的质量对比

#### 趋势分析
- **时间趋势**：按日/周/月的使用趋势
- **成本趋势**：成本变化趋势分析
- **质量趋势**：生成质量的变化趋势
- **效率分析**：使用频率和效率指标

#### 热门关键词统计
- **关键词排行**：最常使用的关键词统计
- **关键词效果**：不同关键词对应的生成质量
- **关键词优化**：基于统计数据的关键词优化建议

### 任务分解策略

#### 按功能模块分解
适用于功能复杂的项目：
```
用户管理模块：注册、登录、权限验证、个人信息管理
内容管理模块：发布、编辑、审核、分类管理
数据分析模块：统计报表、数据可视化、导出功能
```

#### 按开发阶段分解
适用于有明确开发流程的项目：
```
需求分析：用户调研、需求文档、原型设计
开发实现：后端API、前端界面、数据库设计
测试部署：单元测试、集成测试、部署配置
```

#### 按技术栈分解
适用于技术导向的项目：
```
后端开发：Node.js API、数据库设计、权限中间件
前端开发：React组件、状态管理、UI交互
运维部署：Docker配置、CI/CD流程、监控告警
```

### 成本优化策略

#### 1. 合理选择AI提供商
- **简单任务**：优先使用DeepSeek（成本最低）
- **复杂分析**：使用Claude（质量最高）
- **创意任务**：使用OpenAI（创造性强）

#### 2. 优化描述长度
- 避免过于冗长的描述（推荐100-300字）
- 使用关键词而非完整句子
- 重点突出核心需求

#### 3. 批量生成策略
- 一次性生成多个相关任务
- 避免频繁的小批量生成
- 合理设置最大任务数

#### 4. 利用历史记录
- 复用成功的配置模板
- 参考历史质量评分
- 避免重复生成相似任务

### 质量提升技巧

#### 1. 任务描述优化
- **具体化**：避免模糊的描述，使用具体的技术术语
- **可执行性**：确保描述的任务是可以实际执行的
- **完整性**：考虑完整的工作流程，避免遗漏关键步骤

#### 2. 参数调整
- **复杂度选择**：根据项目复杂程度选择合适的生成模式
- **任务数量**：根据实际需要调整任务数量，避免过多或过少
- **提供商选择**：根据任务类型选择最适合的AI提供商

#### 3. 结果优化
- **及时编辑**：生成后及时调整不合适的任务
- **合并分割**：将过于细碎的任务合并，将过大的任务分割
- **优先级调整**：根据实际情况调整任务优先级

## 常见问题解答

### Q1: AI生成失败怎么办？

**可能原因及解决方案：**

1. **API配置问题**
   - 检查API密钥是否正确
   - 确认API配额是否充足
   - 测试网络连接

2. **描述内容问题**
   - 避免使用敏感词汇
   - 确保描述清晰具体
   - 控制描述长度适中

3. **系统限制**
   - 检查并发请求限制
   - 确认服务状态正常
   - 稍后重试

### Q2: 如何提高生成任务的质量？

**优化策略：**

1. **改善输入描述**
   - 使用专业术语
   - 提供上下文信息
   - 明确技术栈和要求

2. **选择合适的AI提供商**
   - 技术类任务：Claude
   - 创意类任务：OpenAI  
   - 常规任务：DeepSeek

3. **调整生成参数**
   - 选择详细模式
   - 增加任务数量
   - 多次生成选择最优结果

### Q3: 如何控制使用成本？

**成本控制建议：**

1. **设置预算预警**
   - 配置月度预算限额
   - 开启成本预警提醒
   - 定期查看使用统计

2. **优化使用习惯**
   - 优先使用DeepSeek
   - 批量生成相关任务
   - 复用历史配置

3. **监控使用情况**
   - 定期查看成本分析
   - 识别高成本操作
   - 调整使用策略

### Q4: 历史记录如何管理？

**管理建议：**

1. **定期整理**
   - 删除无用的历史记录
   - 将优质配置保存为模板
   - 导出重要数据备份

2. **分类管理**
   - 使用标签分类
   - 按项目或时间分组
   - 建立命名规范

3. **复用优化**
   - 识别高质量的历史记录
   - 建立标准化模板
   - 持续优化配置

### Q5: 多人团队如何使用？

**团队协作建议：**

1. **统一规范**
   - 制定关键词描述规范
   - 统一任务分解标准
   - 建立质量评估标准

2. **权限管理**
   - 合理分配使用权限
   - 设置成本控制策略
   - 监控团队使用情况

3. **知识共享**
   - 分享优质模板
   - 总结最佳实践
   - 定期培训更新
