# 推荐的重构架构

  新的统一设计：

  // 统一计时器处理器
  type UnifiedTimerHandler struct {
      db database.DB
      timerService *services.TimerService // 核心逻辑
  }

  // 任务类型枚举
  type TaskType string
  const (
      TaskTypePersonal TaskType = "personal"
      TaskTypeProject  TaskType = "project"
  )

  // 统一的启动请求
  type StartTimerRequest struct {
      TaskType TaskType `json:"task_type" validate:"required,oneof=personal project"`
      TaskID   int      `json:"task_id" validate:"required"`
      Action   string   `json:"action,omitempty"` // start, pause, resume
  }

  新的API设计：
  POST   /user/timer/start    - 统一启动（支持personal/project）
  POST   /user/timer/stop     - 停止计时
  POST   /user/timer/pause    - 暂停计时 ⭐ 新增
  POST   /user/timer/resume   - 恢复计时 ⭐ 新增
  GET    /user/timer/current  - 当前状态
  GET    /user/timer/stats    - 统计信息

  核心服务层：
  type TimerService struct {
      // 提取所有通用逻辑：
      // - 事务管理
      // - 用户状态更新

  }

  🚀 重构收益

  1. 代码减少 60%+ - 消除重复逻辑
  2. API简化 - 统一接口，更容易使用
  3. 功能完整 - 真正的暂停/恢复支持
  4. 维护简单 - 单一职责原则
