  3. 遇到的特别情况和解决方案

  技术挑战

  1. styled-jsx类型错误：
    - 问题：TaskParentSelector使用styled-jsx导致TypeScript编
  译错误
    - 分析：styled-jsx在React 18 +
  TypeScript环境下存在类型兼容性问题
    - 解决：统一采用dangerouslySetInnerHTML方式注入CSS，确保
  类型安全
  2. 组件状态同步复杂性：
    - 问题：父任务选择器与表单组件间的状态同步复杂
    - 分析：需要同时维护selectedTask、form
  values、validation状态
    -
  解决：设计清晰的状态流转机制，通过onChange回调统一状态管理
  3. 验证流程集成：
    - 问题：客户端和服务端验证需要无缝集成
    - 分析：异步验证可能导致UI状态不一致
    -
  解决：添加isValidating状态和loading指示器，确保用户体验连贯

  集成难点

  4. ErrorBoundary集成策略：
    - 问题：如何在不破坏现有功能的前提下添加错误边界
    - 分析：需要平衡错误捕获范围和组件独立性
    - 解决：选择性包装关键组件，提供fallback UI和重试机制

  任务分解

  📋 M3.1 - TaskModal集成改造 (高优先级)

  M3.1.1 分析现有TaskModal的父任务选择实现
  - 当前状态: TaskModal已有基础的父任务选择功能
  - 问题分析:
    - 使用简单Select组件，缺乏搜索和分页
    - 循环依赖检测不完善 (只检查直接父子关系)
    - 层级显示不够直观 (仅使用全角空格缩进)
    - 无实时验证，可能创建无效层级结构
  - 技术债务:
  loadParentTasks方法加载所有任务(最多500个)，性能不佳

  M3.1.2 重构TaskModal使用TaskParentSelectorModal组件
  - 替换策略:
  将Form.Item中的Select替换为TaskParentSelectorModal触发按钮
  - 集成点: 第352-406行的allowParentSelection部分
  - 数据流设计:
  // 状态管理
  const [parentSelectorVisible, setParentSelectorVisible] =
  useState(false);
  const [selectedParent, setSelectedParent] = useState<Task |
   null>(null);

  // 事件处理
  const handleParentSelect = (parentId: number | null, 
  parentTask: Task | null) => {
    form.setFieldValue('parent_id', parentId);
    setSelectedParent(parentTask);
    setParentSelectorVisible(false);
  };

  M3.1.3 清理TaskModal中的旧父任务选择逻辑
  - 移除内容:
    - loadParentTasks方法 (第48-79行)
    - parentTasks和parentTasksLoading状态
    - useEffect中的loadParentTasks调用
    - 原有Select组件的复杂Option渲染逻辑
  - 保留内容:
    - allowParentSelection prop支持
    - parent_id表单字段
    - 父任务信息显示

  M3.1.4 测试TaskModal的父任务选择功能
  - 功能测试: 创建任务时选择父任务、编辑任务时修改父任务

  - UI测试: 模态框交互、响应式布局、错误提示

  📋 M3.2 - TaskEditPage功能增强 (高优先级)

  M3.2.1 分析TaskEditPage缺失的父任务编辑功能

  - 集成位置: 父任务信息显示区域 (Descriptions组件附近)

  M3.2.2 为TaskEditPage添加TaskParentSelector组件
  - UI设计:
  在父任务信息旁添加"修改"按钮，触发TaskParentSelector
  - 布局方案:
  <Descriptions.Item label="父任务" span={2}>
    <div style={{ display: 'flex', alignItems: 'center', gap:
   8 }}>
      {parentTask ? (
        <>
          <Button 
            type="link" 
            onClick={() => navigate(`/projects/${task.project
  _id}/tasks/${parentTask.id}`)}
          >
            {parentTask.title} (#{parentTask.id})
          </Button>
          <TaskParentSelector
            projectId={task.project_id}
            currentTaskId={task.id}
            currentParentId={parentTask.id}
            onChange={handleParentChange}
          />
        </>
      ) : (
        <TaskParentSelector
          projectId={task.project_id}
          currentTaskId={task.id}
          placeholder="选择父任务"
          onChange={handleParentChange}
        />
      )}
    </div>
  </Descriptions.Item>

  const [parentTaskChanged, setParentTaskChanged] =
