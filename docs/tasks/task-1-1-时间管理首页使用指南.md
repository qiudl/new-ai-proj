# 时间管理首页使用指南与测试

## 1. 功能概述

时间管理首页(`/time-management`)是一个专为提高工作效率设计的统计Dashboard，提供今日任务的全方位数据分析。

## 2. 主要功能模块

### 2.1 今日任务统计概览
- **今日任务总数**: 今天相关的所有任务数量
- **已完成任务**: 今天完成的任务数量和完成率
- **进行中任务**: 当前正在处理的任务数量
- **时间效率**: 实际用时与计划用时的比值

### 2.2 重要提醒区域
- **逾期任务提醒**: 当有逾期任务时显示红色警告
- **紧急任务提醒**: 当有高优先级任务时显示橙色提醒

### 2.3 详细统计分析
- **任务状态分布**: 已完成、进行中、待办、逾期任务的数量分布
- **优先级分布**: 紧急、高、中、低优先级任务的分布情况
- **时间统计**: 计划时间、实际时间、按时完成率等

### 2.4 任务列表展示
- **紧急任务列表**: 显示高优先级的未完成任务
- **即将到期列表**: 显示明天到期的任务

### 2.5 智能建议
- **效率小贴士**: 根据当前数据自动生成的工作建议

## 3. 使用步骤

### 3.1 访问页面
```
导航至: /time-management
或者从任务看板页面点击"时间管理工作台"按钮
```

### 3.2 查看统计数据
1. 页面加载后自动显示今日任务统计
2. 数据每2分钟自动缓存，每5分钟自动刷新
3. 可点击"刷新数据"按钮手动更新

### 3.3 操作任务
1. 点击紧急任务或即将到期任务可跳转到任务详情
2. 点击"查看任务看板"可跳转到完整的任务管理页面
3. 点击任务列表中的眼睛图标可快速查看任务详情

## 4. 数据来源说明

### 4.1 今日相关任务定义
系统会自动筛选以下任务作为"今日相关任务"：
- 今天到期的任务
- 今天创建的任务
- 今天更新过的任务
- 当前正在进行中的任务（不限日期）
- 已逾期但未完成的任务

### 4.2 时间数据优先级
1. 计时器记录的实际工作时间 (`total_time_seconds`)
2. 手动录入的实际工时 (`actual_hours`)
3. 预估工时 (`estimated_hours` 或 `custom_fields.estimated_hours`)

## 7. 常见问题排查

### 7.1 数据不显示
```bash
# 检查步骤
1. 确认网络连接正常
2. 检查浏览器控制台是否有错误
3. 确认用户有访问项目和任务的权限
4. 检查 API 服务是否正常运行
5. 清除浏览器缓存重试
```

### 7.2 统计数据异常
```bash
# 排查方法
1. 检查任务数据的完整性
2. 验证时间字段格式是否正确
3. 确认任务状态值是否有效
4. 查看控制台警告信息
5. 对比原始数据和计算结果
```

### 7.3 页面加载慢
```bash
# 优化方案
1. 检查任务数量是否过多（>500个）
2. 确认数据库查询性能
3. 检查网络延迟
4. 考虑增加缓存时间
5. 使用快速统计API
```
