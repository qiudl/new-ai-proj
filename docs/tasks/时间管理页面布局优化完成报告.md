## 🔧 如何使用

### 访问页面
1. 启动开发服务器：`cd frontend && npm start`
2. 访问：`http://localhost:3000`
3. 导航到"时间管理"页面

### 自定义布局
1. 点击右上角的拖拽模式开关
2. 拖拽组件到任意位置
3. 使用组件设置调整尺寸
4. 关闭拖拽模式保存设置

## 📋 组件说明

### 1. 任务计时 (Timer)
- 显示当前计时状态
- 支持暂停/继续/完成操作
- 键盘快捷键支持

### 2. 我的任务 (MyTasks)
- 树形结构显示项目和任务
- 快速启动计时功能
- 任务状态一目了然

### 3. 今日工作统计 (TodayStats)
- 今日工作总时间
- 完成任务数量
- 进行中任务数量
- 最近计时任务列表

### 4. 任务统计分析 (TimerStats)
- 按时间段统计分析
- 数据可视化表格
- 支持日期范围选择
- CSV导出功能

### 5. 任务进度分析 (TaskProgress)
- 今日任务完成率
- 本周任务完成率
- 任务时间分布
- 进度可视化
