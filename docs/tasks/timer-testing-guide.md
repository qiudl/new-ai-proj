## 🐛 常见问题排查

### 502 Bad Gateway
- **原因**: 系统代理干扰
- **解决**: 禁用代理或使用 `--noproxy "*"`

### 浮动定时器不显示
- **检查**: TimerContext是否正确包装App
- **检查**: 是否有CSS冲突隐藏浮动窗口

### 计时状态不同步
- **检查**: 双定时器系统状态是否一致
- **检查**: localStorage中的数据是否正确

### API认证失败
- **检查**: JWT token是否有效
- **检查**: 登录状态是否正常
