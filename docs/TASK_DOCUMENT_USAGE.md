# 任务文档管理功能使用指南

## 概述

任务文档管理功能允许用户为每个任务创建和编辑Markdown格式的文档，用于记录任务的详细信息、技术方案、实现进度等。

## 功能特性

### ✨ 核心功能
- **每个任务一个文档**：每个任务都有一个独立的Markdown文档
- **实时编辑**：支持编辑和预览模式切换
- **自动保存**：内容变化后5秒自动保存
- **状态显示**：Tab上显示文档存在状态
- **默认模板**：新文档自动应用结构化模板

### ⌨️ 快捷键支持
- `Ctrl/Cmd + S`：保存文档
- `Ctrl/Cmd + E`：切换编辑/预览模式

## 如何使用

### 1. 访问任务文档

1. 进入任务详情页面
2. 点击 "任务文档" Tab
3. 系统会自动加载文档或显示默认模板

### 2. 编辑文档

1. 在编辑模式下输入Markdown内容
2. 使用工具栏按钮切换编辑/预览模式
3. 点击保存按钮或使用快捷键保存

### 3. 自动保存

- 文档内容变化后会在5秒后自动保存
- 工具栏会显示自动保存状态
- 自动保存不会显示成功消息，避免干扰

### 4. 状态指示

**Tab状态**：
- 🟢 绿色圆点：文档已存在
- ⚪ 灰色圆点：文档不存在

**工具栏状态**：
- 🔄 自动保存中...（蓝色）
- * 文档有未保存的更改（橙色）
- ✓ 已保存 时间（绿色）

## 默认文档模板

新创建的文档会自动应用以下模板：

```markdown
# 任务文档

## 需求描述
<!-- 在这里描述任务的具体需求 -->

## 技术方案
<!-- 在这里描述实现方案 -->

## 实现进度
- [ ] 需求分析
- [ ] 技术设计
- [ ] 代码实现
- [ ] 测试验证

## 备注
<!-- 其他相关信息 -->
```

## Markdown语法支持

支持所有标准Markdown语法：

### 标题
```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 文本格式
```markdown
**粗体文本**
*斜体文本*
`代码文本`
~~删除线~~
```

### 列表
```markdown
- 无序列表项1
- 无序列表项2

1. 有序列表项1
2. 有序列表项2

- [ ] 待办事项1
- [x] 已完成事项
```

### 代码块
```markdown
```javascript
function hello() {
    console.log("Hello World!");
}
```
```

### 链接和图片
```markdown
[链接文本](https://example.com)
![图片描述](image-url.png)
```

### 表格
```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 数据1 | 数据2 | 数据3 |
```

## 技术实现

### 后端API
- `GET /api/v1/projects/:id/tasks/:taskId/document` - 获取文档内容
- `PUT /api/v1/projects/:id/tasks/:taskId/document` - 保存文档内容
- `HEAD /api/v1/projects/:id/tasks/:taskId/document` - 检查文档是否存在

### 文件存储
- 文档存储在 `./docs/tasks/{taskId}.md`
- 文件名格式：任务ID + ".md"
- 文件编码：UTF-8

## 错误处理

### 常见错误及解决方案

**未授权访问**
- 错误：401 Unauthorized
- 解决：重新登录系统

**任务不存在**
- 错误：404 Not Found
- 解决：检查任务ID是否正确

**网络连接失败**
- 错误：网络连接超时
- 解决：检查网络连接，点击重新加载

**文档内容过大**
- 错误：413 Payload Too Large
- 解决：减少文档内容，分段保存

## 最佳实践

### 1. 文档结构建议
- 使用清晰的标题层级
- 添加目录索引（较长文档）
- 保持段落简洁明了
- 使用列表组织信息

### 2. 内容建议
- **需求描述**：明确、具体的需求说明
- **技术方案**：详细的实现思路和技术选型
- **进度跟踪**：使用待办事项列表跟踪进度
- **备注**：重要的注意事项和参考链接

### 3. 协作建议
- 定期更新文档内容
- 记录重要的变更决定
- 添加时间戳标记重要节点
- 使用引用标注信息来源

## 故障排除

### 文档无法加载
1. 检查网络连接
2. 确认用户权限
3. 验证任务ID是否正确
4. 刷新页面重试

### 保存失败
1. 检查网络连接
2. 确认文档内容大小
3. 检查用户权限
4. 尝试手动保存

### 自动保存异常
1. 检查控制台错误信息
2. 手动保存确认权限
3. 刷新页面重试
