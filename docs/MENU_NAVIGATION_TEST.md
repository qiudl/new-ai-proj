# 文档管理菜单导航测试

## 测试目标
验证新创建的"文档管理"顶级菜单及其子菜单的导航功能。

## 测试环境
- 前端服务：http://localhost:3000
- 后端服务：http://localhost:8080
- 数据库：PostgreSQL运行正常

### 2. 工作笔记导航测试
- 点击 "文档管理" → "工作笔记"
- **预期：** 跳转到 `/document-manager`
- **预期：** 显示原有的文档管理器页面

### 3. 任务文档导航测试
- 点击 "文档管理" → "任务文档"
- **预期：** 跳转到 `/task-documents`
- **预期：** 显示任务文档列表页面
- **预期：** 页面包含：
  - 标题："任务文档管理"
  - 统计卡片：总任务数、有文档任务、无文档任务
  - 筛选区域：搜索框、项目筛选、状态筛选、文档状态筛选
  - 任务列表表格

### 4. 任务文档功能测试
在任务文档列表页面：

**4.1 统计显示测试**
- 检查统计卡片是否显示正确数字
- 检查是否正确计算有文档/无文档任务数量

**4.2 筛选功能测试**
- 测试搜索框：输入任务名称关键词
- 测试项目筛选：选择特定项目
- 测试任务状态筛选：选择"进行中"、"已完成"等
- 测试文档状态筛选：选择"有文档"、"无文档"

**4.3 操作按钮测试**
- 点击"查看任务详情"按钮（眼睛图标）
  - **预期：** 跳转到任务详情页
- 点击"编辑任务文档"按钮（编辑图标）
  - **预期：** 跳转到任务详情页的文档Tab
  - **预期：** URL包含 `?tab=document`
- 点击"打开项目"按钮（文件夹图标）
  - **预期：** 跳转到对应项目页面

### 5. 任务详情页文档Tab测试
从任务文档列表点击"编辑任务文档"后：

- 测试保存功能
- 测试自动保存（5秒）
- 测试快捷键：Ctrl/Cmd + S、Ctrl/Cmd + E

**5.3 文档状态显示测试**
- **预期：** Tab上显示文档状态圆点
- 保存文档后检查状态是否更新

### 6. 菜单展开收起测试

## 总结
完整的文档管理菜单重组已完成，包括：
1. 创建了"文档管理"顶级菜单
2. 将原"文档管理器"重命名为"工作笔记"作为子菜单
3. 新增"任务文档"子菜单，指向任务文档管理功能
4. 实现了完整的任务文档列表和编辑功能
5. 支持从列表页直接跳转到文档编辑
6. 菜单导航和URL状态管理正常

这个重组让用户能够更清晰地区分和访问不同类型的文档功能。
