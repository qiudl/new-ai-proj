# 对齐准则（命名/约束）草稿

> 关联任务：574 M1-1 现状盘点与对齐准则（仓库暂存版；任务系统接口恢复后将自动关联）

## 命名规范
- 表名/列名使用 snake_case
- 索引命名：idx_{table}_{cols}
- 唯一索引：uk_{table}_{cols}
- 外键：fk_{fromTable}_{toTable}

## 约束与默认值
- 必要字段 NOT NULL；为外键列建立必要索引
- 时间戳：created_at/updated_at，默认 now()
- 软删除（如采用）：deleted_at 可空

## 类型与枚举
- 使用合适的整型/枚举/文本类型，避免过大类型导致存储/索引膨胀

## 迁移策略
- 重命名/拆并列使用渐进式迁移（影子列→复制→双写校验→切换→清理）
- 提供回滚路径与验证步骤

## 验收标准
- 准则文档评审通过，后续迁移遵循并可在 CI 校验

## 备注
- 环境与 CI：Jenkins 以 Docker agent 执行，生产与测试均使用 Postgres
