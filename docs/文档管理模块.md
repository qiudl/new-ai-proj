# 项目文档管理模块 - 简化版MVP设计方案

## 🎯 产品概述

项目文档管理模块的简化版本，专注于纯文本文档的创建、编辑和管理。用户可以在项目内创建和编辑纯文本文档，实现基础的文档管理功能。开发时间：1天完成。

## 📋 核心功能需求

### 1. 基础文档管理
- **创建文档**: 在项目内创建纯文本文档
- **编辑文档**: 简单的纯文本编辑器
- **保存文档**: 实时保存或手动保存
- **删除文档**: 删除不需要的文档

### 2. 文档列表
- **文档列表**: 显示项目内所有文档
- **文档搜索**: 按标题搜索文档
- **文档排序**: 按创建时间或更新时间排序

### 3. 项目集成
- **项目归属**: 文档归属于特定项目
- **权限继承**: 继承项目的访问权限
- **快速访问**: 从项目页面快速访问文档

## 🏗️ 数据库设计

### 核心表结构

**documents 文档表**
```sql
CREATE TABLE documents (
    id SERIAL PRIMARY KEY,
    project_id INTEGER NOT NULL REFERENCES projects(id),
    title VARCHAR(255) NOT NULL,
    content TEXT DEFAULT '',
    created_by INTEGER NOT NULL REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_documents_project_id ON documents(project_id);
CREATE INDEX idx_documents_created_by ON documents(created_by);
```

## 🔌 API 设计

### 文档管理 API
```
GET    /api/projects/{project_id}/documents     # 获取项目文档列表
POST   /api/projects/{project_id}/documents     # 创建文档
GET    /api/documents/{id}                      # 获取文档详情
PUT    /api/documents/{id}                      # 更新文档
DELETE /api/documents/{id}                      # 删除文档
```

### API 数据格式

**创建文档请求**
```json
{
  "title": "会议记录",
  "content": "今日会议内容..."
}
```

**文档响应格式**
```json

  "project_id": 1,
  "title": "会议记录",
  "content": "今日会议内容...",
  "created_by": 1,
  "creator_name": "张三",
  "created_at": "2025-07-23T10:00:00Z",
  "updated_at": "2025-07-23T10:30:00Z"
}
```

## 📝 使用流程

1. **进入项目** → 点击"文档"标签
2. **查看文档** → 浏览项目内所有文档
3. **创建文档** → 点击"新建文档"按钮
4. **编辑文档** → 输入标题和内容，点击保存
5. **管理文档** → 搜索、排序、删除文档
