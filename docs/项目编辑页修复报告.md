# 项目编辑页字段保存问题 - 修复报告

## 问题描述
项目编辑页有3个字段保存后失效，没有成功保存到数据库：
1. **项目编号** (project_number)
2. **关联客户** (company_id/company_ids)  
3. **项目进度** (progress)

## 问题原因
后端的 `UpdateProject` 处理器（`/backend/handlers/project_handler.go`）没有正确处理这些字段。处理器的请求结构体中缺少这些字段的定义，导致前端发送的数据被忽略。

## 修复方案

### 1. 后端修改
修改文件：`/backend/handlers/project_handler.go`

**原代码：**
```go
var req struct {
    Name        string   `json:"name" binding:"required,min=1,max=255"`
    Description string   `json:"description"`
    Icon        *string  `json:"icon"`
    Color       *string  `json:"color"`
    Status      string   `json:"status"`
    Priority    string   `json:"priority"`
    // ... 缺少 project_number, company_id, progress 等字段
}
```

**修复后：**
```go
var req struct {
    ProjectNumber *string  `json:"project_number"`
    Name          string   `json:"name" binding:"required,min=1,max=255"`
    Description   string   `json:"description"`
    CompanyID     *int     `json:"company_id"`
    CompanyIDs    []int    `json:"company_ids"`
    UserIDs       []int    `json:"user_ids"`
    Status        string   `json:"status"`
    Priority      string   `json:"priority"`
    Progress      int      `json:"progress"`
    // ... 其他字段
}
```

同时在更新逻辑中添加对这些字段的处理：
```go
// Update fields
if req.ProjectNumber != nil {
    project.ProjectNumber = req.ProjectNumber
}

// Update company_id if provided
if req.CompanyID != nil {
    project.CompanyID = req.CompanyID
} else if len(req.CompanyIDs) > 0 {
    // If company_ids array is provided, use the first one as the primary company
    project.CompanyID = &req.CompanyIDs[0]
}

project.Progress = req.Progress
```
