# Prometheus监控系统集成方案

## 任务概述
将Prometheus监控系统集成到AI项目管理后台,在左侧菜单添加监控入口,仅超级管理员可访问可见。

## 技术方案

### 1. 后端集成 (Go)

#### 1.1 Prometheus客户端配置
```go
// handlers/monitoring_handler.go
type MonitoringHandler struct {
    registry *prometheus.Registry
}

// 创建监控handler
func NewMonitoringHandler() *MonitoringHandler {
    return &MonitoringHandler{
        registry: prometheus.DefaultRegisterer.(*prometheus.Registry),
    }
}

// GetMetrics 获取Prometheus指标数据
func (h *MonitoringHandler) GetMetrics(c *gin.Context) {
    handler := promhttp.HandlerFor(h.registry, promhttp.HandlerOpts{})
    handler.ServeHTTP(c.Writer, c.Request)
}
```

#### 1.2 路由配置
```go
// routes/monitoring_routes.go
func RegisterMonitoringRoutes(r *gin.RouterGroup, handler *MonitoringHandler) {
    monitoring := r.Group("/monitoring")
    {
        // 仅超级管理员可访问
        monitoring.Use(middleware.RequireSuperAdmin())
        monitoring.GET("/metrics", handler.GetMetrics)
        monitoring.GET("/prometheus", handler.GetPrometheusUI)
    }
}
```

#### 1.3 权限中间件
```go
// middleware/super_admin.go
func RequireSuperAdmin() gin.HandlerFunc {
    return func(c *gin.Context) {
        userType := c.GetString("user_type")
        username := c.GetString("username")
        
        // 检查是否为超级管理员
        if userType != "system" || !isSuperAdmin(username) {
            c.JSON(http.StatusForbidden, gin.H{
                "success": false,
                "error": "仅超级管理员可访问此功能",
            })
            c.Abort()
            return
        }
        
        c.Next()
    }
}

func isSuperAdmin(username string) bool {
    superAdmins := strings.Split(os.Getenv("SUPER_ADMIN_USERNAMES"), ",")
    for _, admin := range superAdmins {
        if strings.TrimSpace(admin) == username {
            return true
        }
    }
    return false
}
```

import { Card, Tabs, Alert } from 'antd';

#### 2.4 权限检查Hook
```typescript
// src/hooks/usePermissions.ts
export const useIsSuperAdmin = (): boolean => {
  const userInfo = useSelector((state: RootState) => state.auth.user);
  
  const superAdmins = [
    'admin',
    'guoym',
    'weier',
    'fuxing',
  ];

  return (
    userInfo?.user_type === 'system' &&
    superAdmins.includes(userInfo?.username)
  );
};
```

### 4. 现有Prometheus集成增强

#### 4.1 当前指标
系统已有以下监控指标(backend/monitoring/):
- `permission_check_duration_seconds` - 权限检查耗时
- `permission_db_query_total` - 数据库查询计数
- `permission_error_total` - 错误计数
- `permission_cache_hits_total` - 缓存命中
- `permission_cache_misses_total` - 缓存未命中
- `permission_operation_total` - 操作计数
- `permission_active_requests` - 活跃请求数
