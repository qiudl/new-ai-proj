# 增强统计信息卡片（评论数、浏览次数）

## 任务概述

增强需求详情页面的统计信息卡片，添加评论数和浏览次数统计，提供更全面的需求活跃度信息。

## 实现内容

### 1. 更新统计卡片

在 RequirementDetailPage.tsx 中更新统计卡片（lines 844-873）:

```tsx
{/* 统计信息 */}
<Card
  title="📈 统计"
  size="small"
  style={{ marginBottom: '16px' }}
>
  <Space direction="vertical" size="small" style={{ width: '100%' }}>
    <div>
      <Text type="secondary">💬 评论数</Text>
      <br />
      <Text strong style={{ fontSize: '18px' }}>
        {requirement.comments_count ?? 0}
      </Text>
    </div>
    <div>
      <Text type="secondary">👁️ 浏览次数</Text>
      <br />
      <Text strong style={{ fontSize: '18px' }}>
        {requirement.views_count ?? 0}
      </Text>
    </div>
    <div>
      <Text type="secondary">🔗 关联任务</Text>
      <br />
      <Text strong style={{ fontSize: '18px' }}>
        {linkedTasks.length}
      </Text>
    </div>
  </Space>
</Card>
```

## 功能特性

### 1. **评论数统计**
- 显示需求的总评论数
- 使用 `comments_count` 字段
- 默认值为 0（使用空值合并运算符 ??）
- 图标：💬

### 2. **浏览次数统计**
- 显示需求的总浏览次数
- 使用 `views_count` 字段
- 默认值为 0
- 图标：👁️

### 3. **关联任务统计**
- 显示已关联的任务数量
- 保留原有功能
- 使用实时数据（linkedTasks.length）
- 图标：🔗

## 视觉优化

1. **图标标识**: 每个统计项都有对应的emoji图标，易于识别
2. **字体大小**: 数据值使用18px字体，醒目清晰
3. **间距调整**: 使用 `size="small"` 使间距更紧凑
4. **一致样式**: 所有统计项保持统一的布局结构

## 数据来源

- **评论数**: 从 `requirement.comments_count` 获取（后端查询填充）
- **浏览次数**: 从 `requirement.views_count` 获取（后端查询填充）
- **关联任务**: 从前端加载的 `linkedTasks` 数组计算

## 容错处理

使用空值合并运算符（`??`）确保在后端未返回统计数据时显示默认值 0：

```typescript
{requirement.comments_count ?? 0}
{requirement.views_count ?? 0}
```

## 用户体验改进

1. **一目了然**: 三个关键指标集中展示，用户可快速了解需求热度
2. **图标引导**: Emoji图标使信息更易理解
3. **数据清晰**: 大字号数值提高可读性
4. **响应式**: 统一的布局在不同屏幕尺寸下都保持良好显示

3. 保持与其他侧边栏卡片的风格一致
4. 使用Ant Design的Space组件管理间距
