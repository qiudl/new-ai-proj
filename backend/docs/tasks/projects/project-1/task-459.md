# 任务 #459：Beta 实施：智能泳道/日历/批量级联/共享视图

## 背景与目标
为 Beta 版本落地以下四个能力，提升任务视图的可视化与操作效率：
- 智能泳道：按规则自动分组、拖拽重排、聚合统计
- 日历视图：基于开始/截止日期渲染任务排期，支持拖拽调整
- 批量级联：批量编辑与依赖联动（如状态/负责人/截止日期）
- 共享视图：生成可分享的只读链接并控制权限

## 范围（In/Out）
In：前端 UI、后端接口、权限、审计日志、E2E 验收
Out：移动端适配（可作为后续任务）

## 里程碑与甘特
- M1：设计评审（UX、数据模型、权限）
- M2：核心能力开发（含单元测试）
- M3：联调与 E2E
- M4：Beta 发布与监控

## 验收标准（DoD）
- 四个模块均可在演示环境可用，覆盖主要 Happy Path
- 关键路径具备单测与端到端用例
- 审计与权限覆盖
- 有回滚预案
