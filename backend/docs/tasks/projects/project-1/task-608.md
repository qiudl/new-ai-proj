# 修复父任务选择窗口"加载失败 请求参数错误"问题

## 任务描述
**问题描述:**
- 在任务管理界面中，点击选择父任务时出现"加载失败 请求参数错误"的错误提示
- 影响用户无法正常设置任务的父子关系，严重影响任务管理功能

**问题分析:**
- 可能是前端请求参数格式不正确
- 后端API接口参数验证可能存在问题
- 数据查询条件可能有误

**修复方案:**
1. 检查前端父任务选择组件的请求参数构造逻辑
2. 验证后端API接口的参数验证规则
3. 确认数据库查询条件的正确性
4. 添加详细的错误日志记录便于调试
5. 进行完整的功能测试确保修复效果

**验收标准:**
- 父任务选择窗口能正常加载任务列表
- 能够成功选择和设置父任务
- 不再出现"请求参数错误"的提示
- 相关功能稳定可用
