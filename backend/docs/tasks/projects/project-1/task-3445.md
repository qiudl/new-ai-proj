## 📱 响应式断点策略

基于Ant Design Grid系统定义的响应式断点：

| 断点 | 屏幕宽度 | 设备类型 | 适配策略 |
|------|---------|---------|---------|
| **xs** | < 576px | 超小屏手机 | 单列布局，卡片视图 |
| **sm** | ≥ 576px | 小屏手机 | 单列布局，优化间距 |
| **md** | ≥ 768px | 平板竖屏 | 两列或表格视图 |
| **lg** | ≥ 992px | 平板横屏/小屏桌面 | 标准桌面布局 |
| **xl** | ≥ 1200px | 桌面显示器 | 宽屏优化布局 |
| **xxl** | ≥ 1600px | 大屏显示器 | 最大宽度限制 |

### 设备分类

```typescript
isMobile: !breakpoint.md     // < 768px (手机)
isTablet: md && !lg          // 768-992px (平板)
isDesktop: ≥ lg              // ≥ 992px (桌面)
```

## 🛠️ 核心实现

### 1. useResponsive Hook

**文件**: `src/hooks/useResponsive.ts`  
**功能**: 提供统一的响应式检测和工具函数

#### 主要导出

```typescript
// Hook
export const useResponsive = (): ResponsiveInfo

// 响应式信息接口
export interface ResponsiveInfo {
  isMobile: boolean;      // < 768px
  isTablet: boolean;      // 768-992px
  isDesktop: boolean;     // ≥ 992px
  isXs: boolean;          // < 576px
  isSm: boolean;          // 576-768px
  isMd: boolean;          // 768-992px
  isLg: boolean;          // 992-1200px
  isXl: boolean;          // ≥ 1200px
  currentSize: ScreenSize;
  screenWidth: number;
  breakpoint: Partial<Record<ScreenSize, boolean>>;
}

// 工具函数
export const getResponsiveModalWidth = (
  defaultWidth: number,
  responsive: ResponsiveInfo
): number | string

export const getResponsiveTableScroll = (
  defaultScrollX: number,
  responsive: ResponsiveInfo
): { x?: number | string; y?: number }

export const getResponsiveValue = <T>(
  values: ResponsiveValueMap<T>,
  responsive: ResponsiveInfo
): T
```

#### 使用示例

```typescript
import { useResponsive, getResponsiveModalWidth } from '../hooks/useResponsive';

const MyComponent = () => {
  const responsive = useResponsive();
  
  return (
    <div style={{ 
      padding: responsive.isMobile ? '12px' : '24px',
      flexDirection: responsive.isMobile ? 'column' : 'row' 
    }}>
      {responsive.isMobile ? <MobileView /> : <DesktopView />}
    </div>
  );
};
```

// 移动端卡片视图
const renderMobileList = () => {

              </Dropdown>

              <Space><UserOutlined />{submitter}</Space>
              <Space><CalendarOutlined />{dueDate}</Space>
            </Space>
          </Card>
        </List.Item>
      )}
    />
  );
};

// 条件渲染

### 3. RequirementDetailPage - 详情页响应式

**文件**: `src/pages/RequirementDetailPage.tsx`

#### 响应式操作按钮

```typescript
const renderActionButtons = () => {
  if (!requirement) return null;

  // 移动端：Dropdown菜单
  if (responsive.isMobile) {
    const menuItems: MenuProps['items'] = [
      { key: 'submit', label: '提交评审', icon: <CheckCircleOutlined /> },
      { key: 'review', label: '评审', icon: <CheckCircleOutlined /> },
      { key: 'convert', label: '转换为任务', icon: <SwapOutlined /> },
      { type: 'divider' },
      { key: 'edit', label: '编辑', icon: <EditOutlined /> },
      { key: 'delete', label: '删除', icon: <DeleteOutlined />, danger: true },
    ];
    
    return (
      <Dropdown menu={{ items: menuItems }}>
        <Button type="primary" icon={<MoreOutlined />}>操作</Button>
      </Dropdown>
    );
  }

  // 桌面端：按钮组
  return (
    <Space>
      <Button type="primary" icon={<CheckCircleOutlined />}>提交评审</Button>
      <Button icon={<SwapOutlined />}>转换为任务</Button>
      <Button icon={<EditOutlined />}>编辑</Button>
      <Button danger icon={<DeleteOutlined />}>删除</Button>
    </Space>
  );
};
```

#### 响应式布局

```typescript
<div style={{ padding: responsive.isMobile ? '12px' : '24px' }}>
  <Row align="middle" gutter={responsive.isMobile ? [0, 12] : 0}>
    {/* 左侧：标题和标签 */}
    <Col xs={24} lg={18}>
      <Space size={responsive.isMobile ? 'middle' : 'large'}>
        <Button icon={<ArrowLeftOutlined />}>返回</Button>
        <div>
          <Title level={3}>{requirement.display_id}</Title>
          <Space wrap>
            <Tag>{statusConfig.label}</Tag>
            <Tag>{priorityConfig.label}</Tag>
          </Space>
        </div>
      </Space>
    </Col>
    
    {/* 右侧：操作按钮 */}
    <Col xs={24} lg={6} style={{ 
      textAlign: responsive.isMobile ? 'left' : 'right' 
    }}>
      {renderActionButtons()}
    </Col>
  </Row>
</div>
```

## 📚 开发者指南

### 如何在新组件中使用响应式

#### 1. 基础用法

```typescript
import { useResponsive } from '../hooks/useResponsive';

const MyComponent = () => {
  const responsive = useResponsive();
  
  return (
    <div style={{ 
      padding: responsive.isMobile ? 12 : 24 
    }}>
      {/* 组件内容 */}
    </div>
  );
};
```

#### 2. Modal宽度适配

```typescript
import { useResponsive, getResponsiveModalWidth } from '../hooks/useResponsive';

const MyModal = () => {
  const responsive = useResponsive();
  
  return (
    <Modal
      width={getResponsiveModalWidth(800, responsive)}
      // 自动适配：xs=95%, sm=90%, md+=800px
    />
  );
};
```

#### 3. 条件渲染

```typescript
const MyPage = () => {
  const responsive = useResponsive();
  
  return (
    <>
      {responsive.isMobile ? (
        <MobileView />
      ) : (
        <DesktopView />
      )}
    </>
  );
};
```

#### 4. 响应式值映射

```typescript
import { useResponsive, getResponsiveValue } from '../hooks/useResponsive';

const MyComponent = () => {
  const responsive = useResponsive();
  
  const columns = getResponsiveValue(
    {
      xs: 1,
      sm: 2,
      md: 3,
      lg: 4,
      xl: 5,
    },
    responsive
  );
  
  return <Row gutter={16}>{/* {columns}列布局 */}</Row>;
};
```

## 🎯 最佳实践

### 1. 移动优先设计
- 先设计移动端UI
- 逐步增强到桌面端
- 避免移动端功能缺失

### 2. 触控友好
- 按钮最小44x44px
- 充足的点击区域
- 避免悬停依赖

### 3. 性能优化
- 使用React.memo缓存组件
- 避免响应式Hook导致过多重渲染
- 条件渲染而非隐藏

### 4. 一致性
- 统一使用useResponsive
- 遵循断点定义
- 保持间距规范

### 5. 可访问性
- 保持语义化HTML
- 支持键盘导航
- 确保屏幕阅读器友好
