# 批量设置父任务功能验证与测试

## 功能概述
验证EnhancedProjectTaskManager组件中新增的批量设置父任务功能，确保用户可以同时选择多个任务并为它们设置新的父任务。

## 技术背景
- **核心组件**: TaskParentSelectorModal (弹窗选择器)
- **相关Hook**: useTaskParentSearch (父任务搜索逻辑)
- **API端点**: /projects/{projectId}/tasks/search-parents
- **文件路径**: 
  - frontend/src/components/TaskParentSelectorModal.tsx
  - frontend/src/hooks/useTaskParentSearch.ts

## 详细测试用例

### 1. 批量操作下拉菜单验证
- **测试目标**: 确认统一批量操作下拉菜单中包含更改父任务选项
- **前置条件**: 在项目任务列表中选择多个任务
- **验证步骤**:
  1. 打开项目任务管理页面
  2. 使用复选框选择2-5个任务
  3. 点击批量操作下拉菜单
  4. 确认更改父任务选项存在且可点击
- **预期结果**: 下拉菜单中显示更改父任务选项

### 2. TaskParentSelectorModal弹窗功能验证
- **测试目标**: 验证点击更改父任务能正确打开弹窗
- **验证步骤**:
  1. 选择多个任务后点击更改父任务
  2. 检查TaskParentSelectorModal是否正确打开
  3. 验证弹窗标题、搜索框、任务列表是否正常显示
  4. 检查智能推荐功能是否工作
- **预期结果**: 弹窗正常打开，显示可选父任务列表

### 3. 智能推荐算法验证
- **测试目标**: 验证智能推荐父任务功能
- **验证内容**:
  - 基于相似性的推荐（相同前缀、关键词匹配）
  - 基于任务层级的推荐（优先推荐高层级任务）
  - 基于任务状态的推荐（优先推荐进行中的任务）
  - 基于更新时间的推荐（优先推荐最近更新的任务）
- **预期结果**: 推荐列表按相关度排序，显示前3个最相关的父任务

### 4. 搜索和过滤功能验证
- **测试目标**: 验证父任务搜索功能
- **验证步骤**:
  1. 在搜索框中输入关键词
  2. 验证防抖搜索（300ms延迟）
  3. 测试不同关键词的搜索结果
  4. 验证搜索结果缓存（5分钟TTL）
- **预期结果**: 搜索功能正常，结果准确，性能良好

### 5. 父任务选择和验证
- **测试目标**: 验证父任务选择逻辑和验证规则
- **验证内容**:
  - 任务层级验证（最大层级限制）
  - 自引用防护（任务不能选择自己作为父任务）
  - 循环依赖检测
  - 权限验证
- **预期结果**: 所有验证规则正确执行，错误信息清晰

### 6. 批量更新操作验证
- **测试目标**: 验证批量更新父任务的数据库操作
- **验证步骤**:
  1. 选择父任务后点击确定
  2. 验证API调用是否正确
  3. 检查数据库更新是否成功
  4. 确认UI刷新显示最新状态
- **预期结果**: 所有选中任务的父任务都被正确更新

### 7. 错误处理和反馈验证
- **测试目标**: 验证各种错误场景的处理
- **测试场景**:
  - 网络错误
  - 权限不足
  - 数据验证失败
  - API超时
- **预期结果**: 所有错误都有适当的用户友好提示

### 8. UI交互和用户体验验证
- **测试目标**: 验证整体用户体验
- **验证内容**:
  - 加载状态指示器
  - 操作反馈动画
  - 响应式设计（移动端适配）
  - 键盘导航支持
- **预期结果**: 交互流畅，用户体验良好

## 测试数据准备
- 创建不同层级的测试任务（0-3级）
- 准备不同状态的任务（todo, in_progress, completed）
- 设置不同优先级和标签的任务
- 准备带有相似命名模式的任务群

## 性能要求
- 搜索响应时间 < 500ms
- 弹窗打开时间 < 200ms
- 批量更新操作 < 2s
- 缓存命中率 > 80%

## 浏览器兼容性
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## 验收标准
所有测试用例通过，用户可以顺利完成批量设置父任务的完整流程，系统稳定性和用户体验符合预期。
