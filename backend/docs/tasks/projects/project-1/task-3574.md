# 侧边栏添加快速操作区域

## 任务概述

为需求详情页面的侧边栏添加快速操作区域，提供便捷的功能入口。

## 实现内容

### 1. 新增处理函数

在 RequirementDetailPage.tsx 中添加了三个快速操作处理函数（lines 290-312）:

```typescript
/**
 * 处理复制链接
 */
const handleCopyLink = () => {
  const url = `${window.location.origin}/requirements/${requirementId}`;
  navigator.clipboard.writeText(url);
  message.success('链接已复制到剪贴板');
};

/**
 * 处理导出PDF
 */
const handleExportPDF = () => {
  window.print();
  message.info('请使用浏览器打印功能保存为PDF');
};

/**
 * 处理打印
 */
const handlePrint = () => {
  window.print();
};
```

## 功能特性

### 1. **转为任务** (条件显示)
- 仅在需求状态为"已批准"时显示
- 使用主色调按钮突出显示
- 点击后打开转换对话框

### 2. **复制链接**
- 一键复制需求详情页面URL到剪贴板
- 使用 `navigator.clipboard.writeText()` API
- 成功后显示提示消息

### 3. **导出PDF**
- 调用浏览器打印功能
- 用户可以选择"另存为PDF"
- 提供友好的操作提示

### 4. **打印**
- 直接调用浏览器打印对话框
- 可打印当前需求详情

## 用户体验

1. **位置合理**: 放在侧边栏统计信息下方，便于快速访问
2. **图标清晰**: 每个操作都有对应的图标，易于识别
3. **响应式**: 按钮自动适应容器宽度 (block)
4. **反馈及时**: 每个操作都有相应的用户反馈

## 技术要点

1. 使用 `navigator.clipboard` API 实现复制功能
2. 使用 `window.print()` 实现打印和PDF导出
3. 条件渲染确保"转为任务"按钮仅在适当时显示
4. 所有按钮使用 `block` 属性确保全宽显示
