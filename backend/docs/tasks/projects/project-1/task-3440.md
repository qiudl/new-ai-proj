# Task #3440: Phase 3.4: RequirementForm页面 - 需求创建和编辑表单

## 任务概述

实现统一的需求表单页面，支持创建和编辑两种模式，包含完整的表单字段、验证规则和文件上传功能。

## 实现内容

### 1. 统一表单页面 (src/pages/RequirementFormPage.tsx)

创建了一个统一的表单页面组件，根据URL参数自动判断是创建还是编辑模式。

**核心特性**:

1. **模式识别**:
   ```typescript
   const { id } = useParams<{ id: string }>();
   const isEditMode = !!id;
   ```
   - 创建模式: `/requirements/create`
   - 编辑模式: `/requirements/:id/edit`

2. **表单字段分组**:

   **基本信息**:
   - 需求标题 (必填, 1-500字符)
   - 需求描述 (可选, 最多5000字符)

   **关联和分类**:
   - 关联项目 (下拉选择, 可选)
   - 需求分类 (功能需求/缺陷修复/功能改进/性能优化/安全需求/其他)
   - 优先级 (必填, 低/中/高/紧急)
   - 截止日期 (DatePicker, 可选)

   **业务信息**:
   - 商业价值 (TextArea, 可选, 最多2000字符)
   - 预期结果 (TextArea, 可选, 最多2000字符)
   - 验收标准 (TextArea, 可选, 最多2000字符)

   **附件**:
   - 文件上传 (Dragger, 支持拖拽上传, 单个文件<10MB)

3. **表单验证规则**:
   ```typescript
   {
     title: [
       { required: true, message: '请输入需求标题' },
       { min: 1, max: 500, message: '标题长度应在1-500字符之间' }
     ],
     priority: [
       { required: true, message: '请选择优先级' }
     ]
   }
   ```

4. **文件上传功能**:
   - 支持拖拽上传
   - 限制单个文件大小 < 10MB
   - 最多上传10个文件
   - 自定义上传逻辑（当前为模拟上传）
   - 编辑模式自动回显已有附件

5. **数据加载和回填**:
   - 编辑模式自动加载需求详情
   - 表单字段自动回填
   - 附件列表自动展示
   - 日期格式转换 (string ↔ Dayjs)

6. **提交逻辑**:
   ```typescript
   if (isEditMode) {
     // 更新需求
     await requirementApi.updateRequirement(id, updateData);
     navigate(`/requirements/${id}`);
   } else {
     // 创建需求
     const newRequirement = await requirementApi.createRequirement(createData);
     navigate(`/requirements/${newRequirement.id}`);
   }
   ```

7. **用户交互优化**:
   - 加载状态显示 (Spin)
   - 提交状态显示 (Button loading)
   - 字符计数器 (showCount)
   - 重置表单按钮
   - 取消按钮 (返回列表或详情页)
   - 友好的错误提示

## 操作流程

### 创建流程:
1. 用户点击"创建需求"按钮
2. 导航到 `/requirements/create`
3. 填写表单
4. 点击"创建需求"按钮
5. 提交到API
6. 成功后跳转到需求详情页

### 编辑流程:
1. 用户在列表或详情页点击"编辑"
2. 导航到 `/requirements/:id/edit`
3. 自动加载需求详情
4. 表单自动回填
5. 修改表单
6. 点击"保存修改"按钮
7. 提交到API
8. 成功后返回需求详情页
