# Task #3449: Phase 4.4 E2E测试 - 需求创建到任务转换全流程

## 任务概述

为需求管理系统创建完整的端到端(E2E)测试，覆盖从需求创建、评论、审批、到任务转换的完整工作流。

## 完成内容

### 1. 测试工具类扩展 (test-helpers.ts)

创建了 `RequirementTestHelpers` 类，扩展了基础的 `TestHelpers`，提供需求管理专用的测试辅助方法：

#### 核心方法：

1. **createRequirement()** - 创建新需求
   - 参数：标题、描述、优先级
   - 返回：新创建的需求ID

2. **addComment()** - 添加评论（支持@提及用户）
   - 参数：需求ID、评论内容、被提及用户列表
   - 功能：自动处理@用户交互

3. **submitForReview()** - 提交需求审批
   - 参数：需求ID、审批人列表
   - 验证：状态变更为"审批中"

4. **approveRequirement()** - 批准需求
   - 参数：需求ID、审批意见
   - 验证：状态变更为"已批准"

5. **rejectRequirement()** - 拒绝需求
   - 参数：需求ID、拒绝原因
   - 验证：状态变更为"已拒绝"

6. **convertToTask()** - 将需求转换为任务
   - 参数：需求ID、任务详情（项目ID、标题、负责人）
   - 返回：新创建的任务ID

7. **linkToTask()** - 关联需求到现有任务
   - 参数：需求ID、任务ID
   - 验证：关联成功

8. **辅助验证方法**：
   - verifyRequirementStatus()
   - verifyRequirementDetails()
   - verifyMentionInComment()
   - getRequirementsList()
