
**WebSocket URL构建** (已修复):
```typescript
// 修复前：使用y-websocket默认URL格式
const wsProvider = new WebsocketProvider(wsUrl, fieldName, doc);

// 修复后：使用后端期望的查询参数格式
const queryParams = new URLSearchParams({
  room: fieldName,
  userId: currentUser.id.toString(),
  userName: currentUser.username || 'Anonymous',
  token: localStorage.getItem('token') || '',
});
const wsUrl = `${protocol}//${host}/ws/collaboration/${documentId}?${queryParams.toString()}`;
const wsProvider = new WebsocketProvider(wsUrl, '', doc);
```

**连接URL示例**:
```
ws://localhost:8080/ws/collaboration/1?room=description&userId=1&userName=admin&token=eyJ...
```

- `sync` - 文档同步状态
- `connection-error` - 连接错误
- `awareness.change` - 用户状态变化

## 技术亮点

### 1. 正确的WebSocket URL格式
解决了y-websocket库默认URL格式与后端实现不匹配的问题：
- 将room参数从路径移到查询参数
