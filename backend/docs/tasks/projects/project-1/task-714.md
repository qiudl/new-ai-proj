# 修复PDF打印中文内容空白问题及增加打印预览功能

## 任务描述
## 问题分析

### 根本原因
PDF导出使用jsPDF + times字体，但times字体不支持中文字符，导致中文内容无法显示

### 技术问题详情
1. **字体问题**：exportService.ts:332行设置了pdf.setFont('times', 'normal')，times字体不支持中文
2. **依赖问题**：html2pdf.js通过CDN加载，存在网络依赖风险
3. **用户需求冲突**：用户要求的字体大小、段间距、显示页面等高级定制化需求与中文字体支持存在技术冲突

## 解决方案设计

### 方案一：使用支持中文的字体
- 替换times字体为支持中文的字体（如NotoSansCJK、SimSun等）
- 评估：需要增加字体文件大小，但兼容性最好

### 方案二：使用html2canvas + jsPDF
- 将HTML内容转换为图片再生成PDF
- 评估：能完美保持样式，但文件大小较大，文字不可选择

### 方案三：使用Puppeteer生成PDF
- 服务端使用Puppeteer生成PDF
- 评估：质量最高，但需要服务端支持
