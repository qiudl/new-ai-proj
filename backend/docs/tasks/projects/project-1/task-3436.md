# Task #3436: Phase 2.3: 任务详情显示关联需求

## 任务概述

在任务详情页面添加"关联需求"标签页，用于显示与当前任务关联的所有需求信息。用户可以查看需求标题、状态、关联类型、关联人等详细信息，并可以快速导航到需求详情页面。

## 实现内容

### 1. 前端API服务层

#### 创建 `requirementService.ts` (新建文件)

**文件位置**: `frontend/src/services/requirementService.ts`

**核心功能**:
- 定义需求-任务关联数据类型
- 实现4个API服务方法

**主要方法**:

```typescript
// 1. 获取任务关联的需求列表
export async function getTaskRequirements(
  taskId: number,
  params?: {
    page?: number;
    page_size?: number;
    link_type?: RequirementTaskLinkType;
  }
): Promise<RequirementTaskListResponse>

// 2. 获取需求关联的任务列表
export async function getRequirementTasks(
  requirementId: number,
  params?: { ... }
): Promise<RequirementTaskListResponse>

// 3. 创建需求-任务关联
export async function linkTaskToRequirement(
  requirementId: number,
  taskId: number,
  linkType: RequirementTaskLinkType,
  linkComment?: string
): Promise<RequirementTaskLink>

// 4. 删除需求-任务关联
export async function unlinkTaskFromRequirement(
  requirementId: number,
  taskId: number
): Promise<void>
```

**数据类型定义**:

```typescript
// 链接类型枚举
export enum RequirementTaskLinkType {
  Manual = 'manual',      // 手动关联
  Converted = 'converted', // 需求转任务
  Related = 'related',     // 相关任务
}

// 需求-任务关联信息接口
export interface RequirementTaskLink {
  id: number;
  requirement_id: number;
  task_id: number;
  link_type: RequirementTaskLinkType;
  linked_by: number;
  link_comment: string;
  created_at: string;
  updated_at: string;
  
  // 关联数据
  requirement_title?: string;
  requirement_status?: string;
  task_title?: string;
  task_status?: string;
  linker_username?: string;
}
```
