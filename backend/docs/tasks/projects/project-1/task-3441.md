#### 2.3 Tab配置

**Tab 1: 基本信息 (key: 'basic')**
- 需求编号、所属项目、需求标题、需求描述
- 需求分类、提交人、评审人、时间信息
- 业务信息区块 (商业价值、预期结果、验收标准)
- 评审信息区块 (评审状态、评分、复杂度、预估工时)

**Tab 2: 评论 (key: 'comments')**
- 集成`CommentSection`组件
- 支持@用户提及
- 支持评论回复

- 实时评论统计

**Tab 3: 关联任务 (key: 'tasks')**
- 关联任务列表表格
- 显示任务标题、关联类型、任务状态、关联时间
- 支持点击跳转到任务详情
- 懒加载 (仅在切换到此Tab时加载)

**Tab 4: 操作历史 (key: 'history')**
- 时间线展示需求生命周期
- 需求创建 → 提交评审 → 评审完成 → 转换为任务
- 显示操作时间和操作人
- 支持跳转到转换后的任务

### 4. 交互功能

#### 4.1 页面操作

| 操作 | 触发条件 | 功能描述 |
|-----|---------|---------|
| 返回 | 点击返回按钮 | 跳转回需求列表页 |
| 编辑 | 点击编辑按钮 | 跳转到编辑页面 `/requirements/:id/edit` |
| 提交评审 | 仅草稿状态显示 | 将需求状态从Draft改为Pending |
| 归档 | 非已转换/已归档状态 | 归档需求 (需确认) |
| 删除 | 非已转换状态 | 删除需求 (需确认) |

#### 4.2 Tab切换

- **基本信息**: 默认激活，展示需求详细信息
- **评论**: 展示评论列表，支持新建、回复、编辑、删除
- **关联任务**: 懒加载关联任务列表
- **操作历史**: 展示需求生命周期时间线

#### 4.3 导航跳转

- 关联任务 → 任务详情页: `/projects/:projectId/tasks/:taskId`
- 转换后的任务 → 任务详情页: `/projects/:projectId/tasks/:convertedTaskId`
- 编辑 → 编辑页面: `/requirements/:id/edit`

## 代码亮点

### 1. 懒加载优化

关联任务仅在用户切换到对应Tab时才加载，减少初始加载时间：

```typescript
useEffect(() => {
  if (requirementId && activeTab === 'tasks') {
    loadLinkedTasks();
  }
}, [requirementId, activeTab]);
```

### 2. 状态驱动的UI

使用`useMemo`缓存配置对象，避免重复计算：

```typescript
const statusConfig = useMemo(() => {
  if (!requirement) return null;
  return REQUIREMENT_STATUS_CONFIG[requirement.status as RequirementStatus];
}, [requirement?.status]);
```

### 3. 条件渲染

根据需求状态动态显示/隐藏操作按钮：

```typescript
{requirement.status === RequirementStatus.Draft && (
  <Button type="primary" onClick={handleSubmit}>提交评审</Button>
)}
```

### 4. 集成CommentSection

复用已有的评论组件，传入自定义的服务适配器：

```typescript
<CommentSection<RequirementComment>
  entityId={requirementId}
  entityType="requirement"
  commentService={{
    list: (filters) => requirementCommentService.listComments(requirementId, filters),
    create: (data) => requirementCommentService.createComment(requirementId, { ... }),
    update: (commentId, data) => requirementCommentService.updateComment(...),
    delete: (commentId) => requirementCommentService.deleteComment(...),
  }}
  currentUserId={1}
  showStats={true}
  allowReply={true}
  allowMention={true}
/>
```

### 5. 时间线可视化

使用Ant Design Timeline组件展示操作历史，动态生成时间线项：

```typescript
<Timeline
  items={[
    { children: <div>需求创建 - {created_at}</div> },
    ...(submitted_at ? [{ children: <div>提交评审 - {submitted_at}</div> }] : []),
    ...(reviewed_at ? [{ children: <div>评审完成 - {reviewed_at}</div> }] : []),
    ...(converted_at ? [{ children: <div>转换为任务 - {converted_at}</div> }] : []),
```
