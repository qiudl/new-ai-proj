# 优化Dashboard首页

## 背景
Dashboard 首页存在以下问题：
1. 最近任务：任务项缺少执行日期时间，仅显示用时；未按最近时间倒序。
2. 任务树：项目和任务节点未显示。

## 目标与范围
- 完善“最近任务”区域：展示执行日期与时间；以最近执行时间倒序排列。
- 修复“任务树”区域：正确显示项目与任务节点，支持展开/收起与懒加载。
- 不涉及接口权限模型变更。

## 验收标准
### 最近任务
- 每条任务记录显示：任务名称、用时、执行开始时间（yyyy-MM-dd HH:mm）、执行结束时间或完成时间。
- 列表默认按最近一次执行时间倒序排列。
- 支持切换排序字段（执行开始时间/结束时间/用时），默认按结束时间倒序。
- 若任务无执行记录，显示“—”。

### 任务树
- 首屏展示项目根节点列表；点击可展开加载子节点。
- 节点类型区分：项目、任务、子任务；显示对应图标与名称。
- 懒加载：首次展开时请求对应节点下的子项；再次展开不重复请求（有缓存）。
- 展开/收起状态在会话内保持。
- 空态与错误态有明确提示。

## 技术实现建议
- 最近任务：后端返回execution_started_at, execution_finished_at 或 last_run_at 字段；前端格式化展示；排序逻辑由接口支持参数 sort_by=finished_at&order=desc。
- 任务树：提供 /projects 与 /projects/:id/tasks 分页接口；前端基于虚拟列表优化性能。

## 风险与注意事项
- 历史数据缺失时间字段时的兼容处理。
- 大量节点展开时的性能与接口限流。

## 里程碑
- M1：接口对齐与返回字段补全。
- M2：前端展示、懒加载与排序。
- M3：联调与回归测试。
