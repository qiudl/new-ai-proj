### 1. 前端性能测试 (requirement-performance.spec.ts)

创建了 **17个性能测试用例**，使用Playwright E2E框架，分为4个测试组：

#### 测试组1: @用户搜索性能测试 (5个测试)

**1.1 @提及搜索响应速度测试**
- 测试不同长度搜索词的响应时间
- 性能阈值: < 500ms
- 平均响应时间目标: < 300ms

- 确保防抖有效减少不必要的API请求
- 阈值: API调用次数 < 4次（对于6个字符输入）

**1.3 大量用户搜索性能**
- 测试系统中有大量用户时的搜索性能
- 验证分页/限制机制生效
- 响应时间阈值: < 1000ms
- 结果数量限制: ≤ 20个

**1.4 键盘导航性能**
- 测试下拉列表键盘导航的流畅性
- 平均导航响应时间: < 100ms
- 模拟连续5次方向键操作

**1.5 @提及渲染性能**
- 测试包含多个@提及的评论渲染
- 5个@提及的渲染时间: < 2000ms
- 验证所有提及正确高亮显示

```bash
# 运行功能测试
cd backend
go test -v ./tests -run TestUserSearchPerformance
go test -v ./tests -run TestCommentLoadingPerformance

# 运行基准测试
go test -bench=BenchmarkUserSearch -benchmem ./tests
go test -bench=BenchmarkCommentLoading -benchmem ./tests

# 运行所有性能测试
go test -v ./tests -run "Performance"

# 生成性能报告
go test -v -json ./tests -run "Performance" > performance-report.json
```

### 性能分析

```bash
# CPU profiling
go test -cpuprofile=cpu.prof -bench=. ./tests

go tool pprof cpu.prof
go tool pprof mem.prof
```
