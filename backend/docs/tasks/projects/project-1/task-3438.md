## 2. 实现细节

### 2.1 RequirementComment 类型定义

**文件位置**: `frontend/src/types/requirementComment.ts`

**核心类型**:

#### 评论枚举
```typescript
export enum RequirementCommentType {
  General = 'general',      // 一般评论
  Question = 'question',    // 提问
  Suggestion = 'suggestion', // 建议
  Approval = 'approval',    // 批准
}

export enum RequirementCommentStatus {
  Active = 'active',               // 活跃
  Deleted = 'deleted',             // 已删除
  PendingReview = 'pending_review', // 待审核
  Rejected = 'rejected',           // 已拒绝
}
```

#### 评论数据结构
```typescript
export interface RequirementComment {
  // 基本信息
  id: number;
  requirement_id: number;
  user_id: number;
  parent_comment_id?: number | null; // 回复支持

  // 内容
  content: string;
  comment_type: RequirementCommentType;
  attachments?: CommentAttachment[];

  // 特殊标记
  is_internal: boolean;  // 内部评论（客户不可见）
  is_pinned: boolean;    // 置顶评论

  // @用户提及
  mentioned_user_ids: number[];
  mentioned_users?: MentionedUser[];
  mentioned_count: number;

  // 回复信息
  replies_count?: number;
  replies?: RequirementComment[];
  
  // ... 其他字段
}
```

**配置对象**:
- `COMMENT_TYPE_CONFIG` - 评论类型标签配置（图标、颜色、文字）
- `COMMENT_STATUS_CONFIG` - 评论状态标签配置
- `REQUIREMENT_COMMENT_CONSTANTS` - 常量定义

**文件大小**: 240+ 行

### 2.2 RequirementCommentService

**文件位置**: `frontend/src/services/requirementCommentService.ts`

**核心API**:

1. **CRUD 操作**:
   - `createComment` - 创建评论
   - `listComments` - 获取评论列表（分页、筛选）
   - `getComment` - 获取单条评论
   - `updateComment` - 更新评论
   - `deleteComment` - 删除评论

2. **统计信息**:
   - `getCommentStats` - 获取评论统计

3. **便捷方法**:
   - `createReply` - 创建回复（自动设置 parent_comment_id）
   - `togglePin` - 置顶/取消置顶
   - `toggleInternal` - 切换内部/外部评论

**API 端点**:
- `GET /api/v1/requirements/:id/comments` - 评论列表
- `POST /api/v1/requirements/:id/comments` - 创建评论
- `PUT /api/v1/requirements/:id/comments/:commentId` - 更新评论
- `DELETE /api/v1/requirements/:id/comments/:commentId` - 删除评论
- `GET /api/v1/requirements/:id/comments/stats` - 统计信息

**文件大小**: 220+ 行

### 2.3 RequirementCommentItem 组件

**文件位置**: `frontend/src/components/RequirementComment/RequirementCommentItem.tsx`

**核心功能**:
1. 显示评论内容（使用 MarkdownRenderer，支持 @用户高亮）
2. 显示用户信息（头像、用户名、时间）
3. 显示评论类型标签（提问、建议、批准等）
4. 显示特殊标记（置顶、内部评论）
5. 显示提及的用户列表
6. 显示附件列表

**权限控制**:
- 评论作者可以编辑、删除自己的评论
- 系统用户可以删除任何评论、置顶评论
- 内部评论仅系统用户可见
