## 📊 @Mention功能实现

### 1. 提取@用户名

使用正则表达式提取评论内容中的@用户名:

```go
// models/requirement_comment.go
func (c *RequirementComment) ExtractMentionedUsernames() []string {
    re := regexp.MustCompile(`@([a-zA-Z0-9_-]+)`)
    matches := re.FindAllStringSubmatch(c.Content, -1)
    
    // 去重
    usernameMap := make(map[string]bool)
    for _, match := range matches {
        if len(match) > 1 {
            usernameMap[match[1]] = true
        }
    }
    
    usernames := []string{}
    for username := range usernameMap {
        usernames = append(usernames, username)
    }
    return usernames
}
```

### 2. 用户名解析

将用户名数组转换为用户ID数组:

```go
// Handler中的实现
```

```go
}
```

### 4. 用户信息填充

批量查询并填充被@用户的详细信息:

```go
// Repository实现 (database/requirement_comment_repository.go)
func (r *requirementCommentRepositoryImpl) PopulateMentionedUsers(
    ctx context.Context, 
    comments []*models.RequirementComment,
) error {
    // 1. 收集所有被提及的用户ID（去重）
    userIDMap := make(map[int]bool)
    for _, comment := range comments {
        for _, userID := range comment.MentionedUserIDs {
            userIDMap[userID] = true
        }
    }
    
    // 2. 批量查询用户信息
    query := `SELECT id, username, email FROM users WHERE id = ANY($1)`
    rows, err := r.executor.QueryContext(ctx, query, pq.Array(userIDs))
    
    // 3. 构建用户信息映射
    userInfoMap := make(map[int]*models.MentionedUser)
    for rows.Next() {
        // ... scan user info
        userInfoMap[id] = &models.MentionedUser{...}
    }
    
    // 4. 填充到每个评论
    for _, comment := range comments {
        comment.MentionedUsers = []models.MentionedUser{}
        for _, userID := range comment.MentionedUserIDs {
            if userInfo, ok := userInfoMap[userID]; ok {
                comment.MentionedUsers = append(comment.MentionedUsers, *userInfo)
            }
        }
    }
```
