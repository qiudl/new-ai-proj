## 问题描述
用户反馈：在ProjectTaskList组件中只看到"批量删除"按钮，没有看到"批量操作"按钮，导致无法进行批量修改父任务操作。

## 技术分析
基于 ProjectTaskList.tsx 第751-770行的代码分析：
- 批量操作按钮的显示条件可能存在问题
- selectedRowKeys状态管理可能存在异常
- 任务选择逻辑可能影响按钮显示

## 根本原因分析
1. **状态管理问题**: selectedRowKeys状态可能未正确更新
2. **组件渲染逻辑**: 批量操作按钮的条件渲染可能有bug
3. **事件处理**: 任务选择事件可能未正确触发状态更新

## 解决方案

### 前端修复方案
1. **检查按钮渲染条件**
   - 验证 selectedRowKeys.length > 0 的逻辑
   - 检查CSS样式是否影响按钮显示
   - 确认组件重新渲染机制

2. **状态管理修复**
   - 验证 onSelectChange 回调函数
   - 检查 Table 组件的 rowSelection 配置
   - 确保状态更新触发组件重渲染

3. **UI组件调试**
   - 使用浏览器开发者工具检查DOM结构
   - 验证按钮元素是否存在但被隐藏
   - 检查事件绑定是否正确

### MCP命令行替代方案
在前端修复期间，提供命令行工具进行批量父任务修改：
```bash
# 批量修改任务父任务
node batch-modify-parent.js --task-ids "123,124,125" --parent-id 100
```
