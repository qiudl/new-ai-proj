1. **批量创建优化**:
```go
func (r *notificationRepositoryImpl) BatchCreate(ctx context.Context, notifications []*models.Notification) error {
    if len(notifications) == 0 {
        return nil
    }
    
    // 获取底层*sql.DB用于事务
    db, ok := r.db.(*sql.DB)
    if !ok {
        return fmt.Errorf("invalid database connection type")
    }
    
    // 开启事务
    tx, err := db.BeginTx(ctx, nil)
    if err != nil {
        return fmt.Errorf("failed to begin transaction: %w", err)
    }
    defer tx.Rollback()
    
    // 使用预编译语句批量插入
    query := `INSERT INTO notifications (...) VALUES ($1, $2, ...) RETURNING id, created_at, is_read`
    stmt, err := tx.PrepareContext(ctx, query)
    if err != nil {
        return fmt.Errorf("failed to prepare statement: %w", err)
    }
    defer stmt.Close()
    
    // 批量插入所有通知
    for _, notification := range notifications {
        err := stmt.QueryRowContext(ctx, ...).Scan(&notification.ID, &notification.CreatedAt, &notification.IsRead)
        if err != nil {
            return fmt.Errorf("failed to create notification for user %d: %w", notification.UserID, err)
        }
    }
    
    return tx.Commit()
}
```

- 支持分页（page, page_size）

```go
func (s *notificationServiceImpl) CreateMentionNotifications(
    ctx context.Context,
    requirementID int,
    commentID int,
    mentionedUserIDs []int,
    mentionedByUserID int,
    mentionedByUsername string,
    commentContent string,
) error {
    // 移除自我提及（用户不应收到自己提及自己的通知）
    filteredUserIDs := []int{}
    for _, userID := range mentionedUserIDs {
        if userID != mentionedByUserID {
            filteredUserIDs = append(filteredUserIDs, userID)
        }
    }
    
    if len(filteredUserIDs) == 0 {
        return nil
    }
    
    // 截断评论内容（前100字符）
    truncatedContent := commentContent
    if len(truncatedContent) > 100 {
        truncatedContent = truncatedContent[:100] + "..."
    }
    
    // 创建通知元数据
    mentionData := &models.MentionNotificationData{
        RequirementID:       requirementID,
        CommentID:           commentID,
        MentionedBy:         mentionedByUserID,
        MentionedByUsername: mentionedByUsername,
        CommentContent:      truncatedContent,
    }
    
    // 为所有被提及用户创建通知
    notifications := make([]*models.Notification, 0, len(filteredUserIDs))
    title := fmt.Sprintf("@%s 在需求评论中提到了你", mentionedByUsername)
    message := fmt.Sprintf("%s 在需求评论中提到了你：%s", mentionedByUsername, truncatedContent)
    
    for _, userID := range filteredUserIDs {
        notification := &models.Notification{
            UserID:  userID,
            Type:    string(models.NotificationTypeMention),
            Title:   title,
            Message: &message,
            Metadata: mentionData.ToMetadata(),
        }
        notifications = append(notifications, notification)
    }
    
    return s.notificationRepo.BatchCreate(ctx, notifications)
}
```

**业务规则**:
- ✅ 过滤自我提及（用户不应收到自己@自己的通知）
- ✅ 内容截断（最多100字符，避免过长）
- ✅ 批量创建（避免N+1问题）
- ✅ 元数据结构化存储

## 关键技术决策

### 1. Repository模式选择

**问题**: 如何统一处理 `*sql.DB` 和 `*sql.Tx`？

**方案**: 使用 `db interface{}` + `getDB()` 辅助方法

```go
type notificationRepositoryImpl struct {
    db interface{} // 可以是 *sql.DB 或 *sql.Tx
}

func (r *notificationRepositoryImpl) getDB() DBExecutor {
    if tx, ok := r.db.(*sql.Tx); ok {
        return tx
    }
    return r.db.(*sql.DB)
}
```

**优点**:
- 支持事务和非事务场景
- 与现有代码库模式一致
- 类型安全

### 2. 自我提及过滤

**问题**: 用户是否应该收到自己@自己的通知？

**决策**: 不应该，应过滤掉

**实现**:
```go
filteredUserIDs := []int{}
for _, userID := range mentionedUserIDs {
    if userID != mentionedByUserID {
        filteredUserIDs = append(filteredUserIDs, userID)
    }
}
```

### 3. 内容截断策略

**问题**: 评论内容可能很长，如何处理？

**决策**: 截断到100字符 + "..."

**理由**:
- 通知消息应简洁
- 避免数据库存储压力
- 用户可点击查看完整内容

### 4. 失败处理策略

**问题**: 通知创建失败是否应该阻止评论创建？

**决策**: 不应该，仅记录警告日志

**实现**:
```go
if err != nil {
    log.Printf("Warning: Failed to create mention notifications: %v", err)
    // 不返回错误，继续执行
}
```

**理由**:
- 通知是辅助功能，不应阻塞主流程
- 用户体验优先
- 有日志可追溯问题
