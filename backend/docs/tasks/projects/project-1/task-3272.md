### 2.3 代码复用和可维护性

**1. 树结构扁平化函数** (复用性好):
```typescript
const flattenDepartments = (tree: Department[]): Department[] => {
  const result: Department[] = [];
  const flatten = (nodes: Department[], depth: number = 0) => {
    nodes.forEach(node => {
      result.push({ ...node, level: depth });
      if (node.children?.length) {
        flatten(node.children, depth + 1);
      }
    });
  };
  flatten(tree);
  return result;
};
```
