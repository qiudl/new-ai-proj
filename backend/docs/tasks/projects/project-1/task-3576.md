```typescript
const getFileType = (fileName: string): 'image' | 'pdf' | 'document' | 'other' => {
  const ext = fileName.split('.').pop()?.toLowerCase();
  if (!ext) return 'other';

  const imageExts = ['jpg', 'jpeg', 'png', 'gif', 'bmp', 'webp', 'svg'];
  const pdfExts = ['pdf'];
  const docExts = ['doc', 'docx', 'xls', 'xlsx', 'ppt', 'pptx'];

  if (imageExts.includes(ext)) return 'image';
  if (pdfExts.includes(ext)) return 'pdf';
  if (docExts.includes(ext)) return 'document';
  return 'other';
};
```

### 4. 文件类型图标函数

添加文件类型图标获取函数（lines 339-358）:

```typescript
const getFileIcon = (fileName: string) => {
  const type = getFileType(fileName);
  switch (type) {
    case 'image':
      return <FileImageOutlined style={{ color: '#52c41a' }} />;
    case 'pdf':
      return <FilePdfOutlined style={{ color: '#ff4d4f' }} />;
    case 'document':
      const ext = fileName.split('.').pop()?.toLowerCase();
      if (ext?.includes('xls')) {
        return <FileExcelOutlined style={{ color: '#52c41a' }} />;
      }
      return <FileWordOutlined style={{ color: '#1890ff' }} />;
    default:
      return <FileOutlined />;
  }
};
```

### 5. 预览处理函数

添加附件预览处理函数（lines 360-373）:

```typescript
const handlePreviewAttachment = (url: string, fileName: string) => {
  const type = getFileType(fileName);
  if (type === 'image' || type === 'pdf') {
    setPreviewUrl(url);
    setPreviewType(type);
    setPreviewVisible(true);
  } else {
    // 其他类型直接下载
    window.open(url, '_blank');
  }
};
```

## 功能特性

### 1. **智能文件类型识别**
- 支持图片格式：JPG, JPEG, PNG, GIF, BMP, WEBP, SVG
- 支持PDF格式
- 支持文档格式：DOC, DOCX, XLS, XLSX, PPT, PPTX
- 其他格式归类为未知类型

### 2. **文件类型图标**
- 图片文件：绿色FileImageOutlined图标
- PDF文件：红色FilePdfOutlined图标
- Excel文件：绿色FileExcelOutlined图标
- Word文件：蓝色FileWordOutlined图标
- 其他文件：默认FileOutlined图标

### 3. **预览功能**
- 图片预览：使用居中的img标签，自适应大小
- PDF预览：使用iframe嵌入显示
- 其他文件：直接在新窗口打开下载

### 4. **用户体验优化**
- 预览和下载按钮分离，操作清晰
- 只为支持预览的文件显示预览按钮
- Modal居中显示，支持destroyOnClose
- 图片和PDF使用不同的Modal宽度

## 视觉优化

1. **附件列表布局**：使用flex布局，左侧显示文件信息，右侧显示操作按钮
2. **文件名截断**：超长文件名使用ellipsis截断，防止溢出
3. **文件大小**：使用灰色小字显示，不干扰主要信息
4. **颜色区分**：不同文件类型使用不同颜色图标，易于识别

## 技术要点

1. **TypeScript类型安全**：使用联合类型定义文件类型
2. **条件渲染**：根据文件类型决定是否显示预览按钮
3. **响应式尺寸**：图片和PDF预览使用vh单位，适应不同屏幕
4. **资源释放**：使用destroyOnClose确保Modal关闭时清理资源
