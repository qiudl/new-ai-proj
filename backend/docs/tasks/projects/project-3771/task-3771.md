```typescript
function calculatePasswordStrength(password: string): number {
  let strength = 0;
  if (password.length >= 8) strength += 25;    // 基础长度
  if (password.length >= 12) strength += 25;   // 更长
  if (/[a-z]/.test(password) && /[A-Z]/.test(password)) strength += 25;  // 大小写
  if (/\d/.test(password)) strength += 12.5;   // 数字
  if (/[^a-zA-Z\d]/.test(password)) strength += 12.5;  // 特殊字符
  return Math.min(strength, 100);
}
```

## 🔒 安全特性

### 1. 令牌安全

- ✅ **随机性**: 32字节加密随机数生成
- ✅ **哈希存储**: SHA-256哈希，数据库泄露无法直接使用
- ✅ **短时效性**: 30分钟过期
- ✅ **一次性使用**: 使用后立即标记，防止重放攻击
- ✅ **自动撤销**: 新令牌创建时自动撤销旧令牌
- ✅ **URL安全**: Base64 URL编码，可安全放入URL

### 2. 速率限制

- ✅ **每用户限制**: 每小时最多3次重置请求
- ✅ **防止暴力攻击**: 超过限制返回429错误
- ✅ **时间窗口**: 滚动1小时窗口

### 3. 隐私保护

- ✅ **不泄露用户**: 邮箱不存在也返回成功
- ✅ **邮箱脱敏**: 日志和响应中脱敏邮箱地址
- ✅ **令牌不暴露**: Token字段在JSON中永不序列化

### 4. 密码安全

- ✅ **历史检查**: 防止重用最近5次密码
- ✅ **强度要求**: 至少8字符，大小写字母+数字
- ✅ **bcrypt哈希**: 密码安全存储
- ✅ **客户端验证**: 实时密码强度反馈

### 5. 审计和追踪

- ✅ **IP记录**: 请求IP和重置IP分别记录
- ✅ **UA记录**: User Agent记录
- ✅ **时间戳**: 创建、过期、使用时间完整记录
- ✅ **审计日志**: 所有操作记录到audit_logs表
- ✅ **状态跟踪**: pending → used/expired/revoked

```

  ↓ 输入邮箱

  ↓
PasswordResetService.CreateResetToken
  ↓ 查找用户
  ↓ 生成随机令牌 (32 bytes)
  ↓ SHA-256 哈希
  ↓ 创建数据库记录
  ↓ 数据库触发器撤销旧令牌
  ↓
EmailService.SendPasswordResetEmail
  ↓ 构建HTML邮件
  ↓ SMTP发送邮件
  ↓
用户邮箱 ← 收到重置链接
  ↓ 点击链接
  ↓
前端ResetPasswordPage (?token=ABC123)
```

### 重置密码流程

```
前端ResetPasswordPage
  ↓ 从URL获取token
  ↓ POST /api/v1/auth/verify-reset-token
  ↓
后端PasswordResetHandler.VerifyResetToken
  ↓ 哈希token
  ↓ 查找数据库
  ↓ 检查状态、过期时间
  ↓ 返回邮箱、过期时间
  ↓
前端显示重置表单
  ↓ 用户输入新密码
  ↓ 密码强度实时反馈
  ↓ POST /api/v1/auth/reset-password

  ↓ 验证令牌
  ↓ 检查密码历史
  ↓ bcrypt哈希新密码
  ↓ 开启数据库事务
  ↓   - 更新用户密码
  ↓   - 标记令牌已使用
  ↓   - 记录密码历史
  ↓ 提交事务
  ↓ 发送成功通知邮件
  ↓
前端显示成功页面
  ↓ 3秒后跳转登录
```
