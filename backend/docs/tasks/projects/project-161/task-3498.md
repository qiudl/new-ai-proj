# 物流商对接功能设计文档

## 对接策略

采用适配器模式，为不同物流商提供统一的接口抽象，便于扩展和维护。

## 接口抽象

```go
// LogisticsProvider 物流商接口
type LogisticsProvider interface {
    // CreateWaybill 创建运单
    CreateWaybill(shipment *model.Shipment) (*WaybillResponse, error)
    
    // GetTracking 获取物流轨迹
    GetTracking(trackingNo string) ([]TrackInfo, error)
    
    // CancelWaybill 取消运单
    CancelWaybill(trackingNo string) error
    
    // GetWaybillPDF 获取电子面单PDF
    GetWaybillPDF(trackingNo string) ([]byte, error)
}
```

## 顺丰API对接

```go
type SFProvider struct {
    AppID     string
    AppKey    string
    APIUrl    string
}

func (p *SFProvider) CreateWaybill(shipment *model.Shipment) (*WaybillResponse, error) {
    // 构建顺丰API请求
    req := SFWaybillRequest{
        OrderNo:     shipment.ShipmentNo,
        PayMethod:   1, // 寄方付
        Consignee: ConsigneeInfo{
            Name:    shipment.ReceiverName,
            Mobile:  shipment.ReceiverPhone,
            Province: shipment.ReceiverProvince,
            City:    shipment.ReceiverCity,
            County:  shipment.ReceiverDistrict,
            Address: shipment.ReceiverAddress,
        },
        Sender: SenderInfo{
            Name:    shipment.SenderName,
            Mobile:  shipment.SenderPhone,
            Province: shipment.SenderProvince,
            City:    shipment.SenderCity,
            County:  shipment.SenderDistrict,
            Address: shipment.SenderAddress,
        },
    }
    
    // 调用API
    resp, err := p.callAPI("/waybill/create", req)
    if err != nil {
        return nil, err
    }
    
    return &WaybillResponse{
        TrackingNo: resp.WaybillNo,
        WaybillURL: resp.PrintURL,
    }, nil
}
```
