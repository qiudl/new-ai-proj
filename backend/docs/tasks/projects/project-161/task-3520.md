# 商城对接模块API设计文档（Swagger）

## 1. API概览

商城对接模块提供以下API端点组：

- **平台管理API**: 电商平台配置管理
- **授权管理API**: 平台授权信息管理
- **商品映射API**: 商品映射关系管理
- **订单同步API**: 订单拉取和管理
- **库存同步API**: 库存推送和拉取
- **价格同步API**: 价格推送和拉取
- **同步任务API**: 定时同步任务管理
- **同步日志API**: 同步操作日志查询

## 2. 平台管理API

### 2.1 查询平台列表

```
GET /api/v1/mall/platforms
```

**Query参数:**
- `page`: 页码，默认1
- `page_size`: 每页数量，默认20
- `status`: 状态筛选（active, inactive）

**响应示例:**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "count": 3,
    "data": [
      {
        "id": 1,
        "platform_code": "taobao",
        "platform_name": "淘宝",
        "platform_type": "C2C",
        "api_endpoint": "https://eco.taobao.com/router/rest",
        "api_version": "2.0",
        "auth_type": "oauth2",
        "sync_interval": 300,
        "enable_product_sync": true,
        "enable_order_sync": true,
        "status": "active",
        "created_at": "2025-01-01T00:00:00Z"
      }
    ]
  }
}
```

### 2.2 创建平台配置

```
POST /api/v1/mall/platforms
```

**请求体:**
```json
{
  "platform_code": "taobao",
  "platform_name": "淘宝",
  "platform_type": "C2C",
  "api_endpoint": "https://eco.taobao.com/router/rest",
  "api_version": "2.0",
  "auth_type": "oauth2",
  "sync_interval": 300,
  "enable_product_sync": true,
  "enable_order_sync": true,
  "enable_inventory_sync": true,
  "enable_price_sync": true
}
```

### 2.3 更新平台配置

```
PUT /api/v1/mall/platforms/{id}
```

### 2.4 删除平台配置

```
DELETE /api/v1/mall/platforms/{id}
```

## 10. Webhook接收API

### 10.1 接收平台Webhook

```
POST /api/v1/mall/webhook/{platform_code}
```

**路径参数:**
- `platform_code`: 平台代码（taobao, jd, pdd）

**请求头:**
- `X-Signature`: 签名（用于验证请求来源）

**请求体:** 平台特定的Webhook数据

## 11. 通用响应格式

### 11.1 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

### 11.2 错误响应

```json
{
  "code": 400,
  "message": "参数错误: mapping_id不能为空",
  "data": null
}
```

### 11.3 错误码定义

- `0`: 成功
- `400`: 请求参数错误
- `401`: 未授权
- `403`: 禁止访问
- `404`: 资源不存在
- `500`: 服务器内部错误
- `1001`: 平台配置不存在
- `1002`: 授权已过期
- `1003`: 商品映射不存在
- `1004`: 同步失败
