## 七、测试最佳实践

### 7.1 单元测试规范

**命名规范**:
```go
func TestXxx(t *testing.T)           // 测试函数
func TestXxx_Success(t *testing.T)   // 成功场景
func TestXxx_Error(t *testing.T)     // 错误场景
func BenchmarkXxx(b *testing.B)      // 性能测试
```

**结构规范**:
```go
func TestCreate(t *testing.T) {
    // Arrange (准备)
    handler := NewHandler(...)
    req := &api.ReqCreateOrder{...}
    
    // Act (执行)
    resp, err := handler.Create(ctx, req)
    
    // Assert (断言)
    assert.NoError(t, err)
    assert.NotNil(t, resp)
    assert.Equal(t, "Draft", resp.Status)
}
```

### 7.2 集成测试规范

**测试隔离**:
- 每个测试独立运行
- 使用唯一标识（时间戳）避免冲突
- 测试后清理数据

**错误处理**:
- 检查HTTP状态码
- 记录响应详情
- 统计通过/失败数
