# 业绩报表统计设计文档

## 1. 概述

本文档定义业绩报表和统计分析功能，支持多维度业绩查询和可视化展示。

## 2. 统计维度

- 个人业绩统计
- 部门业绩统计  
- 时间维度统计（日/周/月/年）
- 排行榜统计

## 3. 核心查询

### 3.1 个人业绩查询

```go
// GetUserPerformance 获取个人业绩
func (b *StatisticsBiz) GetUserPerformance(db *gorm.DB, userID uint, startDate, endDate time.Time) (*RespUserPerformance, error) {
	var stats []model.PerformanceStatistics
	db.Where("user_id = ? AND stat_period >= ? AND stat_period <= ?", 
		userID, startDate.Format("2006-01-02"), endDate.Format("2006-01-02")).
		Order("stat_period ASC").
		Find(&stats)
	
	// 汇总数据
	total := &PerformanceSummary{}
	for _, stat := range stats {
		total.OrderCount += stat.OrderCount
		total.SalesAmount = total.SalesAmount.Add(stat.SalesAmount)
		total.CommissionAmount = total.CommissionAmount.Add(stat.CommissionAmount)
	}
	
	return &RespUserPerformance{
		Stats: stats,
		Total: total,
	}, nil
}
```

### 3.2 排行榜统计

```go
// GetRanking 获取业绩排行
func (b *StatisticsBiz) GetRanking(db *gorm.DB, statPeriod string, rankType string, limit int) ([]RankingItem, error) {
	var rankings []RankingItem
	
	orderBy := "sales_amount DESC"
	if rankType == "commission" {
		orderBy = "commission_amount DESC"
	} else if rankType == "profit" {
		orderBy = "profit_amount DESC"
	}
	
	db.Table("performance_statistics").
		Where("stat_period = ?", statPeriod).
		Select("user_id, user_name, sales_amount, commission_amount, profit_amount").
		Order(orderBy).
		Limit(limit).
		Scan(&rankings)
	
	return rankings, nil
}
```
