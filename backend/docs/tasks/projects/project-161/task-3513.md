# 业绩奖金模块API设计文档

## 1. API端点列表

### 1.1 佣金模板管理

```
POST   /api/v1/commission-templates      创建模板
GET    /api/v1/commission-templates      查询模板列表
GET    /api/v1/commission-templates/{id} 获取模板详情
PUT    /api/v1/commission-templates/{id} 更新模板
DELETE /api/v1/commission-templates/{id} 删除模板
POST   /api/v1/commission-templates/{id}/activate   激活模板
POST   /api/v1/commission-templates/{id}/deactivate 停用模板
```

### 1.2 业绩记录

```
GET /api/v1/performances           查询业绩记录
GET /api/v1/performances/{id}      获取业绩详情
GET /api/v1/performances/my        查询我的业绩
GET /api/v1/performances/statistics 业绩统计
```

### 1.3 佣金记录

```
GET /api/v1/commissions            查询佣金记录
GET /api/v1/commissions/{id}       获取佣金详情
GET /api/v1/commissions/my         查询我的佣金
POST /api/v1/commissions/calculate 手动触发计算
```

### 1.4 奖金发放

```
POST   /api/v1/distributions           创建发放批次
GET    /api/v1/distributions           查询发放批次列表
GET    /api/v1/distributions/{id}      获取发放批次详情
POST   /api/v1/distributions/{id}/confirm  确认发放批次
POST   /api/v1/distributions/{id}/execute  执行发放
POST   /api/v1/distributions/{id}/cancel   取消发放
```

### 1.5 统计报表

```
GET /api/v1/statistics/ranking     业绩排行榜
GET /api/v1/statistics/trend       业绩趋势
GET /api/v1/statistics/department  部门业绩
GET /api/v1/statistics/summary     业绩汇总
```

## 2. 示例请求

### 创建模板

```json
POST /api/v1/commission-templates
{
  "template_name": "销售阶梯佣金",
  "template_type": "sales",
  "calculate_method": "tiered",
  "effective_from": "2025-01-01",
  "rules": [
    {
      "rule_name": "0-1万",
      "rule_type": "tier",
      "min_amount": 0,
      "max_amount": 10000,
      "commission_rate": 0.03
    }
  ]
}
```

## 3. 总结

API设计遵循RESTful规范，支持完整的业绩奖金管理功能。
