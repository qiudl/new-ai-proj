# 库存统计报表设计文档

## 1. 概述

### 1.1 文档目的

本文档详细描述仓库库存模块的统计报表功能设计，包括库存汇总报表、库存流水报表、库存预警报表、库存周转分析、ABC分析、库龄分析等核心报表的API接口设计、数据模型、计算逻辑、可视化方案和导出功能。

### 1.2 设计原则

- **数据准确**: 基于实时库存数据，确保报表准确性
- **多维分析**: 支持按时间、仓库、品类、品牌等多维度统计
- **性能优化**: 使用物化视图、缓存、异步计算等优化手段
- **灵活导出**: 支持Excel、CSV、PDF等多种格式导出
- **可视化**: 提供图表数据，便于前端展示

### 1.3 适用范围

- 仓库管理人员：日常库存监控和分析
- 采购人员：库存水平分析，制定采购计划
- 销售人员：库存可用性分析
- 财务人员：库存价值统计和成本分析
- 高层管理：库存周转率、库存健康度分析

## 2. 报表分类

### 2.1 基础统计报表

#### 2.1.1 库存汇总报表

**报表说明**: 按仓库、SKU、品类、品牌等维度汇总库存数量和价值

**统计维度**:
- 按仓库汇总
- 按品类汇总
- 按品牌汇总
- 按SKU汇总

**统计指标**:
- SKU数量
- 库存总量
- 可用库存
- 预留库存
- 冻结库存
- 库存总价值（成本价）
- 库存总价值（零售价）

#### 2.1.2 库存明细报表

**报表说明**: 详细列出每个SKU的库存分布情况

**展示字段**:
- SKU信息（编码、名称、规格）
- 仓库信息
- 库位信息
- 批次信息
- 数量信息（总量、可用、预留）
- 批次有效期
- 库龄

#### 2.1.3 库存流水报表

**报表说明**: 记录库存变动明细，支持追溯

**展示字段**:
- 变动时间
- 变动类型（入库、出库、调拨、盘点）
- SKU信息
- 变动前数量
- 变动数量
- 变动后数量
- 单据号
- 操作人

### 2.2 预警分析报表

#### 2.2.1 库存预警报表

**报表说明**: 统计低库存、高库存、零库存、即将过期等预警情况

**预警类型**:
- 零库存预警
- 低库存预警（低于最小库存阈值）
- 高库存预警（高于最大库存阈值）
- 即将过期预警（30天内过期）
- 已过期预警

#### 2.2.2 呆滞库存报表

**报表说明**: 统计长期未动销的库存（如90天、180天无出库）

**统计指标**:
- 呆滞天数
- 呆滞数量
- 呆滞金额
- SKU信息
- 最后出库时间

### 2.3 分析类报表

#### 2.3.1 库存周转率报表

**报表说明**: 分析库存周转效率

**计算公式**:
```
库存周转率 = 一定时期内出库成本 / 平均库存成本
库存周转天数 = 365 / 库存周转率
```

**统计维度**:
- 按仓库统计
- 按品类统计
- 按品牌统计
- 按时间段统计（月、季、年）

#### 2.3.2 ABC分类报表

**报表说明**: 按销售额或出库量对SKU进行ABC分类

**分类标准**:
- A类：累计占比 0-80%（重点SKU）
- B类：累计占比 80-95%（一般SKU）
- C类：累计占比 95-100%（次要SKU）

**统计指标**:
- SKU数量及占比
- 出库数量及占比
- 出库金额及占比

#### 2.3.3 库龄分析报表

**报表说明**: 统计库存存放时长分布

**库龄区间**:
- 0-30天
- 31-60天
- 61-90天
- 91-180天
- 180天以上

**统计指标**:
- 各区间SKU数量
- 各区间库存数量
- 各区间库存金额

### 2.4 出入库统计报表

#### 2.4.1 入库统计报表

**报表说明**: 统计一定时期内的入库情况

**统计维度**:
- 按时间统计（日、周、月）
- 按入库类型统计（采购、退货、调拨、盘盈）
- 按仓库统计
- 按品类/品牌统计

**统计指标**:
- 入库单数
- 入库数量
- 入库金额

#### 2.4.2 出库统计报表

**报表说明**: 统计一定时期内的出库情况

**统计维度**:
- 按时间统计（日、周、月）
- 按出库类型统计（销售、调拨、退供、盘亏）
- 按仓库统计
- 按品类/品牌统计

**统计指标**:
- 出库单数
- 出库数量
- 出库金额

## 3. API接口设计

### 3.1 库存汇总报表

#### 3.1.1 库存汇总统计

**接口定义**:
```
GET /api/v1/reports/inventory-summary
```

**请求参数** (ReqInventorySummaryReport):
```go
type ReqInventorySummaryReport struct {
    // 筛选条件
    WarehouseID  *uint      `form:"warehouse_id"`
    CategoryID   *uint      `form:"category_id"`
    BrandID      *uint      `form:"brand_id"`
    
    // 分组维度
    GroupBy      string     `form:"group_by" binding:"required,oneof=warehouse category brand sku"` // 分组维度
    
    // 时间范围（用于库存快照）
    SnapshotDate *time.Time `form:"snapshot_date"` // 历史时间点的库存快照
}
```

**响应数据** (RespInventorySummaryReport):
```go
type RespInventorySummaryReport struct {
    ReportDate   time.Time              `json:"report_date"`
    TotalSKUs    int                    `json:"total_skus"`       // 总SKU数
    TotalQty     int                    `json:"total_qty"`        // 总库存量
    TotalValue   float64                `json:"total_value"`      // 总库存价值
    
    Groups       []InventorySummaryGroup `json:"groups"`
}

type InventorySummaryGroup struct {
    GroupKey     string  `json:"group_key"`       // 分组键（仓库ID/品类ID/品牌ID/SKU ID）
    GroupName    string  `json:"group_name"`      // 分组名称
    
    SKUCount     int     `json:"sku_count"`       // SKU数量
    TotalQty     int     `json:"total_qty"`       // 总库存量
    AvailableQty int     `json:"available_qty"`   // 可用库存
    ReservedQty  int     `json:"reserved_qty"`    // 预留库存
    FrozenQty    int     `json:"frozen_qty"`      // 冻结库存
    
    CostValue    float64 `json:"cost_value"`      // 成本价值
    RetailValue  float64 `json:"retail_value"`    // 零售价值
    
    Percentage   float64 `json:"percentage"`      // 占比
}
```

**业务逻辑**:
```go
func (b *ReportBiz) InventorySummary(db *gorm.DB, req *ReqInventorySummaryReport) (*RespInventorySummaryReport, error) {
    query := db.Model(&Inventory{}).
        Joins("JOIN skus ON skus.id = inventories.sku_id").
        Joins("JOIN spus ON spus.id = skus.spu_id")
    
    // 筛选条件
    if req.WarehouseID != nil {
        query = query.Where("inventories.warehouse_id = ?", *req.WarehouseID)
    }
    if req.CategoryID != nil {
        query = query.Where("spus.category_id = ?", *req.CategoryID)
    }
    if req.BrandID != nil {
        query = query.Where("spus.brand_id = ?", *req.BrandID)
    }
    
    // 历史快照（如果指定）
    if req.SnapshotDate != nil {
        // 查询历史快照表
        query = query.Where("snapshot_date = ?", *req.SnapshotDate)
    }
    
    // 计算总体统计
    var totalStats struct {
        TotalSKUs  int
        TotalQty   int
        TotalValue float64
    }
    
    query.Select(`
        COUNT(DISTINCT inventories.sku_id) as total_skus,
        SUM(inventories.quantity) as total_qty,
        SUM(inventories.quantity * skus.cost_price) as total_value
    `).Scan(&totalStats)
    
    resp := &RespInventorySummaryReport{
        ReportDate: time.Now(),
        TotalSKUs:  totalStats.TotalSKUs,
        TotalQty:   totalStats.TotalQty,
        TotalValue: totalStats.TotalValue,
        Groups:     []InventorySummaryGroup{},
    }
    
    // 按维度分组统计
    var groupResults []struct {
        GroupID      uint
        GroupName    string
        SKUCount     int
        TotalQty     int
        AvailableQty int
        ReservedQty  int
        FrozenQty    int
        CostValue    float64
        RetailValue  float64
    }
    
    switch req.GroupBy {
    case "warehouse":
        query.Joins("JOIN warehouses ON warehouses.id = inventories.warehouse_id").
            Select(`
                warehouses.id as group_id,
                warehouses.name as group_name,
                COUNT(DISTINCT inventories.sku_id) as sku_count,
                SUM(inventories.quantity) as total_qty,
                SUM(inventories.available_quantity) as available_qty,
                SUM(inventories.reserved_quantity) as reserved_qty,
                SUM(inventories.frozen_quantity) as frozen_qty,
                SUM(inventories.quantity * skus.cost_price) as cost_value,
                SUM(inventories.quantity * skus.market_price) as retail_value
            `).
            Group("warehouses.id, warehouses.name").
            Scan(&groupResults)
            
    case "category":
        query.Joins("JOIN product_categories ON product_categories.id = spus.category_id").
            Select(`
                product_categories.id as group_id,
                product_categories.name as group_name,
                COUNT(DISTINCT inventories.sku_id) as sku_count,
                SUM(inventories.quantity) as total_qty,
                SUM(inventories.available_quantity) as available_qty,
                SUM(inventories.reserved_quantity) as reserved_qty,
                SUM(inventories.frozen_quantity) as frozen_qty,
                SUM(inventories.quantity * skus.cost_price) as cost_value,
                SUM(inventories.quantity * skus.market_price) as retail_value
            `).
            Group("product_categories.id, product_categories.name").
            Scan(&groupResults)
            
    case "brand":
        query.Joins("JOIN brands ON brands.id = spus.brand_id").
            Select(`
                brands.id as group_id,
                brands.brand_name as group_name,
                COUNT(DISTINCT inventories.sku_id) as sku_count,
                SUM(inventories.quantity) as total_qty,
                SUM(inventories.available_quantity) as available_qty,
                SUM(inventories.reserved_quantity) as reserved_qty,
                SUM(inventories.frozen_quantity) as frozen_qty,
                SUM(inventories.quantity * skus.cost_price) as cost_value,
                SUM(inventories.quantity * skus.market_price) as retail_value
            `).
            Group("brands.id, brands.brand_name").
            Scan(&groupResults)
            
    case "sku":
        query.Select(`
            skus.id as group_id,
            CONCAT(skus.code, ' ', skus.name) as group_name,
            1 as sku_count,
            SUM(inventories.quantity) as total_qty,
            SUM(inventories.available_quantity) as available_qty,
            SUM(inventories.reserved_quantity) as reserved_qty,
            SUM(inventories.frozen_quantity) as frozen_qty,
            SUM(inventories.quantity * skus.cost_price) as cost_value,
            SUM(inventories.quantity * skus.market_price) as retail_value
        `).
        Group("skus.id, skus.code, skus.name").
        Scan(&groupResults)
    }
    
    // 转换结果并计算占比
    for _, gr := range groupResults {
        percentage := 0.0
        if totalStats.TotalQty > 0 {
            percentage = float64(gr.TotalQty) / float64(totalStats.TotalQty) * 100
        }
        
        resp.Groups = append(resp.Groups, InventorySummaryGroup{
            GroupKey:     fmt.Sprintf("%d", gr.GroupID),
            GroupName:    gr.GroupName,
            SKUCount:     gr.SKUCount,
            TotalQty:     gr.TotalQty,
            AvailableQty: gr.AvailableQty,
            ReservedQty:  gr.ReservedQty,
            FrozenQty:    gr.FrozenQty,
            CostValue:    gr.CostValue,
            RetailValue:  gr.RetailValue,
            Percentage:   percentage,
        })
    }
    
    return resp, nil
}
```

### 3.2 库存预警报表

#### 3.2.1 综合预警统计

**接口定义**:
```
GET /api/v1/reports/inventory-alerts
```

**请求参数** (ReqInventoryAlertReport):
```go
type ReqInventoryAlertReport struct {
    WarehouseID *uint  `form:"warehouse_id"`
    AlertType   string `form:"alert_type" binding:"omitempty,oneof=zero_stock low_stock high_stock near_expiry expired stagnant"` // 预警类型
}
```

**响应数据** (RespInventoryAlertReport):
```go
type RespInventoryAlertReport struct {
    ReportDate      time.Time         `json:"report_date"`
    
    // 预警统计
    ZeroStockCount  int               `json:"zero_stock_count"`   // 零库存SKU数
    LowStockCount   int               `json:"low_stock_count"`    // 低库存SKU数
    HighStockCount  int               `json:"high_stock_count"`   // 高库存SKU数
    NearExpiryCount int               `json:"near_expiry_count"`  // 即将过期批次数
    ExpiredCount    int               `json:"expired_count"`      // 已过期批次数
    StagnantCount   int               `json:"stagnant_count"`     // 呆滞库存SKU数
    
    // 预警明细
    Alerts          []InventoryAlert  `json:"alerts"`
}

type InventoryAlert struct {
    AlertType        string     `json:"alert_type"`          // zero_stock/low_stock/high_stock/near_expiry/expired/stagnant
    AlertLevel       string     `json:"alert_level"`         // warning/danger/critical
    
    SkuID            uint       `json:"sku_id"`
    SkuCode          string     `json:"sku_code"`
    SkuName          string     `json:"sku_name"`
    
    WarehouseID      uint       `json:"warehouse_id"`
    WarehouseName    string     `json:"warehouse_name"`
    
    CurrentQty       int        `json:"current_qty"`         // 当前库存
    MinThreshold     *int       `json:"min_threshold"`       // 最小阈值
    MaxThreshold     *int       `json:"max_threshold"`       // 最大阈值
    
    BatchNumber      string     `json:"batch_number,omitempty"`
    ExpiryDate       *time.Time `json:"expiry_date,omitempty"`
    DaysUntilExpiry  *int       `json:"days_until_expiry,omitempty"`
    
    LastOutboundDate *time.Time `json:"last_outbound_date,omitempty"` // 最后出库日期（呆滞）
    StagnantDays     *int       `json:"stagnant_days,omitempty"`      // 呆滞天数
}
```

**业务逻辑**:
```go
func (b *ReportBiz) InventoryAlerts(db *gorm.DB, req *ReqInventoryAlertReport) (*RespInventoryAlertReport, error) {
    resp := &RespInventoryAlertReport{
        ReportDate: time.Now(),
        Alerts:     []InventoryAlert{},
    }
    
    query := db.Model(&Inventory{}).
        Joins("JOIN skus ON skus.id = inventories.sku_id").
        Joins("JOIN spus ON spus.id = skus.spu_id").
        Joins("JOIN warehouses ON warehouses.id = inventories.warehouse_id")
    
    if req.WarehouseID != nil {
        query = query.Where("inventories.warehouse_id = ?", *req.WarehouseID)
    }
    
    // 1. 零库存预警
    if req.AlertType == "" || req.AlertType == "zero_stock" {
        var zeroStockAlerts []InventoryAlert
        db.Model(&Sku{}).
            Select(`
                'zero_stock' as alert_type,
                'critical' as alert_level,
                skus.id as sku_id,
                skus.code as sku_code,
                skus.name as sku_name,
                0 as current_qty
            `).
            Where(`skus.id NOT IN (
                SELECT DISTINCT sku_id FROM inventories 
                WHERE quantity > 0 AND deleted_at IS NULL
            )`).
            Scan(&zeroStockAlerts)
        
        resp.ZeroStockCount = len(zeroStockAlerts)
        resp.Alerts = append(resp.Alerts, zeroStockAlerts...)
    }
    
    // 2. 低库存预警
    if req.AlertType == "" || req.AlertType == "low_stock" {
        var lowStockAlerts []InventoryAlert
        query.Select(`
            'low_stock' as alert_type,
            'warning' as alert_level,
            skus.id as sku_id,
            skus.code as sku_code,
            skus.name as sku_name,
            warehouses.id as warehouse_id,
            warehouses.name as warehouse_name,
            SUM(inventories.quantity) as current_qty,
            skus.stock_alert_threshold as min_threshold
        `).
        Group("skus.id, skus.code, skus.name, warehouses.id, warehouses.name, skus.stock_alert_threshold").
        Having("SUM(inventories.quantity) < skus.stock_alert_threshold").
        Scan(&lowStockAlerts)
        
        resp.LowStockCount = len(lowStockAlerts)
        resp.Alerts = append(resp.Alerts, lowStockAlerts...)
    }
    
    // 3. 高库存预警
    if req.AlertType == "" || req.AlertType == "high_stock" {
        var highStockAlerts []InventoryAlert
        query.Select(`
            'high_stock' as alert_type,
            'warning' as alert_level,
            skus.id as sku_id,
            skus.code as sku_code,
            skus.name as sku_name,
            warehouses.id as warehouse_id,
            warehouses.name as warehouse_name,
            SUM(inventories.quantity) as current_qty,
            skus.stock_max_threshold as max_threshold
        `).
        Where("skus.stock_max_threshold IS NOT NULL").
        Group("skus.id, skus.code, skus.name, warehouses.id, warehouses.name, skus.stock_max_threshold").
        Having("SUM(inventories.quantity) > skus.stock_max_threshold").
        Scan(&highStockAlerts)
        
        resp.HighStockCount = len(highStockAlerts)
        resp.Alerts = append(resp.Alerts, highStockAlerts...)
    }
    
    // 4. 即将过期预警（30天内）
    if req.AlertType == "" || req.AlertType == "near_expiry" {
        var nearExpiryAlerts []InventoryAlert
        thirtyDaysLater := time.Now().AddDate(0, 0, 30)
        
        query.Select(`
            'near_expiry' as alert_type,
            'danger' as alert_level,
            skus.id as sku_id,
            skus.code as sku_code,
            skus.name as sku_name,
            warehouses.id as warehouse_id,
            warehouses.name as warehouse_name,
            inventories.quantity as current_qty,
            inventories.batch_number,
            inventories.expiry_date,
            DATEDIFF(inventories.expiry_date, NOW()) as days_until_expiry
        `).
        Where("inventories.expiry_date IS NOT NULL").
        Where("inventories.expiry_date > NOW()").
        Where("inventories.expiry_date <= ?", thirtyDaysLater).
        Scan(&nearExpiryAlerts)
        
        resp.NearExpiryCount = len(nearExpiryAlerts)
        resp.Alerts = append(resp.Alerts, nearExpiryAlerts...)
    }
    
    // 5. 已过期预警
    if req.AlertType == "" || req.AlertType == "expired" {
        var expiredAlerts []InventoryAlert
        query.Select(`
            'expired' as alert_type,
            'critical' as alert_level,
            skus.id as sku_id,
            skus.code as sku_code,
            skus.name as sku_name,
            warehouses.id as warehouse_id,
            warehouses.name as warehouse_name,
            inventories.quantity as current_qty,
            inventories.batch_number,
            inventories.expiry_date
        `).
        Where("inventories.expiry_date IS NOT NULL").
        Where("inventories.expiry_date < NOW()").
        Scan(&expiredAlerts)
        
        resp.ExpiredCount = len(expiredAlerts)
        resp.Alerts = append(resp.Alerts, expiredAlerts...)
    }
    
    // 6. 呆滞库存预警（90天无出库）
    if req.AlertType == "" || req.AlertType == "stagnant" {
        var stagnantAlerts []InventoryAlert
        ninetyDaysAgo := time.Now().AddDate(0, 0, -90)
        
        // 子查询：找出最后出库日期
        subQuery := db.Model(&OutboundOrderItem{}).
            Select("sku_id, MAX(outbound_orders.shipped_date) as last_outbound").
            Joins("JOIN outbound_orders ON outbound_orders.id = outbound_order_items.outbound_order_id").
            Where("outbound_orders.status = ?", "shipped").
            Group("sku_id")
        
        query.Select(`
            'stagnant' as alert_type,
            'warning' as alert_level,
            skus.id as sku_id,
            skus.code as sku_code,
            skus.name as sku_name,
            warehouses.id as warehouse_id,
            warehouses.name as warehouse_name,
            SUM(inventories.quantity) as current_qty,
            COALESCE(last_outbound_subq.last_outbound, inventories.created_at) as last_outbound_date,
            DATEDIFF(NOW(), COALESCE(last_outbound_subq.last_outbound, inventories.created_at)) as stagnant_days
        `).
        Joins("LEFT JOIN (?) as last_outbound_subq ON last_outbound_subq.sku_id = skus.id", subQuery).
        Group("skus.id, skus.code, skus.name, warehouses.id, warehouses.name, last_outbound_subq.last_outbound, inventories.created_at").
        Having("COALESCE(last_outbound_subq.last_outbound, inventories.created_at) < ?", ninetyDaysAgo).
        Scan(&stagnantAlerts)
        
        resp.StagnantCount = len(stagnantAlerts)
        resp.Alerts = append(resp.Alerts, stagnantAlerts...)
    }
    
    return resp, nil
}
```

### 3.3 库存周转率报表

#### 3.3.1 周转率统计

**接口定义**:
```
GET /api/v1/reports/inventory-turnover
```

**请求参数** (ReqInventoryTurnoverReport):
```go
type ReqInventoryTurnoverReport struct {
    // 时间范围
    StartDate   time.Time `form:"start_date" binding:"required"`
    EndDate     time.Time `form:"end_date" binding:"required"`
    
    // 筛选条件
    WarehouseID *uint     `form:"warehouse_id"`
    CategoryID  *uint     `form:"category_id"`
```

```go
func (b *ReportBiz) InventoryTurnover(db *gorm.DB, req *ReqInventoryTurnoverReport) (*RespInventoryTurnoverReport, error) {
    dayCount := int(req.EndDate.Sub(req.StartDate).Hours() / 24)
    
    resp := &RespInventoryTurnoverReport{
        StartDate: req.StartDate,
        EndDate:   req.EndDate,
        DayCount:  dayCount,
        Groups:    []TurnoverGroup{},
    }
    
    // 1. 计算平均库存（使用物化视图或定期快照）
    avgInventoryQuery := db.Model(&InventorySnapshot{}).
        Where("snapshot_date BETWEEN ? AND ?", req.StartDate, req.EndDate).
        Joins("JOIN skus ON skus.id = inventory_snapshots.sku_id").
        Joins("JOIN spus ON spus.id = skus.spu_id")
    
    // 2. 计算出库成本
    outboundQuery := db.Model(&OutboundOrderItem{}).
        Joins("JOIN outbound_orders ON outbound_orders.id = outbound_order_items.outbound_order_id").
        Joins("JOIN skus ON skus.id = outbound_order_items.sku_id").
        Joins("JOIN spus ON spus.id = skus.spu_id").
        Where("outbound_orders.status = ?", "shipped").
        Where("outbound_orders.shipped_date BETWEEN ? AND ?", req.StartDate, req.EndDate)
    
    // 应用筛选条件
    if req.WarehouseID != nil {
        avgInventoryQuery = avgInventoryQuery.Where("inventory_snapshots.warehouse_id = ?", *req.WarehouseID)
        outboundQuery = outboundQuery.Where("outbound_orders.warehouse_id = ?", *req.WarehouseID)
    }
    if req.CategoryID != nil {
        avgInventoryQuery = avgInventoryQuery.Where("spus.category_id = ?", *req.CategoryID)
        outboundQuery = outboundQuery.Where("spus.category_id = ?", *req.CategoryID)
    }
    if req.BrandID != nil {
        avgInventoryQuery = avgInventoryQuery.Where("spus.brand_id = ?", *req.BrandID)
        outboundQuery = outboundQuery.Where("spus.brand_id = ?", *req.BrandID)
    }
    
    // 按维度分组计算
    var groups []TurnoverGroup
    
    switch req.GroupBy {
    case "warehouse":
        // 计算各仓库的平均库存
        var avgInventories []struct {
            WarehouseID uint
            WarehouseName string
            AvgQty      float64
            AvgValue    float64
        }
        
        avgInventoryQuery.
            Joins("JOIN warehouses ON warehouses.id = inventory_snapshots.warehouse_id").
            Select(`
                warehouses.id as warehouse_id,
                warehouses.name as warehouse_name,
                AVG(inventory_snapshots.quantity) as avg_qty,
                AVG(inventory_snapshots.quantity * skus.cost_price) as avg_value
            `).
            Group("warehouses.id, warehouses.name").
            Scan(&avgInventories)
        
        // 计算各仓库的出库成本
        var outbounds []struct {
            WarehouseID  uint
            OutboundQty  int
            OutboundCost float64
        }
        
        outboundQuery.
            Select(`
                outbound_orders.warehouse_id,
                SUM(outbound_order_items.shipped_qty) as outbound_qty,
                SUM(outbound_order_items.shipped_qty * skus.cost_price) as outbound_cost
            `).
            Group("outbound_orders.warehouse_id").
            Scan(&outbounds)
        
        // 合并计算周转率
        outboundMap := make(map[uint]struct {
            Qty  int
            Cost float64
        })
        for _, ob := range outbounds {
            outboundMap[ob.WarehouseID] = struct {
                Qty  int
                Cost float64
            }{ob.OutboundQty, ob.OutboundCost}
        }
        
        for _, avg := range avgInventories {
            ob := outboundMap[avg.WarehouseID]
            
            turnoverRate := 0.0
            turnoverDays := 0.0
            
            if avg.AvgValue > 0 {
                turnoverRate = ob.Cost / avg.AvgValue
                if turnoverRate > 0 {
                    turnoverDays = float64(dayCount) / turnoverRate
                }
            }
            
            groups = append(groups, TurnoverGroup{
                GroupKey:          fmt.Sprintf("%d", avg.WarehouseID),
                GroupName:         avg.WarehouseName,
                AvgInventory:      avg.AvgQty,
                AvgInventoryValue: avg.AvgValue,
                OutboundQty:       ob.Qty,
                OutboundCost:      ob.Cost,
                TurnoverRate:      turnoverRate,
                TurnoverDays:      turnoverDays,
            })
        }
    
    // 其他维度（category, brand, sku）的实现类似
    }
    
    resp.Groups = groups
    
    // 计算平均值
    if len(groups) > 0 {
        totalTurnoverRate := 0.0
        for _, g := range groups {
            totalTurnoverRate += g.TurnoverRate
        }
        resp.AvgTurnoverRate = totalTurnoverRate / float64(len(groups))
        if resp.AvgTurnoverRate > 0 {
            resp.AvgTurnoverDays = float64(dayCount) / resp.AvgTurnoverRate
        }
    }
    
    return resp, nil
}
```

```go
func (b *ReportBiz) GenerateDailySnapshot(db *gorm.DB) error {
```
