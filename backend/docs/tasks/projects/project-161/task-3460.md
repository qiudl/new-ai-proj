# SKU管理模块产品需求文档 (PRD)

**项目**: Coolbuy 3.0 B2B电商平台  
**模块**: SKU管理 (Stock Keeping Unit Management)  
**版本**: v1.0  
**撰写日期**: 2025-01-06

---

## 1. 产品概述

### 1.1 功能简介
SKU管理模块负责商品最小库存单元的创建、编辑、查询和管理，实现商品规格（颜色、尺码等）的精细化管理，支持多维度属性组合、库存预警、批量导入等功能。

### 1.2 业务价值
- 实现商品规格的精细化管理，支持"李宁"、"百丽"、"波司登"等品牌复杂的鞋服规格
- 支持多价格体系（市场价、店铺价、销售价、客户价），满足B2B分销需求
- 实时库存预警，避免缺货和积压
- 批量导入功能，提升运营效率

### 1.3 用户角色
- **商品管理员**: 创建、编辑SKU信息，设置价格和库存
- **仓库管理员**: 更新库存数量，管理库存预警
- **采购人员**: 查看SKU库存状态，发起采购
- **销售人员**: 查询SKU价格和库存，进行订单处理

### 2.2 SKU属性管理

#### 2.2.1 功能描述
管理SKU的多维度属性值（颜色、尺码、材质等），支持动态属性组合。

#### 2.2.2 数据模型
```
PrdProductSkuItem (SKU属性值表)
├─ productSkuId: SKU ID
├─ attrId: 属性ID (如"颜色"、"尺码")
├─ attrItemId: 属性值ID (如"黑色"、"42码")
├─ attrValue: 属性值文本
└─ sortNo: 排序号
```

#### 2.2.3 业务规则
- 每个SKU必须至少有一个属性值（通常为颜色+尺码）
- 同一个SKU不能有重复的属性组合
- 支持最多5个维度的属性组合
- 属性值来源于"属性管理模块"的预定义值

#### 2.3.2 价格字段

|------|------|------|----------|
| marketPrice | Decimal | 市场价（吊牌价） | 手动设置 |
| shopPrice | Decimal | 店铺价 | 手动设置或按折扣计算 |
| salePrice | Decimal | 销售价 | 实时计算（调用定价模块） |
| customerPrice | Decimal | 普通客户价 | 手动设置 |

```
1. 客户专属价格
2. 客户等级价格
3. 品牌指导价
4. 统一销售价
```

## 3. 非功能性需求

### 3.1 性能要求
| 指标 | 目标值 |
|------|--------|
| SKU列表查询响应时间 | < 500ms (1万条数据) |
| SKU详情查询响应时间 | < 200ms |
| SKU创建/更新响应时间 | < 300ms |
| 批量导入速度 | > 500条/秒 |
| 并发支持 | 100 QPS |

### 3.2 数据一致性
- SKU与SPU的关联关系必须有效
- SKU与属性值的关联必须有效
- 库存扣减采用乐观锁机制（version字段）
- 删除SKU时检查订单关联

### 3.3 安全性
- 操作日志记录（谁、什么时间、做了什么）
- 权限控制（不同角色不同操作权限）
- 敏感数据脱敏（客户价格）

### 3.4 数据迁移
- 从cool_belle的`prd_product_sku`表迁移约5万条SKU数据
- 从cool_lining的`prd_product_sku`表迁移约3万条SKU数据
- 迁移数据包括: 基本信息、价格、库存、属性关联

## 4. 数据库设计

### 4.1 核心表结构

#### product_skus (SKU主表)
```sql
CREATE TABLE product_skus (
    id UUID PRIMARY KEY,
    spu_id UUID NOT NULL REFERENCES product_spus(id),
    sku_code VARCHAR(100) NOT NULL UNIQUE,
    sku_name VARCHAR(200) NOT NULL,
    bar_code VARCHAR(50),
    custom_code VARCHAR(50),
    size_code VARCHAR(20),
    color_code VARCHAR(50),
    market_price DECIMAL(15,2),
    shop_price DECIMAL(15,2),
    sale_price DECIMAL(15,2),
    customer_price DECIMAL(15,2),
    stocks DECIMAL(15,2) DEFAULT 0,
    virtual_stocks DECIMAL(15,2) DEFAULT 0,
    early_warning_number DECIMAL(15,2),
    early_warning_status BOOLEAN DEFAULT false,
    is_on_sale BOOLEAN DEFAULT true,
    status BOOLEAN DEFAULT true,
    is_delete BOOLEAN DEFAULT false,
    sort_no INTEGER,
    remark TEXT,
    version INTEGER DEFAULT 1,
    input_user_id UUID,
    input_user_name VARCHAR(50),
    input_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_user_id UUID,
    update_user_name VARCHAR(50),
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_spu_id (spu_id),
    INDEX idx_sku_code (sku_code),
    INDEX idx_bar_code (bar_code),
    INDEX idx_stocks (stocks),
    INDEX idx_status (status, is_on_sale)
);
```

#### product_sku_attributes (SKU属性值关联表)
```sql
CREATE TABLE product_sku_attributes (
    id UUID PRIMARY KEY,
    sku_id UUID NOT NULL REFERENCES product_skus(id) ON DELETE CASCADE,
    spu_id UUID NOT NULL REFERENCES product_spus(id),
    attribute_id UUID NOT NULL REFERENCES product_attributes(id),
    attribute_value_id UUID REFERENCES product_attribute_values(id),
    attribute_value VARCHAR(100),
    sort_no INTEGER,
    status BOOLEAN DEFAULT true,
    is_delete BOOLEAN DEFAULT false,
    version INTEGER DEFAULT 1,
    input_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_sku_id (sku_id),
    INDEX idx_spu_id (spu_id),
    INDEX idx_attribute_id (attribute_id),
    UNIQUE KEY uk_sku_attr (sku_id, attribute_id)
);
```

## 8. 附录

### 8.1 业务术语
- **SKU**: Stock Keeping Unit，库存量单位，是商品的最小销售单元
- **SPU**: Standard Product Unit，标准产品单元，是商品的抽象概念
- **吊牌价**: 商品的市场指导价
- **款色编码**: 款式+颜色的组合编码
