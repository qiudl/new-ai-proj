## 1. 服务概述

### 1.1 服务职责

**基础服务 (Platform Service)** 是PaaS平台的基础设施层,提供核心的平台能力:

- **系统管理 (SYS)**: 用户、角色、权限、菜单管理
- **认证服务 (AUTH)**: 登录认证、Token管理、会话管理
- **租户管理 (Tenant)**: 多租户隔离、租户配置、计费管理
- **通知服务 (Notification)**: 邮件、短信、站内信、WebSocket推送

### 1.2 技术栈

```yaml
语言框架:
  - Go 1.23+
  - Gin 1.10+ (HTTP框架)
  - GORM v2 (ORM)
  - gRPC 1.58+ (服务间通信)

认证授权:
  - JWT (JSON Web Token)
  - Casbin (RBAC权限管理)

数据存储:
  - PostgreSQL 16+ (主数据库)
  - Redis 7+ (缓存 + Session)

消息推送:
  - SMTP (邮件)
  - 阿里云SMS (短信)
  - WebSocket (实时推送)

服务发现:
  - Consul / Kubernetes Service
```

### 1.3 端口配置

```yaml
开发环境:
  HTTP API: 12100
  gRPC: 12101
  WebSocket: 12102
  Metrics: 12103
  Health: 12104

测试环境:
  HTTP API: 16100
  gRPC: 16101
  WebSocket: 16102
  Metrics: 16103
  Health: 16104

生产环境:
  HTTP API: 18100 (内网)
  gRPC: 18101 (内网)
  WebSocket: 18102 (内网)
  Metrics: 18103 (内网)
  Health: 18104 (内网)
```
