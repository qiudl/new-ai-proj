# 库存查询功能设计文档

## 1. 概述

### 1.1 文档目的

本文档详细描述仓库库存模块的库存查询功能设计，包括实时库存查询、多维度库存报表、可用库存校验、批次有效期查询等核心功能的API接口设计、业务逻辑、性能优化和权限控制。

### 1.2 设计原则

- **实时性**: 提供实时库存查询，确保数据准确性
- **多维度**: 支持按仓库、SKU、批次、地库位等多维度查询
- **高性能**: 查询响应时间 < 100ms (P95)，支持高并发
- **安全性**: 租户数据隔离，基于角色的数据权限控制
- **可扩展**: 支持自定义查询条件和报表导出

### 1.3 适用范围

- 仓库管理人员：查看仓库库存分布、库存明细
- 采购人员：查询可用库存，制定采购计划
- 销售人员：查询可售库存，确认订单可发货量
- 财务人员：查询库存价值，进行库存盘点

---

## 2. 库存查询核心场景

### 2.1 实时库存查询

**业务需求**: 
- 查询指定仓库或SKU的实时库存数量
- 区分总库存、可用库存、预留库存
- 支持批量SKU查询

**查询维度**:
```
- 按仓库ID查询: 查看仓库内所有SKU库存
- 按SKU ID查询: 查看SKU在所有仓库的分布
- 按仓库+SKU查询: 精确查询特定库存
- 批量SKU查询: 一次查询多个SKU的库存
```

### 2.2 可用库存校验

**业务需求**:
- 订单下单前校验库存是否充足
- 支持批量SKU可用量查询
- 考虑已预留库存（如未发货订单）

**计算逻辑**:
```
可用库存 = 总库存 - 预留库存 - 冻结库存
```

### 2.3 库存分布查询

**业务需求**:
- 查询SKU在不同仓库的库存分布
- 查询仓库内不同区域（Zone）、库位（Location）的库存分布
- 用于调拨决策和仓库优化

### 2.4 批次库存查询

**业务需求**:
- 查询指定批次号的库存
- 按生产日期、有效期筛选批次
- 查询近期到期批次（预警）

### 2.5 库存统计报表

**业务需求**:
- 库存汇总：按品类、品牌、仓库汇总
- 库存周转率统计
- 库存预警统计（低于最小库存、高于最大库存、即将过期）
- 库存价值统计（成本价 × 库存量）

## 3. API接口设计

### 3.1 实时库存查询

#### 3.1.1 按仓库查询库存列表

**接口定义**:
```
GET /api/v1/inventories
```

**请求参数** (ReqListInventory):
```go
type ReqListInventory struct {
    // 分页参数
    Page     int `form:"page" binding:"required,min=1"`
    PageSize int `form:"page_size" binding:"required,min=1,max=100"`
    
    // 筛选条件
    WarehouseID     *uint   `form:"warehouse_id"`      // 仓库ID
    WarehouseCode   string  `form:"warehouse_code"`    // 仓库编码
    SkuID           *uint   `form:"sku_id"`            // SKU ID
    SkuCode         string  `form:"sku_code"`          // SKU编码
    LocationID      *uint   `form:"location_id"`       // 库位ID
    BatchNumber     string  `form:"batch_number"`      // 批次号
    
    // 库存筛选
    MinQuantity     *int    `form:"min_quantity"`      // 最小库存量
    MaxQuantity     *int    `form:"max_quantity"`      // 最大库存量
    OnlyAvailable   bool    `form:"only_available"`    // 仅显示有库存的
    OnlyLowStock    bool    `form:"only_low_stock"`    // 仅显示低库存

}
```

**响应数据** (RespListInventory):
```go
type RespListInventory struct {

type InventoryDetail struct {

    IsOverStock       bool       `json:"is_over_stock"`      // 高于最大库存
```

**业务逻辑**:
```go
func (b *InventoryBiz) List(db *gorm.DB, req *ReqListInventory) (*RespListInventory, error) {
    var inventories []model.Inventory
    var count int64
    
    query := db.Model(&model.Inventory{}).
        Preload("Warehouse").
        Preload("Sku.Spu").
        Preload("Location")
    
    // 筛选条件
    if req.WarehouseID != nil {
        query = query.Where("warehouse_id = ?", *req.WarehouseID)
    }
    if req.WarehouseCode != "" {
        query = query.Joins("JOIN warehouses ON warehouses.id = inventories.warehouse_id").
            Where("warehouses.code = ?", req.WarehouseCode)
    }
    if req.SkuID != nil {
        query = query.Where("sku_id = ?", *req.SkuID)
    }
    if req.SkuCode != "" {
        query = query.Joins("JOIN skus ON skus.id = inventories.sku_id").
            Where("skus.code = ?", req.SkuCode)
    }
    if req.LocationID != nil {
        query = query.Where("location_id = ?", *req.LocationID)
    }
    if req.BatchNumber != "" {
        query = query.Where("batch_number = ?", req.BatchNumber)
    }
    
    // 库存数量筛选
    if req.MinQuantity != nil {
        query = query.Where("quantity >= ?", *req.MinQuantity)
    }
    if req.MaxQuantity != nil {
        query = query.Where("quantity <= ?", *req.MaxQuantity)
    }
    if req.OnlyAvailable {
        query = query.Where("available_quantity > 0")
    }
    if req.OnlyLowStock {
        // 关联SKU表获取最小库存阈值
        query = query.Joins("JOIN skus ON skus.id = inventories.sku_id").
            Where("inventories.quantity < skus.stock_alert_threshold")
    }
    
    // 排序
    sortBy := "updated_at"
    if req.SortBy != "" {
        sortBy = req.SortBy
    }
    sortOrder := "DESC"
    if req.SortOrder != "" {
        sortOrder = strings.ToUpper(req.SortOrder)
    }
    query = query.Order(fmt.Sprintf("%s %s", sortBy, sortOrder))
    
    // 计数
    query.Count(&count)
    
    // 分页查询
    offset := (req.Page - 1) * req.PageSize
    if err := query.Offset(offset).Limit(req.PageSize).Find(&inventories).Error; err != nil {
        return nil, err
    }
    
    // 转换为响应格式
    data := make([]InventoryDetail, len(inventories))
    for i, inv := range inventories {
        data[i] = b.toInventoryDetail(&inv)
    }
    
    return &RespListInventory{
        Count: int(count),
        Data:  data,
    }, nil
}

// 转换为详情格式，计算派生字段
func (b *InventoryBiz) toInventoryDetail(inv *model.Inventory) InventoryDetail {
    detail := InventoryDetail{
        ID:                inv.ID,
        WarehouseID:       inv.WarehouseID,
        SkuID:             inv.SkuID,
        LocationID:        inv.LocationID,
        BatchNumber:       inv.BatchNumber,
        Quantity:          inv.Quantity,
        AvailableQuantity: inv.AvailableQuantity,
        ReservedQuantity:  inv.ReservedQuantity,
        FrozenQuantity:    inv.FrozenQuantity,
        ProductionDate:    inv.ProductionDate,
        ExpiryDate:        inv.ExpiryDate,
        UpdatedAt:         inv.UpdatedAt,
    }
    
    // 关联数据
    if inv.Warehouse != nil {
        detail.WarehouseName = inv.Warehouse.Name
        detail.WarehouseCode = inv.Warehouse.Code
    }
    if inv.Sku != nil {
        detail.SkuCode = inv.Sku.Code
        detail.SkuName = inv.Sku.Name
        if inv.Sku.Spu != nil {
            detail.SpuName = inv.Sku.Spu.Name
        }
    }
    if inv.Location != nil {
        detail.LocationCode = inv.Location.Code
    }
    
    // 计算库存状态
    if inv.Sku != nil {
        detail.IsLowStock = inv.Quantity < inv.Sku.StockAlertThreshold
        detail.IsOverStock = inv.Quantity > inv.Sku.StockMaxThreshold
    }
    
    // 计算距离过期天数
    if inv.ExpiryDate != nil {
        daysUntil := int(time.Until(*inv.ExpiryDate).Hours() / 24)
        detail.DaysUntilExpiry = &daysUntil
        detail.IsNearExpiry = daysUntil <= 30 && daysUntil > 0
    }
    
    return detail
}
```

```go
type ReqBatchQueryInventory struct {
```

```go
type RespBatchQueryInventory struct {
    Data []SkuInventorySummary `json:"data"`
}

type SkuInventorySummary struct {
    SkuID             uint                    `json:"sku_id"`
    SkuCode           string                  `json:"sku_code"`
    SkuName           string                  `json:"sku_name"`
    
    // 汇总库存
    TotalQuantity     int                     `json:"total_quantity"`      // 总库存
    TotalAvailable    int                     `json:"total_available"`     // 总可用
    TotalReserved     int                     `json:"total_reserved"`      // 总预留
    
    // 分仓库明细
    Warehouses        []WarehouseInventory    `json:"warehouses"`
}

type WarehouseInventory struct {
    WarehouseID       uint   `json:"warehouse_id"`
    WarehouseName     string `json:"warehouse_name"`
    WarehouseCode     string `json:"warehouse_code"`
    Quantity          int    `json:"quantity"`
    AvailableQuantity int    `json:"available_quantity"`
    ReservedQuantity  int    `json:"reserved_quantity"`
}
```

**业务逻辑**:
```go
func (b *InventoryBiz) BatchQuery(db *gorm.DB, req *ReqBatchQueryInventory) (*RespBatchQueryInventory, error) {
    query := db.Model(&model.Inventory{}).
        Preload("Sku").
        Preload("Warehouse")
    
    // 按SKU ID或编码筛选
    if len(req.SkuIDs) > 0 {
        query = query.Where("sku_id IN ?", req.SkuIDs)
    } else if len(req.SkuCodes) > 0 {
        query = query.Joins("JOIN skus ON skus.id = inventories.sku_id").
            Where("skus.code IN ?", req.SkuCodes)
    }
    
    // 指定仓库
    if req.WarehouseID != nil {
        query = query.Where("warehouse_id = ?", *req.WarehouseID)
    }
    
    var inventories []model.Inventory
    if err := query.Find(&inventories).Error; err != nil {
        return nil, err
    }
    
    // 按SKU分组汇总
    summaryMap := make(map[uint]*SkuInventorySummary)
    for _, inv := range inventories {
        summary, exists := summaryMap[inv.SkuID]
        if !exists {
            summary = &SkuInventorySummary{
                SkuID:      inv.SkuID,
                Warehouses: []WarehouseInventory{},
            }
            if inv.Sku != nil {
                summary.SkuCode = inv.Sku.Code
                summary.SkuName = inv.Sku.Name
            }
            summaryMap[inv.SkuID] = summary
        }
        
        // 累加总量
        summary.TotalQuantity += inv.Quantity
        summary.TotalAvailable += inv.AvailableQuantity
        summary.TotalReserved += inv.ReservedQuantity
        
        // 添加仓库明细
        whInv := WarehouseInventory{
            WarehouseID:       inv.WarehouseID,
            Quantity:          inv.Quantity,
            AvailableQuantity: inv.AvailableQuantity,
            ReservedQuantity:  inv.ReservedQuantity,
        }
        if inv.Warehouse != nil {
            whInv.WarehouseName = inv.Warehouse.Name
            whInv.WarehouseCode = inv.Warehouse.Code
        }
        summary.Warehouses = append(summary.Warehouses, whInv)
    }
    
    // 转换为列表
    data := make([]SkuInventorySummary, 0, len(summaryMap))
    for _, summary := range summaryMap {
        data = append(data, *summary)
    }
    
    return &RespBatchQueryInventory{Data: data}, nil
}
```

**业务逻辑**:
```go
func (b *InventoryBiz) CheckAvailable(db *gorm.DB, req *ReqCheckAvailable) (*RespCheckAvailable, error) {
    query := db.Model(&model.Inventory{}).
        Select("SUM(available_quantity) as total_available").
        Preload("Sku").
        Preload("Warehouse")
    
    // SKU筛选
    if req.SkuID != nil {
        query = query.Where("sku_id = ?", *req.SkuID)
    } else if req.SkuCode != "" {
        query = query.Joins("JOIN skus ON skus.id = inventories.sku_id").
            Where("skus.code = ?", req.SkuCode)
    } else {
        return nil, errors.New("必须提供sku_id或sku_code")
    }
    
    // 仓库筛选
    if req.WarehouseID != nil {
        query = query.Where("warehouse_id = ?", *req.WarehouseID)
    }
    
    // 查询可用总量
    var result struct {
        TotalAvailable int
    }
    if err := query.Scan(&result).Error; err != nil {
        return nil, err
    }
    
    resp := &RespCheckAvailable{
        RequiredQuantity:  req.RequiredQty,
        AvailableQuantity: result.TotalAvailable,
        IsAvailable:       result.TotalAvailable >= req.RequiredQty,
    }
    
    if !resp.IsAvailable {
        resp.ShortageQuantity = req.RequiredQty - result.TotalAvailable
    }
    
    // 如果未指定仓库，返回各仓库可用量
    if req.WarehouseID == nil {
        var inventories []model.Inventory
        db.Model(&model.Inventory{}).
            Where("sku_id = ? AND available_quantity > 0", req.SkuID).
            Preload("Warehouse").
            Find(&inventories)
        
        for _, inv := range inventories {
            whAvail := WarehouseAvailability{
                WarehouseID:       inv.WarehouseID,
                AvailableQuantity: inv.AvailableQuantity,
            }
            if inv.Warehouse != nil {
                whAvail.WarehouseName = inv.Warehouse.Name
            }
            resp.Warehouses = append(resp.Warehouses, whAvail)
        }
    }
    
    // 获取SKU信息
    var sku model.Sku
    if err := db.First(&sku, req.SkuID).Error; err == nil {
        resp.SkuID = sku.ID
        resp.SkuCode = sku.Code
        resp.SkuName = sku.Name
    }
    
    return resp, nil
}
```

```go
func (b *InventoryBiz) Summary(db *gorm.DB, req *ReqInventorySummary) (*RespInventorySummary, error) {
    query := db.Model(&model.Inventory{}).
        Joins("JOIN skus ON skus.id = inventories.sku_id")
    
    if req.WarehouseID != nil {
        query = query.Where("inventories.warehouse_id = ?", *req.WarehouseID)
    }
    
    // 计算总体统计
    var totalStats struct {
        TotalSKUs      int
        TotalQuantity  int
        TotalAvailable int
        TotalValue     float64
    }
    
    query.Select(`
        COUNT(DISTINCT inventories.sku_id) as total_skus,
        SUM(inventories.quantity) as total_quantity,
        SUM(inventories.available_quantity) as total_available,
        SUM(inventories.quantity * skus.cost_price) as total_value
    `).Scan(&totalStats)
    
    resp := &RespInventorySummary{
        TotalSKUs:      totalStats.TotalSKUs,
        TotalQuantity:  totalStats.TotalQuantity,
        TotalAvailable: totalStats.TotalAvailable,
        TotalValue:     totalStats.TotalValue,
        Groups:         []SummaryGroup{},
    }
    
    // 按维度分组统计
    if req.GroupBy != "" {
        var groupResults []struct {
            GroupID   uint
            GroupName string
            SKUCount  int
            Quantity  int
            Available int
            Value     float64
        }
        
        switch req.GroupBy {
        case "category":
            query.Joins("JOIN spus ON spus.id = skus.spu_id").
                Joins("JOIN product_categories ON product_categories.id = spus.category_id").
                Select(`
                    product_categories.id as group_id,
                    product_categories.name as group_name,
                    COUNT(DISTINCT inventories.sku_id) as sku_count,
                    SUM(inventories.quantity) as quantity,
                    SUM(inventories.available_quantity) as available,
                    SUM(inventories.quantity * skus.cost_price) as value
                `).
                Group("product_categories.id, product_categories.name").
                Scan(&groupResults)
                
        case "brand":
            query.Joins("JOIN spus ON spus.id = skus.spu_id").
                Joins("JOIN brands ON brands.id = spus.brand_id").
                Select(`
                    brands.id as group_id,
                    brands.brand_name as group_name,
                    COUNT(DISTINCT inventories.sku_id) as sku_count,
                    SUM(inventories.quantity) as quantity,
                    SUM(inventories.available_quantity) as available,
                    SUM(inventories.quantity * skus.cost_price) as value
                `).
                Group("brands.id, brands.brand_name").
                Scan(&groupResults)
                
        case "warehouse":
            query.Joins("JOIN warehouses ON warehouses.id = inventories.warehouse_id").
                Select(`
                    warehouses.id as group_id,
                    warehouses.name as group_name,
                    COUNT(DISTINCT inventories.sku_id) as sku_count,
                    SUM(inventories.quantity) as quantity,
                    SUM(inventories.available_quantity) as available,
                    SUM(inventories.quantity * skus.cost_price) as value
                `).
                Group("warehouses.id, warehouses.name").
                Scan(&groupResults)
        }
        
        // 转换结果并计算占比
        for _, gr := range groupResults {
            percentage := 0.0
            if totalStats.TotalQuantity > 0 {
                percentage = float64(gr.Quantity) / float64(totalStats.TotalQuantity) * 100
            }
            
            resp.Groups = append(resp.Groups, SummaryGroup{
                GroupKey:          fmt.Sprintf("%d", gr.GroupID),
                GroupName:         gr.GroupName,
                SKUCount:          gr.SKUCount,
                Quantity:          gr.Quantity,
                AvailableQuantity: gr.Available,
                Value:             gr.Value,
                Percentage:        percentage,
            })
        }
    }
    
    return resp, nil
}
```

```go
// 缓存键设计
const (
    CacheKeyInventoryBySKU       = "inventory:sku:%d:warehouse:%d"     // 单SKU库存
    CacheKeyInventorySummary     = "inventory:summary:warehouse:%d"    // 仓库汇总
    CacheKeyAvailableQuantity    = "inventory:available:sku:%d"        // 可用量
    CacheTTLInventory            = 5 * time.Minute                     // 5分钟过期
)

// 缓存实现
func (b *InventoryBiz) GetInventoryCached(db *gorm.DB, skuID, warehouseID uint) (*InventoryDetail, error) {
    cacheKey := fmt.Sprintf(CacheKeyInventoryBySKU, skuID, warehouseID)
    
    // 1. 尝试从缓存读取
    var cached InventoryDetail
    if err := b.cache.Get(cacheKey, &cached); err == nil {
        return &cached, nil
    }
    
    // 2. 缓存未命中，查询数据库
    detail, err := b.GetInventory(db, skuID, warehouseID)
    if err != nil {
        return nil, err
    }
    
    // 3. 写入缓存
    b.cache.Set(cacheKey, detail, CacheTTLInventory)
    
    return detail, nil
}

// 缓存失效策略
func (b *InventoryBiz) InvalidateCache(skuID, warehouseID uint) {
    cacheKey := fmt.Sprintf(CacheKeyInventoryBySKU, skuID, warehouseID)
    b.cache.Delete(cacheKey)
    
    // 同时失效汇总缓存
    summaryKey := fmt.Sprintf(CacheKeyInventorySummary, warehouseID)
    b.cache.Delete(summaryKey)
}
```

**缓存更新时机**:
- 入库操作后：更新相关SKU+仓库的缓存
- 出库操作后：更新相关SKU+仓库的缓存
- 库存调整后：更新相关缓存
- 定时任务：每5分钟自动刷新热点数据
