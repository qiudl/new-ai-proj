# 实现批量操作功能（批量删除/批量改状态）

## 📋 任务概述

**优先级**: P0 - 高优先级  
**预估工时**: 2.5小时  
**负责模块**: 用户管理、角色管理  
**参考设计**: Zero-Admin-UI 批量操作工具栏

## 🎯 目标

充分利用表格的行选择（rowSelection）功能，提供批量删除、批量修改状态等操作，提升管理员的批量操作效率。

## 📊 现状分析

**当前实现**:
```tsx
// UserList.tsx 已有行选择配置
<AdvancedProTable
  rowSelection={{
    selectedRowKeys,
    onChange: setSelectedRowKeys,
  }}
/>
```

**存在问题**：
- ❌ 选中行后无后续操作
- ❌ 无批量删除功能
- ❌ 无批量修改状态功能
- ❌ 无选中数量提示

## 🔧 实现方案

### 步骤1: 扩展状态管理

```tsx
const UserList: React.FC = () => {
  const [selectedRowKeys, setSelectedRowKeys] = useState<React.Key[]>([]);
  const [selectedRows, setSelectedRows] = useState<User[]>([]); // 新增：保存选中的完整行数据
  
  // 批量操作的加载状态
  const [batchDeleting, setBatchDeleting] = useState(false);
  const [batchUpdating, setBatchUpdating] = useState(false);
```

### 步骤2: 实现批量删除功能

```tsx
  /**
   * 批量删除用户
   */
  const handleBatchDelete = () => {
    if (selectedRowKeys.length === 0) {
      message.warning('请先选择要删除的用户');
      return;
    }

    // 检查是否包含当前登录用户
    const currentUserId = getCurrentUserId(); // 假设有此函数获取当前用户ID
    if (selectedRowKeys.includes(currentUserId)) {
      message.error('不能删除当前登录用户');
      return;
    }

    // 构建确认信息
    const userNames = selectedRows.map(u => u.realName).slice(0, 5).join('、');
    const moreText = selectedRows.length > 5 ? ` 等${selectedRows.length}个用户` : '';

    Modal.confirm({
      title: '批量删除用户',
      icon: <ExclamationCircleOutlined style={{ color: '#ff4d4f' }} />,
      content: (
        <div>
          <p>确定要删除以下用户吗？删除后无法恢复。</p>
          <Alert
            message={`${userNames}${moreText}`}
            type="warning"
            showIcon
            style={{ marginTop: 12 }}
          />
        </div>
      ),
      okText: '确认删除',
      okType: 'danger',
      cancelText: '取消',
      onOk: async () => {
        setBatchDeleting(true);
        try {
          // 调用批量删除API
          await systemApi.batchDeleteUsers(selectedRowKeys as number[]);
          
          message.success(`成功删除 ${selectedRowKeys.length} 个用户`);
          
          // 清空选中状态
          setSelectedRowKeys([]);
          setSelectedRows([]);
          
          // 刷新表格
          tableRef.current?.reload();
          
          // 刷新统计数据
          fetchStatistics();
        } catch (error: any) {
          message.error(error.message || '批量删除失败，请重试');
        } finally {
          setBatchDeleting(false);
        }
      },
    });
  };
```

### 步骤3: 实现批量修改状态功能

```tsx
  /**
   * 批量修改用户状态
   */
  const handleBatchUpdateStatus = (status: UserStatus) => {
    if (selectedRowKeys.length === 0) {
      message.warning('请先选择要修改的用户');
      return;
    }

    // 检查是否包含当前登录用户且要禁用
    const currentUserId = getCurrentUserId();
    if (status === UserStatus.DISABLED && selectedRowKeys.includes(currentUserId)) {
      message.error('不能禁用当前登录用户');
      return;
    }

    const statusText = status === UserStatus.NORMAL ? '启用' : '禁用';
    const userNames = selectedRows.map(u => u.realName).slice(0, 5).join('、');
    const moreText = selectedRows.length > 5 ? ` 等${selectedRows.length}个用户` : '';

    Modal.confirm({
      title: `批量${statusText}用户`,
      icon: <ExclamationCircleOutlined style={{ color: status === UserStatus.DISABLED ? '#ff4d4f' : '#52c41a' }} />,
      content: (
        <div>
          <p>确定要将以下用户状态修改为"{statusText}"吗？</p>
          <Alert
            message={`${userNames}${moreText}`}
            type="info"
            showIcon
            style={{ marginTop: 12 }}
          />
        </div>
      ),
      okText: `确认${statusText}`,
      okType: status === UserStatus.DISABLED ? 'danger' : 'primary',
      cancelText: '取消',
      onOk: async () => {
        setBatchUpdating(true);
        try {
          // 调用批量更新API
          await systemApi.batchUpdateUserStatus(
            selectedRowKeys as number[], 
            status
          );
          
          message.success(`成功${statusText} ${selectedRowKeys.length} 个用户`);
          
          // 清空选中状态
          setSelectedRowKeys([]);
          setSelectedRows([]);
          
          // 刷新表格
          tableRef.current?.reload();
          
          // 刷新统计数据
          fetchStatistics();
        } catch (error: any) {
          message.error(error.message || `批量${statusText}失败，请重试`);
        } finally {
          setBatchUpdating(false);
        }
      },
    });
  };
```

### 步骤4: 渲染批量操作工具栏

```tsx
  return (
    <div style={{ padding: '24px' }}>
      {/* 统计卡片 */}
      <Row gutter={16} style={{ marginBottom: '16px' }}>
        {/* ... */}
      </Row>

      <Card>
        {/* 批量操作工具栏 */}
        {selectedRowKeys.length > 0 && (
          <Alert
            message={
              <Space size="middle">
                <span style={{ fontWeight: 500 }}>
                  已选择 <a style={{ fontWeight: 600 }}>{selectedRowKeys.length}</a> 项
                </span>
                <Button 
                  size="small" 
                  type="link"
                  onClick={() => {
                    setSelectedRowKeys([]);
                    setSelectedRows([]);
                  }}
                >
                  取消选择
                </Button>
                <Divider type="vertical" />
                <Button 
                  size="small" 
                  type="primary" 
                  danger 
                  icon={<DeleteOutlined />}
                  loading={batchDeleting}
                  onClick={handleBatchDelete}
                >
                  批量删除
                </Button>
                <Button 
                  size="small" 
                  icon={<CheckCircleOutlined />}
                  loading={batchUpdating}
                  onClick={() => handleBatchUpdateStatus(UserStatus.NORMAL)}
                >
                  批量启用
                </Button>
                <Button 
                  size="small" 
                  icon={<StopOutlined />}
                  loading={batchUpdating}
                  onClick={() => handleBatchUpdateStatus(UserStatus.DISABLED)}
                >
                  批量禁用
                </Button>
              </Space>
            }
            type="info"
            showIcon
            style={{ marginBottom: 16 }}
            closable
            onClose={() => {
              setSelectedRowKeys([]);
              setSelectedRows([]);
            }}
          />
        )}

        {/* 搜索表单 */}
        <SearchForm {...} />

        {/* 用户表格 */}
        <AdvancedProTable<User>
          ref={tableRef}
          columns={columns}
          request={fetchUserList}
          rowKey="id"
          rowSelection={{
            selectedRowKeys,
            onChange: (keys, rows) => {
              setSelectedRowKeys(keys);
              setSelectedRows(rows);
            },
            // 禁用当前登录用户的选择（可选）
            getCheckboxProps: (record) => ({
              disabled: record.id === getCurrentUserId(),
            }),
          }}
          // ...
        />
      </Card>
    </div>
  );
};
```

## 📝 后端API需求

### 1. 批量删除用户API

```typescript
// POST /api/v1/users/batch-delete
interface BatchDeleteRequest {
  ids: number[];
}

interface BatchDeleteResponse {
  success: number;  // 成功删除数量
  failed: number;   // 失败数量
  errors?: Array<{
    id: number;
    message: string;
  }>;
}
```

### 2. 批量更新状态API

```typescript
// POST /api/v1/users/batch-update-status
interface BatchUpdateStatusRequest {
  ids: number[];
  status: UserStatus;
}

interface BatchUpdateStatusResponse {
  success: number;
  failed: number;
  errors?: Array<{
    id: number;
    message: string;
  }>;
}
```

## ✅ 验收标准

1. ✅ 选中行后，顶部显示批量操作工具栏
2. ✅ 工具栏显示选中数量
3. ✅ 批量删除功能正常，有二次确认
4. ✅ 批量启用/禁用功能正常
5. ✅ 取消选择功能正常
6. ✅ 当前登录用户不能被批量删除或禁用
7. ✅ 操作完成后清空选中状态
8. ✅ 操作完成后刷新表格和统计数据
9. ✅ 错误情况有友好提示

## 🐛 边界情况处理

1. **选中为空**: 提示"请先选择要操作的用户"
2. **包含当前用户**: 禁用当前用户的复选框，或操作时提示
3. **API部分失败**: 显示成功数量和失败详情
4. **网络错误**: 显示错误信息，不清空选中状态
5. **权限不足**: 提示"权限不足，无法执行批量操作"
