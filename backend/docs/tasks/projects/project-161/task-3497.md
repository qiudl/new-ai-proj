# 物流跟踪功能设计文档

## 功能概述

物流跟踪功能提供实时的包裹位置和状态信息，通过对接物流商API或接收Webhook推送，自动更新物流轨迹。

## 核心功能

### 1. 同步物流轨迹

```go
// SyncTrackingInfo 同步物流轨迹
func (b *TrackingBiz) SyncTrackingInfo(db *gorm.DB, shipmentID uint) error {
    // 查询物流单
    shipment, err := b.shipmentStore.GetByID(db, shipmentID)
    if err != nil {
        return err
    }
    
    // 调用物流商API获取最新轨迹
    tracks, err := b.getTrackingFromProvider(shipment.ProviderCode, shipment.TrackingNo)
    if err != nil {
        return err
    }
    
    // 保存新轨迹
    for _, track := range tracks {
        // 检查是否已存在
        var exists int64
        db.Model(&model.ShipmentTrack{}).
            Where("shipment_id = ? AND track_time = ? AND description = ?", 
                shipmentID, track.TrackTime, track.Description).
            Count(&exists)
        
        if exists == 0 {
            newTrack := &model.ShipmentTrack{
                ShipmentID:  shipmentID,
                ShipmentNo:  shipment.ShipmentNo,
                TrackingNo:  shipment.TrackingNo,
                TrackStatus: track.Status,
                TrackTime:   track.Time,
                Location:    track.Location,
                Description: track.Description,
                DataSource:  "api",
                RawData:     track.RawJSON,
            }
            db.Create(newTrack)
        }
    }
    
    return nil
}
```

### 2. Webhook接收

```go
// HandleWebhook 处理物流商Webhook回调
func (h *TrackingHandler) HandleWebhook(c *gin.Context) {
    providerCode := c.Param("provider")
    
    // 验证签名
    if !b.verifyWebhookSignature(c, providerCode) {
        c.JSON(http.StatusUnauthorized, gin.H{"error": "签名验证失败"})
        return
    }
    
    // 解析回调数据
    var webhook WebhookData
    if err := c.ShouldBindJSON(&webhook); err != nil {
        c.JSON(http.StatusBadRequest, gin.H{"error": err.Error()})
        return
    }
    
    // 异步处理
    go b.processWebhook(webhook)
    
    c.JSON(http.StatusOK, gin.H{"success": true})
}
```

### 3. 定时同步任务

```go
// ScheduleSyncTask 定时同步物流轨迹
func (b *TrackingBiz) ScheduleSyncTask() {
    ticker := time.NewTicker(30 * time.Minute)
    defer ticker.Stop()
    
    for range ticker.C {
        // 查询需要同步的物流单（运输中的）
        var shipments []model.Shipment
        db.Where("status IN ?", []string{"shipped", "in_transit"}).
            Find(&shipments)
        
        for _, shipment := range shipments {
            b.SyncTrackingInfo(db, shipment.ID)
        }
    }
}
```

## 物流商API对接

### 顺丰API示例

```go
// GetSFTracking 获取顺丰物流轨迹
func (b *TrackingBiz) GetSFTracking(waybillNo string) ([]TrackInfo, error) {
    url := "https://bsp-oisp.sf-express.com/bsp-oisp/sfexpressService"
    
    // 构建请求参数
    params := map[string]interface{}{
        "waybillNoList": []string{waybillNo},
    }
    
    // 调用API
    resp, err := http.Post(url, "application/json", params)
    if err != nil {
        return nil, err
    }
    
    // 解析响应
    var result SFTrackingResponse
    json.NewDecoder(resp.Body).Decode(&result)
    
    return result.Tracks, nil
}
```
