# 售后模块API设计文档

## 1. 概述

本文档定义Coolbuy 3.0售后模块的RESTful API接口规范，基于Swagger/OpenAPI 3.0标准。

### 1.1 API基础信息

- **Base URL**: `http://localhost:7091/api/v1`
- **认证方式**: JWT Bearer Token
- **租户隔离**: Header `X-Tenant-ID`
- **响应格式**: JSON

### 1.2 通用响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

错误响应：
```json
{
  "code": 400,
  "message": "error message",
  "error": "detailed error"
}
```

## 2. API端点列表

### 2.1 售后单管理

#### 创建售后申请
```
POST /after-sales
```

**Request Body**:
```json
{
  "order_id": 123,
  "after_sales_type": "return_refund",
  "reason_type": "quality_issue",
  "reason_detail": "商品有破损",
  "items": [
    {
      "order_item_id": 456,
      "quantity": 1,
      "exchange_sku_id": 789
    }
  ],
  "images": ["https://example.com/image1.jpg"],
  "contact_phone": "13800138000",
  "refund_account": "支付宝账号"
}
```

**Response**:
```json
{
  "code": 201,
  "message": "创建成功",
  "data": {
    "after_sales_id": 1001,
    "after_sales_no": "AS20250106001",
    "status": "pending"
  }
}
```

#### 查询售后单列表
```
GET /after-sales?page=1&page_size=20&status=pending&after_sales_type=return_refund
```

**Query Parameters**:
- `page`: 页码（默认1）
- `page_size`: 每页数量（默认20）
- `status`: 状态筛选
- `after_sales_type`: 类型筛选
- `customer_id`: 客户ID筛选
- `order_no`: 订单号搜索
- `after_sales_no`: 售后单号搜索

**Response**:
```json
{
  "code": 200,
  "data": {
    "count": 100,
    "page": 1,
    "page_size": 20,
    "data": [
      {
        "id": 1001,
        "after_sales_no": "AS20250106001",
        "after_sales_type": "return_refund",
        "order_no": "ORD20250105001",
        "customer_name": "张三",
        "refund_amount": 299.00,
        "status": "pending",
        "applied_at": "2025-01-06T10:00:00Z"
      }
    ]
  }
}
```

#### 获取售后单详情
```
GET /after-sales/{id}
```

**Response**:
```json
{
  "code": 200,
  "data": {
    "id": 1001,
    "after_sales_no": "AS20250106001",
    "after_sales_type": "return_refund",
    "order_id": 123,
    "order_no": "ORD20250105001",
    "customer_name": "张三",
    "reason_type": "quality_issue",
    "reason_detail": "商品有破损",
    "refund_amount": 299.00,
    "actual_refund_amount": 299.00,
    "status": "pending",
    "approval_status": "pending",
    "items": [
      {
        "id": 2001,
        "sku_code": "SKU001",
        "sku_name": "李宁运动鞋",
        "quantity": 1,
        "refund_amount": 299.00
      }
    ],
    "images": [
      {
        "image_url": "https://example.com/image1.jpg",
        "image_type": "quality_issue"
      }
    ],
    "approvals": [],
    "refunds": [],
    "logistics": [],
    "logs": []
  }
}
```

#### 取消售后申请
```
POST /after-sales/{id}/cancel
```

**Request Body**:
```json
{
  "reason": "不需要退货了"
}
```

### 2.2 审批管理

#### 审批售后申请
```
POST /after-sales/{id}/approve
```

**Request Body**:
```json
{
  "action": "approve",
  "approval_remark": "同意退款",
  "approved_amount": 299.00,
  "deduction_amount": 0,
  "deduction_reason": ""
}
```

#### 获取待审批列表
```
GET /after-sales/pending-approvals?page=1&page_size=20
```

## 3. 错误码

| 错误码 | 说明 |
|-------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 409 | 状态冲突 |
| 500 | 服务器错误 |

```go
// @name Authorization

// @x-tenant-id-header X-Tenant-ID
```

## 5. 总结

本文档定义了售后模块的完整API接口，包括：

- ✅ **售后申请**: 创建、查询、取消
- ✅ **审批管理**: 审批、待审批列表
- ✅ **退货物流**: 物流提交、收货质检
- ✅ **退款管理**: 退款处理、退款查询
- ✅ **换货管理**: 换货申请、换货订单
- ✅ **操作日志**: 完整的操作记录

所有API遵循RESTful设计规范，支持多租户和JWT认证。
