### ⚠️ 编译问题（可修复）

执行 `go build ./...` 发现3个依赖问题：

#### 1. 缺少copier包
```
internal/product/biz/category.go:9:2: 
  no required module provides package github.com/jinzhu/copier
```
**原因**: biz层使用了copier进行对象复制  
**解决**: `go get github.com/jinzhu/copier`

#### 2. paas-common未在require中声明
```
internal/router/router.go:9:2: 
  module github.com/coolbuy/paas-common provides package 
  github.com/coolbuy/paas-common/pkg/common/metrics 
  and is replaced but not required
```
**原因**: router使用了paas-common，但go.mod中只有replace没有require  
**解决**: `go get github.com/coolbuy/paas-common`

#### 3. paas-common middleware包
```
internal/router/router.go:10:2: 
  module github.com/coolbuy/paas-common provides package 
  github.com/coolbuy/paas-common/pkg/common/middleware 
  and is replaced but not required
```
**原因**: 同上  
**解决**: 同上（一次go get即可）
