# 外部接口数据库Schema设计文档

## 1. 概述

外部接口模块负责与供应商、ERP系统、物流公司、支付平台等外部系统的数据交互。本文档定义相关的数据库表结构。

### 1.1 设计原则

- 多租户支持：使用PostgreSQL Schema隔离
- 多系统适配：支持多种外部系统类型
- 灵活配置：使用JSONB存储系统特定配置
- 可追溯：完整的调用日志和状态记录
- 高可用：重试机制和容错处理

### 1.2 核心表结构

```
external_systems       - 外部系统配置
api_credentials        - API凭证管理
api_endpoints          - API端点配置
supplier_mappings      - 供应商映射关系
erp_sync_records       - ERP同步记录
logistics_orders       - 物流订单
payment_transactions   - 支付交易记录
api_call_logs          - API调用日志
webhook_configs        - Webhook配置
webhook_logs           - Webhook日志
