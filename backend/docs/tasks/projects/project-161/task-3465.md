## 1. 页面结构总览

### 1.1 页面导航层级
```
商品管理
├─ SPU管理 (当前页)
├─ SKU管理
├─ 品类管理
├─ 属性管理
└─ 商品导入导出
```

### 1.2 核心页面
- **SPU列表页** (`/products/spu/list`)
- **SPU创建页** (`/products/spu/create`)
- **SPU编辑页** (`/products/spu/edit/:id`)
- **SPU详情页** (`/products/spu/detail/:id`)

### 2.3 表格列设计

| 列名 | 宽度 | 对齐 | 排序 | 说明 |
|------|------|------|------|------|
| 选择框 | 40px | 居中 | - | 支持批量选择 |
| 款号 | 120px | 居左 | ✓ | 可点击跳转详情 |
| 商品名称 | 200px | 居左 | ✓ | 可点击跳转详情，超长省略显示 |
| 品类 | 150px | 居左 | ✓ | 显示完整路径 |
| 品牌 | 100px | 居左 | ✓ | - |
| SKU数 | 80px | 居中 | ✓ | 可点击查看SKU列表 |
| 状态 | 100px | 居中 | ✓ | 显示启用/上架状态 |
| 创建时间 | 150px | 居中 | ✓ | YYYY-MM-DD HH:mm |
| 操作 | 180px | 居中 | - | 固定在右侧 |

## 6. 交互逻辑设计

### 6.1 表单验证逻辑

#### 6.1.1 实时验证规则

| 字段 | 验证时机 | 验证规则 | 错误提示 |
|------|----------|----------|----------|
| 款号 | 失去焦点 | 1. 必填<br>2. 长度2-50字符<br>3. 唯一性（异步校验） | "款号不能为空"<br>"款号长度为2-50字符"<br>"款号已存在" |
| 商品名称 | 输入时 | 1. 必填<br>2. 长度2-100字符 | "商品名称不能为空"<br>"商品名称最多100字符" |
| 品类 | 选择时 | 1. 必选 | "请选择商品品类" |
| 吊牌价 | 失去焦点 | 1. 必填<br>2. 数字<br>3. 大于0<br>4. 最多2位小数 | "吊牌价不能为空"<br>"吊牌价必须大于0"<br>"最多保留2位小数" |
| 商品主图 | 上传时 | 1. 至少1张<br>2. 最多5张<br>3. 单张≤5MB<br>4. 格式JPG/PNG | "请至少上传1张商品主图"<br>"最多上传5张图片"<br>"图片大小不能超过5MB"<br>"仅支持JPG/PNG格式" |

#### 6.1.2 提交验证流程

```
用户点击"保存"
    ↓
前端表单验证
    ├─ 验证失败 → 显示错误提示，聚焦到第一个错误字段
    └─ 验证成功 ↓
显示加载状态
    ↓
发送API请求
    ↓
后端验证
    ├─ 验证失败 → 返回错误信息 → 显示错误提示
    └─ 验证成功 ↓
保存数据
    ↓
返回成功
    ↓
显示成功提示 "商品创建成功"
    ↓
跳转到列表页 / 详情页
```

## 10. 组件库与技术栈建议

### 10.1 推荐组件库

- **UI框架**: Ant Design Vue / Element Plus
- **表格**: Ant Design Table (支持虚拟滚动)
- **表单**: Ant Design Form (支持复杂验证)
- **上传**: Ant Design Upload (支持拖拽、预览)
- **富文本**: TinyMCE / Quill
- **图片预览**: vue-photo-preview

### 10.2 交互组件

- **确认对话框**: Modal.confirm()
- **消息提示**: Message.success() / Message.error()
- **通知**: Notification
- **加载**: Spin / Skeleton
- **步骤条**: Steps
