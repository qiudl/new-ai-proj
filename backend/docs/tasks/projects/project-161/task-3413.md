#### 1.1 Asynq服务器配置 ✅
**文件**: `worker/internal/queue/asynq.go`

**核心功能**:
- 三个队列配置：export（导出）、batch（批量）、cleanup（清理）
- 并发控制：从配置文件读取 Concurrency
- 重试策略：基于配置的 RetryDelay 和重试次数
- 错误处理器：统一记录任务失败日志
- 定时调度器：支持cron表达式，使用Asia/Shanghai时区

```go
func NewAsynqServer(c config.Config) *asynq.Server {
    return asynq.NewServer(
        redisOpt,
        asynq.Config{
            Concurrency: c.Asynq.Concurrency,
            Queues: map[string]int{
                "export":  c.Asynq.Queues["export"],
                "batch":   c.Asynq.Queues["batch"],
                "cleanup": c.Asynq.Queues["cleanup"],
            },
            RetryDelayFunc: func(n int, err error, task *asynq.Task) time.Duration {
                return time.Duration(c.Asynq.RetryDelay) * time.Second * time.Duration(n)
            },
            ErrorHandler: asynq.ErrorHandlerFunc(func(ctx context.Context, task *asynq.Task, err error) {
                logx.Errorf("Task failed: type=%s, payload=%s, error=%v",
                    task.Type(), task.Payload(), err)
            }),
        },
    )
}
```

#### 2.1 批量任务处理器（BatchProcessor）🆕
**文件**: `worker/internal/processor/batch/batch_processor.go`

**核心功能**:
- ✅ 下载用户上传的Excel文件
- ✅ 解析Excel数据（支持ParseExcelFile）
- ✅ 并发处理每条记录（goroutine pool，默认5并发）
- ✅ 实时进度跟踪（每处理10条更新一次）
- ✅ 生成包含成功/失败明细的结果文件
- ✅ 上传结果到OSS

**处理流程**:
```
1. 更新任务状态为"处理中"（01）
2. 下载源文件到本地临时目录
3. 解析Excel文件，获取所有记录行
4. 使用goroutine pool并发处理：
   - Semaphore控制并发数（默认5）
   - 每条记录调用business-service API
   - 记录成功/失败结果
   - 每10条更新进度和剩余时间
5. 生成结果Excel文件（原始数据+处理状态+处理结果）
6. 上传结果文件到OSS（batch-results/{tenant_id}/{task_id}_result.xlsx）
7. 更新最终状态：
   - "02": 完全成功（failedCount=0）
   - "03": 完全失败（successCount=0）
   - "04": 部分成功（有成功也有失败）
8. 清理临时文件
```

**支持的任务类型**:
- `batch_update_image`: 批量更新商品图片
  - Excel格式: 商品编号 | 图片URL
  - 调用: `BusinessClient.BatchUpdateProductImage()`
  - 验证: 商品编号和图片URL不能为空

```go
func (g *fileGenerator) ParseExcelFile(filePath string) ([][]string, error) {
    f, err := excelize.OpenFile(filePath)
    if err != nil {
        return nil, fmt.Errorf("failed to open excel file: %w", err)
    }
    defer f.Close()

    sheets := f.GetSheetList()
    if len(sheets) == 0 {
        return nil, fmt.Errorf("no sheets found in excel file")
    }

    sheet := sheets[0]
    rows, err := f.GetRows(sheet)
    if err != nil {
        return nil, fmt.Errorf("failed to get rows: %w", err)
    }

    // 排除表头（第一行）
    if len(rows) <= 1 {
        return [][]string{}, nil
    }

    return rows[1:], nil
}
```

### 4. 主程序入口

**文件**: `worker/worker.go`

**核心流程**:
```go
func main() {
    // 1. 加载配置
    conf.MustLoad(*configFile, &c)
    
    // 2. 初始化服务上下文
    ctx := svc.NewServiceContext(c)
    
    // 3. 创建Asynq服务器
    srv := queue.NewAsynqServer(c)
    
    // 4. 注册任务处理器
    mux := asynq.NewServeMux()
    mux.HandleFunc(queue.TypeExportTask, exportProcessor.ProcessTask)
    mux.HandleFunc(queue.TypeBatchTask, batchProcessor.ProcessTask)
    mux.HandleFunc(queue.TypeCleanup, cleanupProcessor.ProcessCleanup)
    
    // 5. 创建并启动调度器
    scheduler := queue.NewAsynqScheduler(c)
    scheduler.Register("0 3 * * *", cleanupTask, asynq.Queue("cleanup"))
    scheduler.Start()
    
    // 6. 启动服务器
    srv.Run(mux)
    
    // 7. 优雅关闭
    scheduler.Shutdown()
}
```
