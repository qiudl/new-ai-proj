### 二、完整流程测试脚本

创建自动化测试脚本：

```bash
#!/bin/bash

# 二维码登录完整流程测试脚本
# test_qrcode_login.sh

set -e

API_BASE="http://localhost:8080/api/v1"
TOKEN="your-test-token-here"

echo "========================================="
echo "二维码登录完整流程测试"
echo "========================================="

# 1. 生成二维码
echo -e "\n[1/7] 生成二维码..."
GENERATE_RESPONSE=$(curl -s -X POST "$API_BASE/auth/qrcode/generate")
QRCODE_ID=$(echo $GENERATE_RESPONSE | jq -r '.qrcode_id')
echo "✓ 二维码ID: $QRCODE_ID"

# 2. 检查初始状态
echo -e "\n[2/7] 检查初始状态..."
CHECK_RESPONSE=$(curl -s -X GET "$API_BASE/auth/qrcode/check?qrcode_id=$QRCODE_ID")
STATUS=$(echo $CHECK_RESPONSE | jq -r '.status')
if [ "$STATUS" != "pending" ]; then
  echo "✗ 失败: 初始状态应为pending，实际为$STATUS"
  exit 1
fi
echo "✓ 初始状态正确: pending"

# 3. 扫描二维码
echo -e "\n[3/7] 扫描二维码..."
SCAN_RESPONSE=$(curl -s -X POST "$API_BASE/auth/qrcode/scan" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"qrcode_id\": \"$QRCODE_ID\"}")
USERNAME=$(echo $SCAN_RESPONSE | jq -r '.user_info.username')
echo "✓ 扫码成功，用户: $USERNAME"

# 4. 检查扫码后状态
echo -e "\n[4/7] 检查扫码后状态..."
CHECK_RESPONSE=$(curl -s -X GET "$API_BASE/auth/qrcode/check?qrcode_id=$QRCODE_ID")
STATUS=$(echo $CHECK_RESPONSE | jq -r '.status')
if [ "$STATUS" != "scanned" ]; then
  echo "✗ 失败: 扫码后状态应为scanned，实际为$STATUS"
  exit 1
fi
echo "✓ 扫码后状态正确: scanned"

# 5. 确认登录
echo -e "\n[5/7] 确认登录..."
CONFIRM_RESPONSE=$(curl -s -X POST "$API_BASE/auth/qrcode/confirm" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"qrcode_id\": \"$QRCODE_ID\", \"action\": \"confirm\"}")
MESSAGE=$(echo $CONFIRM_RESPONSE | jq -r '.message')
echo "✓ 确认成功: $MESSAGE"

# 6. 检查确认后状态
echo -e "\n[6/7] 检查确认后状态..."
CHECK_RESPONSE=$(curl -s -X GET "$API_BASE/auth/qrcode/check?qrcode_id=$QRCODE_ID")
STATUS=$(echo $CHECK_RESPONSE | jq -r '.status')
ACCESS_TOKEN=$(echo $CHECK_RESPONSE | jq -r '.access_token')
if [ "$STATUS" != "confirmed" ]; then
  echo "✗ 失败: 确认后状态应为confirmed，实际为$STATUS"
  exit 1
fi
if [ "$ACCESS_TOKEN" == "null" ] || [ -z "$ACCESS_TOKEN" ]; then
  echo "✗ 失败: 应返回access_token"
  exit 1
fi
echo "✓ 确认后状态正确: confirmed"
echo "✓ 已获取Token: ${ACCESS_TOKEN:0:20}..."

# 7. 验证二维码已被删除
echo -e "\n[7/7] 验证二维码已被删除..."
CHECK_RESPONSE=$(curl -s -X GET "$API_BASE/auth/qrcode/check?qrcode_id=$QRCODE_ID")
STATUS=$(echo $CHECK_RESPONSE | jq -r '.status')
if [ "$STATUS" != "expired" ]; then
  echo "⚠ 警告: 二维码应已被删除，状态应为expired"
fi
echo "✓ 二维码已清理"

echo -e "\n========================================="
echo "✓ 所有测试通过！"
echo "========================================="
```

**使用方法**：
```bash
chmod +x test_qrcode_login.sh
./test_qrcode_login.sh
```

### 三、安全性验证

#### 3.1 认证安全

**测试点1：未登录用户无法扫码**
```bash
# 不携带Token
curl -X POST http://localhost:8080/api/v1/auth/qrcode/scan \
  -H "Content-Type: application/json" \
  -d '{"qrcode_id": "test-id"}'
```
**预期**：返回401 Unauthorized

**测试点2：无效Token被拒绝**
```bash
curl -X POST http://localhost:8080/api/v1/auth/qrcode/scan \
  -H "Authorization: Bearer invalid-token" \
  -d '{"qrcode_id": "test-id"}'
```
**预期**：返回401 Unauthorized

#### 3.2 租户隔离

**测试点3：跨租户登录被拒绝**
```bash
# 使用租户A的用户扫描
# 然后使用租户B的用户确认
# 应该失败
```
**预期**：返回错误"跨租户登录被拒绝"

#### 3.3 状态流转安全

**测试点4：无效状态流转被拒绝**
```bash
# 尝试从pending直接到confirmed（跳过scanned）
curl -X POST http://localhost:8080/api/v1/auth/qrcode/confirm \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "qrcode_id": "$PENDING_QRCODE_ID",
    "action": "confirm"
  }'
```
**预期**：返回错误"二维码状态异常"

**测试点5：已确认的二维码无法重复使用**
```bash
# 对已confirmed的二维码再次调用check
curl -X GET "http://localhost:8080/api/v1/auth/qrcode/check?qrcode_id=$CONFIRMED_ID"
```
**预期**：返回expired或不存在

#### 3.4 时效性验证

**测试点6：过期二维码无法使用**
```bash
# 生成二维码后等待5分钟
sleep 300

# 尝试扫描
curl -X POST http://localhost:8080/api/v1/auth/qrcode/scan \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"qrcode_id": "$EXPIRED_ID"}'
```
**预期**：返回错误"二维码已过期"

#### 3.5 用户身份验证

**测试点7：用户身份不匹配被拒绝**
```bash
# 用户A扫描二维码
# 用户B尝试确认
```
**预期**：返回错误"用户身份不匹配"
