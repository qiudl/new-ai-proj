# 商城对接数据库Schema设计文档

## 1. 概述

本文档定义商城对接模块的数据库Schema设计，支持与淘宝、天猫、京东、拼多多等主流电商平台的数据同步功能。

### 1.1 设计原则

- 多租户支持：使用PostgreSQL Schema隔离
- 多平台支持：支持多个电商平台同时对接
- 灵活配置：使用JSONB存储平台特定配置
- 可追溯：完整的同步日志和状态记录
- 高性能：合理的索引和分区策略

### 1.2 核心表结构

```
mall_platforms         - 电商平台配置
mall_auth_configs      - 平台授权配置
product_sync_mappings  - 商品映射关系
order_sync_records     - 订单同步记录
inventory_sync_records - 库存同步记录
price_sync_records     - 价格同步记录
sync_tasks             - 同步任务队列
sync_logs              - 同步操作日志
```

## 2. 详细表结构设计

### 2.1 电商平台配置表 (mall_platforms)

存储支持的电商平台配置信息。

```go
package model

import (
	"time"
	"gorm.io/gorm"
)

// MallPlatform 电商平台配置
type MallPlatform struct {
	ID uint `gorm:"primaryKey;autoIncrement" json:"id"`
	
	// 平台基本信息
	PlatformCode string `gorm:"type:varchar(50);uniqueIndex;not null" json:"platform_code"` // taobao, tmall, jd, pdd
	PlatformName string `gorm:"type:varchar(100);not null" json:"platform_name"`             // 平台名称
	PlatformType string `gorm:"type:varchar(20);not null" json:"platform_type"`              // B2C, C2C, B2B
	
	// 接口配置
	ApiEndpoint   string `gorm:"type:varchar(500);not null" json:"api_endpoint"`    // API地址
	ApiVersion    string `gorm:"type:varchar(20)" json:"api_version"`               // API版本
	AuthType      string `gorm:"type:varchar(20);not null" json:"auth_type"`        // oauth2, api_key, app_secret
	
	// 同步配置
	SyncInterval     int    `gorm:"type:int;default:300" json:"sync_interval"`           // 同步间隔(秒)
	MaxRetryCount    int    `gorm:"type:int;default:3" json:"max_retry_count"`           // 最大重试次数
	TimeoutSeconds   int    `gorm:"type:int;default:30" json:"timeout_seconds"`          // 请求超时(秒)
	RateLimitPerMin  int    `gorm:"type:int;default:60" json:"rate_limit_per_min"`       // 每分钟请求限制
	
	// 功能开关
	EnableProductSync   bool `gorm:"default:true" json:"enable_product_sync"`     // 启用商品同步
	EnableOrderSync     bool `gorm:"default:true" json:"enable_order_sync"`       // 启用订单同步
	EnableInventorySync bool `gorm:"default:true" json:"enable_inventory_sync"`   // 启用库存同步
	EnablePriceSync     bool `gorm:"default:true" json:"enable_price_sync"`       // 启用价格同步
	
	// 扩展配置
	ConfigJSON string `gorm:"type:jsonb" json:"config_json"` // 平台特定配置
	
	Status    string         `gorm:"type:varchar(20);not null;default:'active';index" json:"status"` // active, inactive
	CreatedAt time.Time      `json:"created_at"`
	UpdatedAt time.Time      `json:"updated_at"`
	DeletedAt gorm.DeletedAt `gorm:"index" json:"-"`
	
	// 关联关系
	AuthConfigs []MallAuthConfig `gorm:"foreignKey:PlatformID" json:"auth_configs,omitempty"`
}

func (MallPlatform) TableName() string {
	return "mall_platforms"
}
```

**SQL DDL:**

```sql
CREATE TABLE mall_platforms (
    id SERIAL PRIMARY KEY,
    platform_code VARCHAR(50) UNIQUE NOT NULL,
    platform_name VARCHAR(100) NOT NULL,
    platform_type VARCHAR(20) NOT NULL,
    
    api_endpoint VARCHAR(500) NOT NULL,
    api_version VARCHAR(20),
    auth_type VARCHAR(20) NOT NULL,
    
    sync_interval INT DEFAULT 300,
    max_retry_count INT DEFAULT 3,
    timeout_seconds INT DEFAULT 30,
    rate_limit_per_min INT DEFAULT 60,
    
    enable_product_sync BOOLEAN DEFAULT true,
    enable_order_sync BOOLEAN DEFAULT true,
    enable_inventory_sync BOOLEAN DEFAULT true,
    enable_price_sync BOOLEAN DEFAULT true,
    
    config_json JSONB,
    
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,

CREATE INDEX idx_mall_platforms_status ON mall_platforms(status);
CREATE INDEX idx_mall_platforms_deleted_at ON mall_platforms(deleted_at);
```

### 2.2 平台授权配置表 (mall_auth_configs)

存储每个租户在各平台的授权信息。

```go
package model

import (
	"time"
	"gorm.io/gorm"
)

// MallAuthConfig 平台授权配置
type MallAuthConfig struct {
	ID uint `gorm:"primaryKey;autoIncrement" json:"id"`
	
	PlatformID uint   `gorm:"index;not null" json:"platform_id"`           // 平台ID
	ShopID     string `gorm:"type:varchar(100);index;not null" json:"shop_id"` // 店铺ID
	ShopName   string `gorm:"type:varchar(200);not null" json:"shop_name"`     // 店铺名称
	
	// OAuth2授权信息
	AppKey       string `gorm:"type:varchar(100);not null" json:"app_key"`       // 应用Key
	AppSecret    string `gorm:"type:varchar(200);not null" json:"app_secret"`    // 应用密钥(加密存储)
	AccessToken  string `gorm:"type:text" json:"access_token"`                   // 访问令牌
	RefreshToken string `gorm:"type:text" json:"refresh_token"`                  // 刷新令牌
	
	// 令牌有效期
	TokenExpiresAt        *time.Time `json:"token_expires_at"`         // 令牌过期时间
	RefreshTokenExpiresAt *time.Time `json:"refresh_token_expires_at"` // 刷新令牌过期时间
	
	// 授权范围
	AuthScope string `gorm:"type:text" json:"auth_scope"` // 授权权限范围
	
	// 卖家信息
	SellerID   string `gorm:"type:varchar(100);index" json:"seller_id"`   // 卖家ID
	SellerNick string `gorm:"type:varchar(200)" json:"seller_nick"`       // 卖家昵称
	
	// 扩展配置
	ExtraConfig string `gorm:"type:jsonb" json:"extra_config"` // 额外配置
	
	Status    string         `gorm:"type:varchar(20);not null;default:'active';index" json:"status"` // active, expired, revoked
	CreatedAt time.Time      `json:"created_at"`
	UpdatedAt time.Time      `json:"updated_at"`
	DeletedAt gorm.DeletedAt `gorm:"index" json:"-"`
	
	// 关联关系
	Platform *MallPlatform `gorm:"foreignKey:PlatformID" json:"platform,omitempty"`
}

func (MallAuthConfig) TableName() string {
	return "mall_auth_configs"
}
```

**SQL DDL:**

```sql
CREATE TABLE mall_auth_configs (
    id SERIAL PRIMARY KEY,
    platform_id INT NOT NULL REFERENCES mall_platforms(id),
    shop_id VARCHAR(100) NOT NULL,
    shop_name VARCHAR(200) NOT NULL,
    
    app_key VARCHAR(100) NOT NULL,
    app_secret VARCHAR(200) NOT NULL,
    access_token TEXT,
    refresh_token TEXT,
    
    token_expires_at TIMESTAMP,
    refresh_token_expires_at TIMESTAMP,
    
    auth_scope TEXT,
    
    seller_id VARCHAR(100),
    seller_nick VARCHAR(200),
    
    extra_config JSONB,
    
    status VARCHAR(20) NOT NULL DEFAULT 'active',
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP
);

CREATE INDEX idx_mall_auth_configs_platform_id ON mall_auth_configs(platform_id);
CREATE INDEX idx_mall_auth_configs_shop_id ON mall_auth_configs(shop_id);
CREATE INDEX idx_mall_auth_configs_seller_id ON mall_auth_configs(seller_id);
CREATE INDEX idx_mall_auth_configs_status ON mall_auth_configs(status);
CREATE INDEX idx_mall_auth_configs_deleted_at ON mall_auth_configs(deleted_at);
CREATE UNIQUE INDEX idx_mall_auth_configs_platform_shop ON mall_auth_configs(platform_id, shop_id) WHERE deleted_at IS NULL;
```

### 2.3 商品映射关系表 (product_sync_mappings)

存储内部商品与外部平台商品的映射关系。

```go
package model

import (
	"time"
	"gorm.io/gorm"
)

// ProductSyncMapping 商品同步映射
type ProductSyncMapping struct {
	ID uint `gorm:"primaryKey;autoIncrement" json:"id"`
	
	// 内部商品信息
	SpuID uint   `gorm:"index;not null" json:"spu_id"`      // 内部SPU ID
	SkuID uint   `gorm:"index" json:"sku_id"`               // 内部SKU ID
	SpuCode string `gorm:"type:varchar(100);index" json:"spu_code"` // SPU编码
	SkuCode string `gorm:"type:varchar(100);index" json:"sku_code"` // SKU编码
	
	// 外部平台信息
	PlatformID    uint   `gorm:"index;not null" json:"platform_id"`           // 平台ID
	ShopID        string `gorm:"type:varchar(100);index;not null" json:"shop_id"` // 店铺ID
	ExternalSpuID string `gorm:"type:varchar(100);index" json:"external_spu_id"`  // 外部商品ID
	ExternalSkuID string `gorm:"type:varchar(100);index" json:"external_sku_id"`  // 外部SKU ID
	
	// 映射类型
	MappingType string `gorm:"type:varchar(20);not null" json:"mapping_type"` // spu, sku
	SyncMode    string `gorm:"type:varchar(20);not null" json:"sync_mode"`    // auto, manual
	
	// 同步控制
	EnableSync       bool       `gorm:"default:true" json:"enable_sync"`        // 启用同步
	LastSyncAt       *time.Time `json:"last_sync_at"`                           // 最后同步时间
	LastSyncStatus   string     `gorm:"type:varchar(20)" json:"last_sync_status"` // success, failed, pending
	NextSyncAt       *time.Time `json:"next_sync_at"`                           // 下次同步时间
	
	// 同步内容控制
	SyncPrice     bool `gorm:"default:true" json:"sync_price"`     // 同步价格
	SyncInventory bool `gorm:"default:true" json:"sync_inventory"` // 同步库存
	SyncImages    bool `gorm:"default:true" json:"sync_images"`    // 同步图片
	SyncDesc      bool `gorm:"default:true" json:"sync_desc"`      // 同步描述
	
	// 映射规则
	MappingRules string `gorm:"type:jsonb" json:"mapping_rules"` // 映射规则配置
	
	Status    string         `gorm:"type:varchar(20);not null;default:'active';index" json:"status"` // active, inactive
	CreatedAt time.Time      `json:"created_at"`
	UpdatedAt time.Time      `json:"updated_at"`
	DeletedAt gorm.DeletedAt `gorm:"index" json:"-"`
	
	// 关联关系
	Platform *MallPlatform `gorm:"foreignKey:PlatformID" json:"platform,omitempty"`
	Spu      *Spu          `gorm:"foreignKey:SpuID" json:"spu,omitempty"`
	Sku      *Sku          `gorm:"foreignKey:SkuID" json:"sku,omitempty"`
}

func (ProductSyncMapping) TableName() string {
	return "product_sync_mappings"
}
```

## 5. 性能优化建议

### 5.1 分区表

- **order_sync_records**: 按月分区，提高历史订单查询性能
- **sync_logs**: 按周分区，便于日志归档和清理

### 5.2 定期维护

```sql
-- 清理3个月前的同步日志
DELETE FROM sync_logs WHERE created_at < NOW() - INTERVAL '3 months';

-- 归档6个月前的订单同步记录
INSERT INTO order_sync_records_archive SELECT * FROM order_sync_records WHERE created_at < NOW() - INTERVAL '6 months';
```

### 5.3 缓存策略

- 平台配置使用Redis缓存，减少数据库查询
- 商品映射关系使用本地缓存，提高同步性能
- Token信息使用Redis缓存，并设置自动过期
