# 任务 #3101: 创建Express模块目录结构

## 1. 任务概述

本任务是Phase 4.1.6 Product路由集成的第一个子任务，负责为Express（快递公司管理）模块创建标准的目录结构和基础文件框架。

## 2. Express模块业务范围

**Express模块** 负责快递公司的基础数据管理，属于业务主数据模块。

### 2.1 核心功能
- 快递公司列表查询（支持按编码、名称模糊查询）
- 创建快递公司
- 更新快递公司信息
- 删除快递公司
- 获取单个快递公司详情
- 获取组件数据（用于下拉选择器）

### 2.2 数据结构
```go
type Express struct {
    ID           uint           // 主键ID
    Name         string         // 快递公司名称
    Code         string         // 快递公司编码（唯一索引，自动生成）
    ExternalCode string         // 外部系统编码
    Status       int            // 状态: 0-禁用, 1-启用
    SortNumber   uint           // 排序号
    CreatedAt    time.Time      // 创建时间
    UpdatedAt    time.Time      // 更新时间
    DeletedAt    gorm.DeletedAt // 软删除时间
}
```

### 2.3 API接口（待实现）
- `GET /api/v1/express` - 列表查询
- `POST /api/v1/express` - 创建
- `GET /api/v1/express/:id` - 获取详情
- `PUT /api/v1/express/:id` - 更新
- `DELETE /api/v1/express/:id` - 删除
- `GET /api/v1/express/comp` - 组件数据
