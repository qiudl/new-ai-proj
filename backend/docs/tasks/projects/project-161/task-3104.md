### 4. API路由清单

Express模块提供以下6个HTTP接口：

| 方法 | 路径 | 功能 | Handler |
|------|------|------|---------|
| GET | /api/v1/express | 列表查询（支持分页和模糊搜索） | List |
| POST | /api/v1/express | 创建快递公司 | Create |
| GET | /api/v1/express/comp | 获取组件数据（下拉选择用） | Comp |
| GET | /api/v1/express/:id | 获取详情 | Get |
| PUT | /api/v1/express/:id | 更新快递公司 | Update |
| DELETE | /api/v1/express/:id | 删除快递公司（软删除） | Delete |

**路由顺序注意事项**:
- `/express/comp` 路由必须放在 `/:id` 之前
- 避免 `comp` 被识别为ID参数导致路由冲突

## 技术要点

### 1. 多租户支持

- 所有接口通过 `middleware.GetTenantDB(c)` 获取租户DB
- Schema级别隔离，自动切换到正确的租户Schema
- 无需在代码中显式处理tenant_id

### 2. 编码自动生成

- 创建时如果Code为空，自动生成：`001 + 时间戳 + 序号`
- 示例：`001202510311030450001`
- 格式验证：只允许大写字母和数字
- 唯一性检查：Schema级别确保编码唯一

### 3. 架构简化

相比旧架构，新架构简化为2层：

- **旧架构**: Ctrl → Biz → Store → Model (4层)
- **新架构**: Handler → Model (2层)

Handler直接从Context获取租户DB，减少中间层传递。

### 4. 依赖关系

Express模块依赖：

```
express/
├── model/         (数据模型)
├── api/           (DTO定义)
├── handler/       (HTTP处理器，依赖model和api)
└── router.go      (路由注册，依赖handler)

router/router.go   (主路由，依赖express)
database/database.go (模型注册，依赖express/model)
```
