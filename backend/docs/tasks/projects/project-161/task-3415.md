### 2. JWT认证集成 ✅

#### 2.1 AuthMiddleware实现

**文件**: `api/internal/middleware/auth_middleware.go`

**核心功能**:
- ✅ JWT Token验证（HMAC-SHA256）
- ✅ Claims提取（user_id, tenant_id, username）
- ✅ Context存储（供后续Handler使用）
- ✅ 错误处理（401 Unauthorized）

**实现**:
```go
type CustomClaims struct {
    UserID   int64  `json:"user_id"`
    TenantID int64  `json:"tenant_id"`
    Username string `json:"username"`
    jwt.RegisteredClaims
}

func (m *AuthMiddleware) Handle(next http.HandlerFunc) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        // 1. 获取Authorization Header
        authHeader := r.Header.Get("Authorization")
        if authHeader == "" {
            http.Error(w, `{"error":"Missing Authorization header"}`, http.StatusUnauthorized)
            return
        }
        
        // 2. 提取Token
        parts := strings.SplitN(authHeader, " ", 2)
        if len(parts) != 2 || parts[0] != "Bearer" {
            http.Error(w, `{"error":"Invalid Authorization header format"}`, http.StatusUnauthorized)
            return
        }
        
        // 3. 解析JWT
        token, err := jwt.ParseWithClaims(parts[1], &CustomClaims{}, func(token *jwt.Token) (interface{}, error) {
            return []byte(m.jwtSecret), nil
        })
        
        // 4. 验证Claims
        claims, ok := token.Claims.(*CustomClaims)
        if !ok || !token.Valid {
            http.Error(w, `{"error":"Invalid token claims"}`, http.StatusUnauthorized)
            return
        }
        
        // 5. 存入Context
        ctx := r.Context()
        ctx = context.WithValue(ctx, "user_id", claims.UserID)
        ctx = context.WithValue(ctx, "tenant_id", claims.TenantID)
        ctx = context.WithValue(ctx, "username", claims.Username)
        
        // 6. 传递到下一个Handler
        next(w, r.WithContext(ctx))
    }
}
```

### 3. 数据权限过滤 ✅

#### 3.1 租户隔离

**实现位置**: 所有Logic层

**原理**: 
1. AuthMiddleware从JWT提取tenant_id并存入Context
2. Logic层从Context获取tenant_id
3. 数据库查询时强制添加tenant_id过滤条件

**示例** - ExportTask查询:
```go
func (l *CreateExportTaskLogic) CreateExportTask(req *types.CreateExportTaskRequest) (*types.CreateExportTaskResponse, error) {
    // 1. 从Context提取租户ID
    tenantID := int64(1)  // 默认值
    if val := l.ctx.Value("tenant_id"); val != nil {
        if tid, ok := val.(int64); ok {
            tenantID = tid
        }
    }
    
    // 2. 创建任务时绑定租户ID
    task := &model.ExportTask{
        ID:       uuid.New().String(),
        TenantID: tenantID,  // 强制租户隔离
        UserID:   userID,
        // ...
    }
    
    l.svcCtx.ExportTaskModel.Insert(l.ctx, task)
    // ...
}
```

**示例** - 查询时过滤:
```go
func (m *ExportTaskModel) List(ctx context.Context, req *ListRequest) ([]*ExportTask, int64, error) {
    var tasks []*ExportTask

    }
    
    // ...

    return tasks, total, nil
}
```

**任务类型**: `batch_update_image`

**Excel格式**:
| 商品编号 | 图片URL |
|---------|---------|

**处理流程**:
```go
func (p *BatchProcessor) processRecord(ctx context.Context, payload queue.BatchTaskPayload, record []string, excelRow int) BatchResult {
    switch payload.TaskType {
    case "batch_update_image":
        // 验证字段
        if len(record) < 2 {
            return BatchResult{Success: false, Message: "数据格式错误：缺少必要字段"}
        }
        
        productCode := record[0]
        imageURL := record[1]
        
        // 调用business-service API
        err := p.svcCtx.BusinessClient.BatchUpdateProductImage(ctx, payload.TenantID, productCode, imageURL)
        if err != nil {
            return BatchResult{Success: false, Message: fmt.Sprintf("更新失败: %v", err)}
        }
        
        return BatchResult{Success: true, Message: "更新成功"}
    }
}
```
