### 2. ✅ 创建图标注册表

**文件**: `src/utils/iconRegistry.ts`

**核心设计**:
```typescript
// 真正的按需导入，不是从整体中选择
import {
  HomeOutlined,
  UserOutlined,
  SettingOutlined,
  // ... 130个实际使用的图标
} from '@ant-design/icons';

// 创建注册表映射
export const iconRegistry: IconRegistry = {
  HomeOutlined,
  UserOutlined,
  SettingOutlined,
  // ...
};

// 提供getIcon函数
export function getIcon(iconName?: string): React.ComponentType | null {
  if (!iconName) return null;
  
  const IconComponent = iconRegistry[iconName];
  
  if (!IconComponent) {
    // 开发环境警告
    if (process.env.NODE_ENV !== 'production') {
      console.warn(`Icon "${iconName}" is not registered`);
    }
    return null;
  }
  
  return IconComponent;
}
```

**优势**:
- ✅ 真正的ES Module按需导入
- ✅ 支持tree-shaking
- ✅ 类型安全
- ✅ 开发时警告未注册的图标
- ✅ 统一的图标管理

## 技术细节

### 为什么这样优化有效？

1. **避免动态索引访问**
   ```typescript
   // ❌ 错误：阻止tree-shaking
   const Icons = await import('@ant-design/icons');
   const Icon = Icons[iconName];
   
   // ✅ 正确：支持tree-shaking
   import { HomeOutlined, UserOutlined } from '@ant-design/icons';
   ```

2. **ES Module静态分析**
   - Vite/Rollup可以分析静态import语句
   - 未使用的导出会被tree-shake掉
   - 动态访问会让打包工具保留所有内容

3. **按需导入原理**
   ```typescript
   // 每个图标都是独立的ES Module
   // 只导入使用的，其他的会被tree-shake
   export { HomeOutlined } from './icons/HomeOutlined';
   export { UserOutlined } from './icons/UserOutlined';
   // ...
   ```

### Ant Design 5.x特性

- ✅ 完全支持ES Module
- ✅ 每个组件独立导出
- ✅ CSS-in-JS（无需单独导入CSS）
- ✅ 自动tree-shaking
- ❌ 但动态访问会破坏tree-shaking

## 后续维护

### 添加新图标

当项目需要使用新图标时：

1. **在iconRegistry.ts中添加导入**:
   ```typescript
   import {
     // ... existing icons
     NewIconOutlined,  // 新增
   } from '@ant-design/icons';
   ```

2. **在iconRegistry对象中注册**:
   ```typescript
   export const iconRegistry: IconRegistry = {
     // ... existing icons

   };
   ```
