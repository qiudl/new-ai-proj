# React Native移动端应用完整开发方案

## 项目概述

开发一个React Native移动端应用，支持扫描Platform-admin管理平台的二维码并完成登录确认功能。

**父任务**: #3610 移动端APP - 扫码功能开发
**新任务**: #3639 React Native移动端应用完整开发

## 技术栈

### 核心技术
- **React Native**: 0.72+ (跨平台移动应用框架)
- **TypeScript**: 5.0+ (类型安全)
- **React Navigation**: 6.x (导航管理)
- **Axios**: 1.x (HTTP客户端)
- **React Native Camera**: 4.x (相机和二维码扫描)
- **AsyncStorage**: 数据持久化

### 状态管理
- **React Context API** 或 **Zustand** (轻量级状态管理)

### UI组件库
- **React Native Paper** 或 **NativeBase** (Material Design组件)
- 自定义组件（品牌色#667EEA）

### 任务3643: 集成API调用和状态管理

**目标**: 实现与Auth Service的API通信和全局状态管理

**工作内容**:

1. 配置Axios客户端
   ```typescript
   // src/api/client.ts
   import axios from 'axios';
   import AsyncStorage from '@react-native-async-storage/async-storage';
   
   const API_BASE_URL = 'http://localhost:7089/api/v1';
   
   const apiClient = axios.create({
     baseURL: API_BASE_URL,
     timeout: 10000,
     headers: {
       'Content-Type': 'application/json',
     },
   });
   
   // 请求拦截器：添加token
   apiClient.interceptors.request.use(async (config) => {
     const token = await AsyncStorage.getItem('access_token');
     if (token) {
       config.headers.Authorization = `Bearer ${token}`;
     }
     return config;
   });
   
   // 响应拦截器：错误处理
   apiClient.interceptors.response.use(
     (response) => response.data,
     (error) => {
       if (error.response?.status === 401) {
         // Token过期，跳转登录
       }
       return Promise.reject(error);
     }
   );
   ```

2. 实现Auth API
   ```typescript
   // src/api/auth.ts
   export const authApi = {
     // 扫描二维码
     scanQRCode: (qrcodeId: string): Promise<ScanResponse> => {
       return apiClient.post('/auth/qrcode/scan', { qrcode_id: qrcodeId });
     },
     
     // 确认/取消登录
     confirmQRCode: (qrcodeId: string, action: 'confirm' | 'cancel') => {
       return apiClient.post('/auth/qrcode/confirm', { 
         qrcode_id: qrcodeId, 
         action 
       });
     },
     
     // 用户登录
     login: (username: string, password: string) => {
       return apiClient.post('/auth/login', { username, password });
     },
   };
   ```

3. 创建AuthContext
   ```typescript
   // src/contexts/AuthContext.tsx
   interface AuthContextType {
     user: UserInfo | null;
     token: string | null;
     login: (username: string, password: string) => Promise<void>;
     logout: () => Promise<void>;
     isAuthenticated: boolean;
   }
   
   export const AuthProvider: React.FC<{children: ReactNode}> = ({children}) => {
     const [user, setUser] = useState<UserInfo | null>(null);
     const [token, setToken] = useState<string | null>(null);
     
     useEffect(() => {
       loadStoredAuth();
     }, []);
     
     const loadStoredAuth = async () => {
       const storedToken = await AsyncStorage.getItem('access_token');
       const storedUser = await AsyncStorage.getItem('user_info');
       if (storedToken && storedUser) {
         setToken(storedToken);
         setUser(JSON.parse(storedUser));
       }
     };
     
     const login = async (username: string, password: string) => {
       const response = await authApi.login(username, password);
       setToken(response.access_token);
       setUser(response.user_info);
       await AsyncStorage.setItem('access_token', response.access_token);
       await AsyncStorage.setItem('user_info', JSON.stringify(response.user_info));
     };
     
     const logout = async () => {
       setToken(null);
       setUser(null);
       await AsyncStorage.multiRemove(['access_token', 'user_info']);
     };
     
     return (
       <AuthContext.Provider value={{user, token, login, logout, isAuthenticated: !!token}}>
         {children}
       </AuthContext.Provider>
     );
   };
   ```

4. TypeScript类型定义
   ```typescript
   // src/types/api.ts
   export interface UserInfo {
     user_id: number;
     username: string;
     tenant_id: number;
     tenant_code: string;
     tenant_name: string;
   }
   
   export interface ScanResponse {

   }
   
   export interface LoginResponse {
     access_token: string;
     refresh_token: string;
     token_type: string;
     expires_in: number;
     user_info: UserInfo;
   }
   ```

   ```xml
       <key>CFBundleURLSchemes</key>
       <array>
         <string>paas</string>
       </array>
     </dict>
   </array>
   ```

2. 配置Android Intent Filter
   ```xml
   <!-- android/app/src/main/AndroidManifest.xml -->
   <activity android:name=".MainActivity">
     <intent-filter>
       <action android:name="android.intent.action.VIEW" />
       <category android:name="android.intent.category.DEFAULT" />
       <category android:name="android.intent.category.BROWSABLE" />
       <data
         android:scheme="paas"
         android:host="login" />
     </intent-filter>
   </activity>
   ```

3. 实现Linking处理
   ```typescript
   // src/utils/linking.ts
   import { Linking } from 'react-native';
   
   export const linking = {
     prefixes: ['paas://'],
     config: {
       screens: {
         QRConfirm: 'login',
       },
     },
   };
   
   export const handleDeepLink = (url: string) => {
     const { path, queryParams } = Linking.parse(url);
     if (path === 'login' && queryParams?.qrcode_id) {
       // 导航到确认页面
       return {
         screen: 'QRConfirm',
         params: { qrcodeId: queryParams.qrcode_id },
       };
     }
   };
   ```

4. 在App.tsx中集成
   ```typescript
   // src/App.tsx
   import { NavigationContainer } from '@react-navigation/native';
   import { linking } from './utils/linking';
   
   const App = () => (
     <NavigationContainer linking={linking}>
       <Stack.Navigator>
         {/* ... */}
       </Stack.Navigator>
     </NavigationContainer>
   );
   ```

## 技术难点和解决方案

### 1. 相机权限处理
**难点**: iOS和Android权限请求机制不同
**方案**: 使用react-native-permissions统一处理，提供友好的权限说明

### 2. 二维码解析
**难点**: 需要准确解析URL中的参数
**方案**: 使用正则表达式匹配`paas://login?qrcode_id=xxx`格式

### 3. 深度链接
**难点**: 应用未启动时的URL处理
**方案**: 在MainActivity/AppDelegate中处理初始URL

### 4. Token管理
**难点**: Token过期处理和刷新
**方案**: 
- 使用Axios拦截器自动添加token
- 401响应时自动跳转登录
- 实现token刷新机制

### 5. 网络异常
**难点**: 移动端网络环境复杂
**方案**:
- 设置合理的超时时间
- 实现重试机制
- 提供离线提示
