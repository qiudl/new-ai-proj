# 用户管理添加左侧组织树导航（两栏布局）

## 📋 任务概述

**优先级**: P0 - 高优先级  
**预估工时**: 4小时  
**负责模块**: 用户管理（UserList.tsx）  
**参考设计**: Zero-Admin-UI 用户管理模块

## 🎯 目标

实现左侧部门树 + 右侧用户表格的两栏布局，支持按组织结构快速筛选用户。

## 📊 现状分析

**当前实现**（`/src/modules/platform/pages/System/UserList.tsx`）:
```
┌────────────────────────────────────────────────────────┐
│  搜索栏: [用户名] [姓名] [手机] [邮箱] [状态] [搜索]     │
├────────────────────────────────────────────────────────┤
│  用户表格（单栏）                                       │
│  用户信息 | 联系方式 | 性别 | 部门 | 角色 | 状态 | 操作  │
└────────────────────────────────────────────────────────┘
```

**存在问题**：
- ❌ 无左侧组织树导航
- ❌ 部门筛选需在搜索栏中手动选择
- ❌ 无法快速按层级浏览组织结构
- ❌ 大量用户时定位效率低

## 🎨 目标设计

```
┌─────────────┬──────────────────────────────────────────┐
│  组织架构   │  用户列表                                 │
│             │                                          │
│  📁 全部    │  搜索: [姓名] [手机] [状态]  [搜索]       │
│  📁 技术部  │  ┌──────────────────────────────────┐   │
│    📁 前端  │  │ [头像] 张三  前端组  管理员  🟢  │   │
│    📁 后端  │  │ [头像] 李四  前端组  开发者  🟢  │   │
│  📁 市场部  │  └──────────────────────────────────┘   │
│  📁 运营部  │  已选中 "前端组"，显示 15 个用户          │
└─────────────┴──────────────────────────────────────────┘
```

## 🔧 实现方案

### 步骤1: 获取和构建部门树数据

```tsx
import { Layout, Tree } from 'antd';
import type { DataNode } from 'antd/es/tree';
import { buildTreeData } from '@/utils/treeUtils';

const { Sider, Content } = Layout;

const UserList: React.FC = () => {
  const [selectedDeptId, setSelectedDeptId] = useState<number | null>(null);
  const [deptTree, setDeptTree] = useState<DataNode[]>([]);
  const [deptExpanded, setDeptExpanded] = useState<React.Key[]>([]);

  // 获取部门树数据
  useEffect(() => {
    fetchDepartments();
  }, []);

  const fetchDepartments = async () => {
    try {
      const response = await systemApi.getDepartmentList();
      const depts = response.data || [];
      
      // 转换为树形结构
      const tree = buildTreeData(
        depts.map(d => ({
          key: d.id,
          title: d.name,
          value: d.id,
          parent_id: d.parent_id || 0,
          icon: <TeamOutlined />,
          children: []
        })),
        0
      );
      
      // 添加"全部"根节点
      const treeWithRoot: DataNode[] = [
        {
          key: 0,
          title: '全部部门',
          value: 0,
          icon: <AppstoreOutlined />,
          children: tree
        }
      ];
      
      setDeptTree(treeWithRoot);
      
      // 默认展开所有节点
      const allKeys = depts.map(d => d.id);
      setDeptExpanded([0, ...allKeys]);
    } catch (error) {
      console.error('获取部门数据失败:', error);
    }
  };
```

### 步骤2: 处理部门选择

```tsx
  // 选择部门时更新筛选条件
  const handleDeptSelect = (selectedKeys: React.Key[]) => {
    if (selectedKeys.length === 0) return;
    
    const deptId = selectedKeys[0];
    
    // 0 表示"全部"
    if (deptId === 0) {
      setSelectedDeptId(null);
      setSearchParams(prev => {
        const { deptId, ...rest } = prev;
        return rest;
      });
    } else {
      setSelectedDeptId(Number(deptId));
      setSearchParams(prev => ({ 
        ...prev, 
        deptId: Number(deptId) 
      }));
    }
  };
```

### 步骤4: 辅助函数

```tsx
// 根据部门ID获取部门名称
const getDeptName = (deptId: number): string => {
  const dept = departments.find(d => d.id === deptId);
  return dept?.name || '未知部门';
};
```

## 🐛 边界情况处理

1. **部门数据为空**: 显示"暂无部门数据"提示
2. **部门树加载失败**: 显示错误提示，提供重试按钮
3. **选中部门无用户**: 表格显示空状态，提示"该部门暂无用户"
4. **部门树层级过深**: 限制最大展开层级为3层
5. **部门名称过长**: 使用Tooltip显示完整名称
