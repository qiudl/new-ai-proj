## 2. 融合策略设计

### 2.1 总体原则

**核心策略**：**组件级迁移 + 逐步适配**

- ✅ **保留 PaaS-System 的基础架构**（Vite + React 18 + React Router 6）
- ✅ **复用 Zero-Admin 的业务组件**（订单列表、订单详情等）
- ✅ **升级 Ant Design 到 v5**（Zero-Admin 组件需适配）
- ✅ **统一状态管理为 Zustand**（替换 Dva）
- ✅ **统一 ProTable 实现**（保留 PaaS 自研版本）

### 2.2 迁移路径

```
Phase 1: 组件提取与准备
  ├── 提取订单相关组件
  ├── 提取通用组件（Modal、Form等）
  ├── 提取类型定义
  └── 提取样式文件

Phase 2: 适配层开发
  ├── API适配层（Umi Request → Axios）
  ├── 路由适配层（Umi Router → React Router 6）
  ├── 状态适配层（Dva → Zustand）
  └── UI适配层（Ant Design 4 → 5）

Phase 3: 组件集成
  ├── 订单列表组件集成
  ├── 订单详情组件集成
  ├── 发货流程组件集成
  └── 测试验证

Phase 4: 优化完善
  ├── 性能优化
  ├── 代码规范统一
  ├── 文档完善
  └── 单元测试
```

## 3. 关键技术适配方案

### 3.1 构建工具迁移：UmiJS → Vite

#### 问题分析
- UmiJS 是约定式路由 + 配置式构建
- Vite 是模块化构建工具，需手动配置路由

#### 解决方案：保留 Vite，提取组件

**不迁移 UmiJS 配置，仅提取 React 组件源码**

**Vite配置保持不变**：
```typescript
// paas-system/web/vite.config.ts (保持现有配置)
export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
      '@/components': path.resolve(__dirname, './src/components'),
      '@/modules': path.resolve(__dirname, './src/modules')
    }
  },
  build: {
    rollupOptions: {
      output: {
        manualChunks: {
          'vendor-react': ['react', 'react-dom'],
          'vendor-ui': ['antd', '@ant-design/icons'],
          'vendor-router': ['react-router-dom']
        }
      }
    }
  }
});
```

### 3.3 状态管理迁移：Dva → Zustand

#### Zero-Admin 的 Dva Model（需转换）
```typescript

  namespace: 'order',
  state: {
    orderList: [],
    pagination: {}
  },
  effects: {
    *fetch({ payload }, { call, put }) {
      const response = yield call(queryOrderList, payload);
      yield put({
        type: 'save',
        payload: response
      });
    }
  },
  reducers: {
    save(state, action) {
      return {
        ...state,
        orderList: action.payload.list,
        pagination: action.payload.pagination

```

#### 转换为 Zustand Store
```typescript
// src/modules/business/stores/orderStore.ts
import { create } from 'zustand';
import { queryOrderList } from '../api/order';

interface OrderState {
  orderList: Order[];
  pagination: {
    current: number;
    pageSize: number;
    total: number;
  };
  loading: boolean;
  
  // Actions
  fetchOrderList: (params: OrderQueryParams) => Promise<void>;
  setOrderList: (list: Order[]) => void;
  setPagination: (pagination: Partial<OrderState['pagination']>) => void;
}

export const useOrderStore = create<OrderState>((set, get) => ({
  orderList: [],
  pagination: {
    current: 1,
    pageSize: 10,
    total: 0
  },
  loading: false,
  
  fetchOrderList: async (params) => {
    set({ loading: true });
    try {
      const response = await queryOrderList(params);
      set({
        orderList: response.list,
        pagination: {
          current: params.current || 1,
          pageSize: params.pageSize || 10,
          total: response.total
        }
      });
    } catch (error) {
      console.error('Failed to fetch orders:', error);
    } finally {
      set({ loading: false });
    }
  },
  
  setOrderList: (list) => set({ orderList: list }),
  setPagination: (pagination) => set((state) => ({
    pagination: { ...state.pagination, ...pagination }
  }))
}));
```

**适配后代码**（PaaS-System）：
```typescript
// paas-system/web/src/modules/business/pages/Order/ZeroOrderList.tsx
import React, { useState, useEffect } from 'react';
import { Button, message } from 'antd';
import { ProTable, ProTableColumn } from '@/components/common/ProTable';
import { useOrderStore } from '../../stores/orderStore';
import { queryOrderList, removeOrder } from '../../api/order';
import OrderDetailModal from '../../components/Order/OrderDetailModal';
import DeliveryModal from '../../components/Order/DeliveryModal';

const ZeroOrderList: React.FC = () => {
  const { orderList, pagination, fetchOrderList } = useOrderStore();
  const [loading, setLoading] = useState(false);
  const [currentRow, setCurrentRow] = useState<Order>();
  const [detailVisible, setDetailVisible] = useState(false);
  const [deliveryVisible, setDeliveryVisible] = useState(false);

  // 获取订单列表
  const handleFetch = async (params: any) => {
    setLoading(true);
    try {
      await fetchOrderList(params);
    } finally {
      setLoading(false);
    }
  };

  useEffect(() => {
    handleFetch({ current: 1, pageSize: 10 });
  }, []);

  // 删除订单
  const handleRemove = async (record: Order) => {
    try {
      await removeOrder({ ids: [record.id] });
      message.success('删除成功');
      handleFetch(pagination);
    } catch (error) {
      message.error('删除失败');
    }
  };

  // 列定义（适配Ant Design 5）
  const columns: ProTableColumn<Order>[] = [
    {
      title: '订单编号',
      dataIndex: 'orderNo',
      render: (_, record) => (
        <a onClick={() => {
          setCurrentRow(record);
          setDetailVisible(true);
        }}>
          {record.orderNo}
        </a>
      )
    },
    {
      title: '用户账号',
      dataIndex: 'memberUsername'
    },
    {
      title: '订单金额',
      dataIndex: 'totalAmount',
      render: (_, record) => `¥${record.totalAmount.toFixed(2)}`
    },
    {
      title: '订单状态',
      dataIndex: 'status',
      render: (_, record) => {
        const statusMap = {
          10: { text: '草稿', color: 'default' },
          20: { text: '待审批', color: 'warning' },
          30: { text: '待支付', color: 'warning' },
          39: { text: '已支付', color: 'success' },
          49: { text: '已发货', color: 'success' },
          90: { text: '已完成', color: 'success' },
          95: { text: '已取消', color: 'error' }
        };
        const config = statusMap[record.status] || { text: '未知', color: 'default' };
        return <Tag color={config.color}>{config.text}</Tag>;
      }
    },
    {
      title: '创建时间',
      dataIndex: 'createdAt',
      valueType: 'dateTime'
    },
    {
      title: '操作',
      key: 'action',
      render: (_, record) => (
        <Space>
          {record.status === 30 && (
            <Button size="small" type="link">支付</Button>
          )}
          {record.status === 39 && (
            <Button
              size="small"
              type="link"
              onClick={() => {
                setCurrentRow(record);
                setDeliveryVisible(true);
              }}
            >
              发货
            </Button>
          )}
          <Button
            size="small"
            type="link"
            danger
            onClick={() => handleRemove(record)}
          >
            删除
          </Button>
        </Space>
      )
    }
  ];

  return (
    <>
      <ProTable<Order>
        columns={columns}
        dataSource={orderList}
        loading={loading}
        pagination={pagination}
        onPageChange={(page, pageSize) => {
          handleFetch({ current: page, pageSize });
        }}
        onRefresh={() => handleFetch(pagination)}
      />

      {/* 订单详情 */}
      <OrderDetailModal
        open={detailVisible}
        order={currentRow}
        onCancel={() => setDetailVisible(false)}
      />

      {/* 发货Modal */}
      <DeliveryModal
        open={deliveryVisible}
        order={currentRow}
        onOk={async (values) => {
          await delivery(values);
          setDeliveryVisible(false);
          handleFetch(pagination);
        }}
        onCancel={() => setDeliveryVisible(false)}
      />
    </>
  );
};

export default ZeroOrderList;
```

## 10. 风险与应对

### 10.1 技术风险

#### 风险1: Ant Design 4→5 API变更导致组件报错
**概率**: 高 | **影响**: 中

**应对**:
- 使用 `@ant-design/codemod-v5` 自动转换
- 建立组件测试用例
- 提前在测试环境验证

#### 风险2: 状态管理迁移后数据流异常
**概率**: 中 | **影响**: 高

**应对**:
- 保留原有数据流逻辑
- 增加日志监控
- 分阶段灰度上线

#### 风险3: 性能下降
**概率**: 低 | **影响**: 高

**应对**:
- 使用 React.lazy 懒加载
- 优化 Vite 打包配置
- 引入虚拟滚动（长列表）

### 10.2 业务风险

#### 风险1: 用户体验变化引起不适
**概率**: 中 | **影响**: 中

**应对**:
- 保持UI风格一致
- 提供用户引导
- 收集用户反馈快速迭代

## 12. 附录：快速开始

### 12.1 环境准备

```bash
# 克隆 Zero-Admin-UI 源码（用于参考）
git clone https://github.com/feihua/zero-admin-ui.git

# 安装 PaaS-System 依赖
cd paas-system/web
npm install

# 安装 Ant Design 5 codemod工具
npm install -g @ant-design/codemod-v5
```

### 12.2 组件提取脚本

```bash
#!/bin/bash
# extract-zero-components.sh

ZERO_DIR="../zero-admin-ui"
PAAS_DIR="./paas-system/web/src/modules/business"

# 创建目标目录
mkdir -p $PAAS_DIR/pages/Order
mkdir -p $PAAS_DIR/components/Order

# 复制订单列表组件
cp $ZERO_DIR/src/pages/oms/order/index.tsx \
   $PAAS_DIR/pages/Order/ZeroOrderList.tsx

# 复制子组件
cp $ZERO_DIR/src/pages/oms/order/components/*.tsx \
   $PAAS_DIR/components/Order/

# 复制样式
cp $ZERO_DIR/src/pages/oms/order/index.less \
   $PAAS_DIR/pages/Order/OrderList.less

echo "✅ 组件提取完成！"
echo "下一步: 运行 npx @ant-design/codemod-v5 进行API适配"
```

### 12.3 运行适配工具

```bash
# 自动转换 Ant Design 4 到 5
npx @ant-design/codemod-v5 \
  src/modules/business/pages/Order \
  src/modules/business/components/Order

# 手动检查和修复
# 1. visible → open
# 2. moment → dayjs
# 3. connect → useOrderStore
```
