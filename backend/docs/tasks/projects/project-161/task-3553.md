# 详情展示统一使用Drawer（用户/角色/菜单）

## 📋 任务概述

**优先级**: P1 - 中优先级  
**预估工时**: 6小时（用户2h + 角色2h + 菜单2h）  
**负责模块**: 用户管理、角色管理、菜单管理  
**参考设计**: Ant Design Drawer 最佳实践

## 🎯 目标

将用户、角色、菜单的详情展示从 Modal 改为 Drawer（侧滑抽屉），提升用户体验，允许在查看详情的同时浏览列表数据。

## 📊 现状分析

**当前实现**（以用户详情为例）:
```tsx
// UserList.tsx (第802-860行)
<Modal
  title="用户详情"
  open={detailModalVisible}
  onCancel={() => setDetailModalVisible(false)}
  footer={[...]}
  width={800}
>
  <Descriptions column={2} bordered>
    {/* 详情内容 */}
  </Descriptions>
</Modal>
```

**存在问题**：
- ❌ Modal 完全遮挡主界面，无法对比查看
- ❌ 查看详情后想编辑，需要关闭Modal再打开表单
- ❌ 多个详情间切换需要反复关闭/打开
- ❌ 用户体验不够流畅

**改进后效果**：
```
┌────────────────────────┬──────────────┐
│  用户列表              │  用户详情     │
│  [张三] ...  [查看]    │  [X] 关闭    │
│  [李四] ...  [查看]    │              │
│  [王五] ...  [查看]    │  头像: 📷    │
│                        │  姓名: 张三   │
│                        │  部门: 技术部 │
│                        │  角色: 管理员 │
│                        │              │
│                        │  [编辑用户]  │
└────────────────────────┴──────────────┘
```

## 🔧 实现方案

### 1. 用户详情 Drawer

#### 步骤1: 创建 UserDetailDrawer 组件

```tsx
// /src/modules/platform/pages/System/components/user/UserDetailDrawer.tsx

import React from 'react';
import {
  Drawer,
  Descriptions,
  Avatar,
  Badge,
  Tag,
  Button,
  Space,
  Divider,
  Typography,
  Card
} from 'antd';
import {
  UserOutlined,
  EditOutlined,
  ManOutlined,
  WomanOutlined,
  MailOutlined,
  PhoneOutlined,
  TeamOutlined,
  CalendarOutlined,
  ClockCircleOutlined
} from '@ant-design/icons';
import type { User } from '@/api/modules/system';
import { UserStatus, UserGender } from '@/api/modules/system';

const { Title, Text } = Typography;

interface UserDetailDrawerProps {
  visible: boolean;
  onClose: () => void;
  user: User | null;
  onEdit: () => void;
}

const UserDetailDrawer: React.FC<UserDetailDrawerProps> = ({
  visible,
  onClose,
  user,
  onEdit
}) => {
  if (!user) return null;

  // 获取性别显示
  const getGenderDisplay = (gender: UserGender) => {
    switch (gender) {
      case UserGender.MALE:
        return { text: '男', icon: <ManOutlined />, color: 'blue' };
      case UserGender.FEMALE:
        return { text: '女', icon: <WomanOutlined />, color: 'pink' };
      default:
        return { text: '保密', icon: <UserOutlined />, color: 'default' };
    }
  };

  const genderInfo = getGenderDisplay(user.gender);

  return (
    <Drawer
      title="用户详情"
      placement="right"
      width={640}
      open={visible}
      onClose={onClose}
      extra={
        <Space>
          <Button onClick={onClose}>关闭</Button>
          <Button type="primary" icon={<EditOutlined />} onClick={onEdit}>
            编辑用户
          </Button>
        </Space>
      }
    >
      {/* 用户头像和基本信息 */}
      <Card style={{ marginBottom: 24, textAlign: 'center' }}>
        <Space direction="vertical" size="middle" style={{ width: '100%' }}>
          <Avatar size={100} src={user.avatar} icon={<UserOutlined />} />
          
          <div>
            <Title level={4} style={{ marginBottom: 4 }}>{user.realName}</Title>
            <Text type="secondary">@{user.username}</Text>
          </div>
          
          <Badge 
            status={user.status === UserStatus.NORMAL ? 'success' : 'error'} 
            text={user.status === UserStatus.NORMAL ? '正常' : '禁用'} 
          />
        </Space>
      </Card>

      <Divider orientation="left">基本信息</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="真实姓名">
          {user.realName}
        </Descriptions.Item>
        <Descriptions.Item label="用户名">
          {user.username}
        </Descriptions.Item>
        <Descriptions.Item label="昵称">
          {user.nickname || '-'}
        </Descriptions.Item>
        <Descriptions.Item label="性别">
          <Space>
            {genderInfo.icon}
            <span>{genderInfo.text}</span>
          </Space>
        </Descriptions.Item>
        <Descriptions.Item label="生日">
          <Space>
            <CalendarOutlined />
            {user.birthday || '-'}
          </Space>
        </Descriptions.Item>
      </Descriptions>

      <Divider orientation="left">联系方式</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="手机号">
          <Space>
            <PhoneOutlined />
            {user.phone || '-'}
          </Space>
        </Descriptions.Item>
        <Descriptions.Item label="邮箱">
          <Space>
            <MailOutlined />
            {user.email || '-'}
          </Space>
        </Descriptions.Item>
      </Descriptions>

      <Divider orientation="left">组织信息</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="部门">
          {user.deptName ? (
            <Tag icon={<TeamOutlined />} color="blue">
              {user.deptName}
            </Tag>
          ) : '-'}
        </Descriptions.Item>
        <Descriptions.Item label="职位">
          {user.positionName || '-'}
        </Descriptions.Item>
        <Descriptions.Item label="角色">
          <Space wrap>
            {user.roles?.map((role, index) => (
              <Tag key={index} color="green">{role.name}</Tag>
            )) || '-'}
          </Space>
        </Descriptions.Item>
      </Descriptions>

      <Divider orientation="left">系统信息</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="最后登录">
          <Space>
            <ClockCircleOutlined />
            {user.loginTime || '未登录'}
          </Space>
        </Descriptions.Item>
        <Descriptions.Item label="创建时间">
          {user.created_at}
        </Descriptions.Item>
        <Descriptions.Item label="更新时间">
          {user.updated_at}
        </Descriptions.Item>
        <Descriptions.Item label="创建人">
          {user.createdBy || '-'}
        </Descriptions.Item>
      </Descriptions>

      {user.intro && (
        <>
          <Divider orientation="left">个人简介</Divider>
          <Card>
            <Text>{user.intro}</Text>
          </Card>
        </>
      )}
    </Drawer>
  );
};

export default UserDetailDrawer;
```

### 3. 菜单详情 Drawer

#### 创建 MenuDetailDrawer 组件

```tsx
// /src/modules/platform/pages/System/components/menu/MenuDetailDrawer.tsx

import React from 'react';
import {
  Drawer,
  Descriptions,
  Tag,
  Button,
  Space,
  Divider,
  Card,
  Typography,
  Badge
} from 'antd';
import {
  EditOutlined,
  FolderOutlined,
  FileOutlined,
  AppstoreOutlined,
  MenuOutlined,
  ClockCircleOutlined
} from '@ant-design/icons';
import type { MenuItem } from '@/api/modules/menu';
import { MenuType } from '@/api/modules/menu';

const { Title, Text } = Typography;

interface MenuDetailDrawerProps {
  visible: boolean;
  onClose: () => void;
  menu: MenuItem | null;
  onEdit: () => void;
}

const MenuDetailDrawer: React.FC<MenuDetailDrawerProps> = ({
  visible,
  onClose,
  menu,
  onEdit
}) => {
  if (!menu) return null;

  // 获取菜单类型信息
  const getMenuTypeInfo = (type: MenuType) => {
    const config = {
      [MenuType.DIRECTORY]: { 
        color: 'blue', 
        text: '目录', 
        icon: <FolderOutlined /> 
      },
      [MenuType.MENU]: { 
        color: 'green', 
        text: '菜单', 
        icon: <FileOutlined /> 
      },
      [MenuType.BUTTON]: { 
        color: 'orange', 
        text: '按钮', 
        icon: <AppstoreOutlined /> 
      },
    };
    return config[type];
  };

  const typeInfo = getMenuTypeInfo(menu.menu_type);

  return (
    <Drawer
      title="菜单详情"
      placement="right"
      width={640}
      open={visible}
      onClose={onClose}
      extra={
        <Space>
          <Button onClick={onClose}>关闭</Button>
          <Button type="primary" icon={<EditOutlined />} onClick={onEdit}>
            编辑菜单
          </Button>
        </Space>
      }
    >
      {/* 菜单基本信息卡片 */}
      <Card style={{ marginBottom: 24, textAlign: 'center' }}>
        <Space direction="vertical" size="middle" style={{ width: '100%' }}>
          <MenuOutlined style={{ fontSize: 64, color: '#1890ff' }} />
          
          <div>
            <Title level={4} style={{ marginBottom: 4 }}>{menu.title}</Title>
            <Text type="secondary" code>{menu.name}</Text>
          </div>
          
          <Tag color={typeInfo.color} icon={typeInfo.icon}>
            {typeInfo.text}
          </Tag>
        </Space>
      </Card>

      <Divider orientation="left">基本信息</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="菜单名称">
          {menu.title}
        </Descriptions.Item>
        <Descriptions.Item label="菜单标识">
          <Text code>{menu.name}</Text>
        </Descriptions.Item>
        <Descriptions.Item label="菜单类型">
          <Tag color={typeInfo.color} icon={typeInfo.icon}>
            {typeInfo.text}
          </Tag>
        </Descriptions.Item>
        <Descriptions.Item label="排序">
          <Badge count={menu.sort_number} showZero style={{ backgroundColor: '#52c41a' }} />
        </Descriptions.Item>
      </Descriptions>

      <Divider orientation="left">路由信息</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="路由地址">
          <Text code>{menu.path || '-'}</Text>
        </Descriptions.Item>
        <Descriptions.Item label="组件路径">
          <Text code>{menu.component || '-'}</Text>
        </Descriptions.Item>
        <Descriptions.Item label="图标">
          {menu.icon || '-'}
        </Descriptions.Item>
        <Descriptions.Item label="权限标识">
          <Text code>{menu.authority || '-'}</Text>
        </Descriptions.Item>
      </Descriptions>

      <Divider orientation="left">显示设置</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="显示状态">
          <Tag color={menu.hide !== 1 ? 'success' : 'error'}>
            {menu.hide !== 1 ? '显示' : '隐藏'}
          </Tag>
        </Descriptions.Item>
      </Descriptions>

      <Divider orientation="left">系统信息</Divider>
      
      <Descriptions column={1} bordered>
        <Descriptions.Item label="创建时间">
          <Space>
            <ClockCircleOutlined />
            {menu.created_at}
          </Space>
        </Descriptions.Item>
        <Descriptions.Item label="更新时间">
          <Space>
            <ClockCircleOutlined />
            {menu.updated_at}
          </Space>
        </Descriptions.Item>
      </Descriptions>

      {menu.mark && (
        <>
          <Divider orientation="left">备注</Divider>
          <Card>
            <Text>{menu.mark}</Text>
          </Card>
        </>
      )}
    </Drawer>
  );
};

export default MenuDetailDrawer;
```

## 🎨 设计规范

### Drawer 统一配置

```tsx
// 统一的 Drawer 配置
const DRAWER_CONFIG = {
  placement: 'right' as const,
  width: 640,
  headerStyle: {
    borderBottom: '1px solid #f0f0f0'
  },
  bodyStyle: {

  }
};
```

### 布局结构

1. **顶部卡片**: 展示核心信息（头像/图标 + 名称 + 状态）
2. **分组信息**: 使用 Divider 分隔不同类型的信息
3. **操作按钮**: 固定在右上角 extra 区域
4. **描述列表**: 使用 Descriptions 组件，单列bordered样式

## ✅ 验收标准

1. ✅ 用户详情使用 Drawer 展示
2. ✅ 角色详情使用 Drawer 展示
3. ✅ 菜单详情使用 Drawer 展示
4. ✅ Drawer 打开时不遮挡列表，可以对比查看
5. ✅ Drawer 内可以直接点击"编辑"按钮
6. ✅ 关闭 Drawer 后状态正确重置
7. ✅ 样式统一，符合设计规范
8. ✅ 在移动端自动调整宽度

## 🐛 边界情况处理

1. **数据为空**: 显示 "-" 占位符
2. **长文本**: 使用 Typography.Text 的 ellipsis 属性
3. **图片加载失败**: Avatar 组件自动显示默认图标
4. **移动端**: Drawer 宽度自适应，小于640时占满屏幕
