### 步骤2: 更新router.go

#### 需要添加的内容
1. 导入warehouse handler包
```go
import (
    warehousehandler "github.com/coolbuy/paas-business/internal/warehouse/handler"
)
```

2. 在API路由组中添加warehouse路由
```go
// 仓库管理
warehouses := api.Group("/warehouses")
{
    warehouseHandler := warehousehandler.NewWarehouseHandler(db)
    warehouses.GET("", warehouseHandler.List)
    warehouses.GET("/:id", warehouseHandler.Get)
    warehouses.POST("", warehouseHandler.Create)
    warehouses.PUT("/:id", warehouseHandler.Update)
    warehouses.DELETE("/:id", warehouseHandler.Delete)
    warehouses.GET("/comp", warehouseHandler.Comp)
}

// 仓库快递管理
warehouseExpresses := api.Group("/warehouse-expresses")
{
    warehouseExpressHandler := warehousehandler.NewWarehouseExpressHandler(db)
    warehouseExpresses.GET("", warehouseExpressHandler.List)
    warehouseExpresses.GET("/:id", warehouseExpressHandler.Get)
    warehouseExpresses.POST("", warehouseExpressHandler.Create)
    warehouseExpresses.PUT("/:id", warehouseExpressHandler.Update)
    warehouseExpresses.DELETE("/:id", warehouseExpressHandler.Delete)
    warehouseExpresses.GET("/comp", warehouseExpressHandler.Comp)
}
```

## 技术说明

### 模型自动迁移
添加到GetModels()的模型将会：
1. 在public schema自动创建表结构
2. 在新租户创建时自动在租户schema中创建表结构
3. 支持schema自动迁移

### 路由中间件链
所有warehouse路由将经过以下中间件：
1. Logger - 请求日志
2. PrometheusMetrics - 性能监控
3. Recovery - 错误恢复
4. CORS - 跨域支持
5. TenantContext - 租户上下文
6. TenantValidation - 租户验证
7. TenantSchema - Schema切换

### 导入路径规范
- Model包: `github.com/coolbuy/paas-business/internal/warehouse/model`
- Handler包: `github.com/coolbuy/paas-business/internal/warehouse/handler`
