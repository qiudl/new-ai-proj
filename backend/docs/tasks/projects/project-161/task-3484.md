## 技术亮点

### 1. 双格式价格存储
```go
// DECIMAL格式（兼容性）
MarketPrice float64 `gorm:"type:decimal(10,2)"`

// 分格式（精确计算）
MarketPriceCents *int64 `json:"market_price_cents"`

// GORM Hook自动同步
func (s *SKU) BeforeCreate(tx *gorm.DB) error {
    if s.MarketPriceCents == nil && s.MarketPrice > 0 {
        cents := int64(s.MarketPrice * 100)
        s.MarketPriceCents = &cents
    }
    return nil
}
```
