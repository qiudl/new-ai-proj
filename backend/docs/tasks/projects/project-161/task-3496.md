# 发货流程功能设计文档

## 流程概述

发货流程是物流模块的核心业务流程，包含订单审核、拣货、打包、称重、交接物流等环节，需要保证准确性和效率。

## 完整发货流程

```
订单支付成功 → 订单审核 → 库存校验 → 拣货任务 → 打包称重 → 创建物流单 → 打印面单 → 交接物流 → 物流跟踪
```

## 核心功能设计

### 1. 订单发货前置检查

```go
// CheckBeforeShipment 发货前置检查
func (b *ShipmentBiz) CheckBeforeShipment(db *gorm.DB, orderID uint) (*PreShipmentCheck, error) {
    var order model.Order
    if err := db.Preload("Items").First(&order, orderID).Error; err != nil {
        return nil, err
    }
    
    check := &PreShipmentCheck{
        OrderID:     orderID,
        OrderNo:     order.OrderNo,
        CanShip:     true,
        CheckItems:  []CheckItem{},
    }
    
    // 1. 检查订单状态
    if order.Status != "paid" {
        check.CanShip = false
        check.CheckItems = append(check.CheckItems, CheckItem{
            CheckType: "order_status",
            Pass:      false,
            Message:   "订单未支付或状态异常",
        })
    }
    
    // 2. 检查收货地址
    if order.ReceiverAddress == "" {
        check.CanShip = false
        check.CheckItems = append(check.CheckItems, CheckItem{
            CheckType: "address",
            Pass:      false,
            Message:   "收货地址不完整",
        })
    }
    
    // 3. 检查库存
    for _, item := range order.Items {
        inventory, err := b.inventoryStore.GetBySkuAndWarehouse(db, item.SkuID, order.WarehouseID)
        if err != nil || inventory.AvailableQuantity < item.Quantity {
            check.CanShip = false
            check.CheckItems = append(check.CheckItems, CheckItem{
                CheckType: "inventory",
                Pass:      false,
                Message:   fmt.Sprintf("SKU %s 库存不足", item.SkuCode),
                SkuID:     item.SkuID,
                Required:  item.Quantity,
                Available: inventory.AvailableQuantity,
            })
        }
    }
    
    return check, nil
}
```

### 2. 批量发货

```go
// BatchShipment 批量发货
func (b *ShipmentBiz) BatchShipment(db *gorm.DB, req *ReqBatchShipment, userID uint) (*RespBatchShipment, error) {
    results := &RespBatchShipment{
        Total:      len(req.OrderIDs),
        Success:    0,
        Failed:     0,
        Results:    []BatchShipmentResult{},
    }
    
    for _, orderID := range req.OrderIDs {
        // 发货前检查
        check, err := b.CheckBeforeShipment(db, orderID)
        if err != nil || !check.CanShip {
            results.Failed++
            results.Results = append(results.Results, BatchShipmentResult{
                OrderID: orderID,
                Success: false,
                Message: "发货前检查失败",
            })
            continue
        }
        
        // 创建物流单
        shipmentReq := &ReqCreateShipment{
            OrderID:      orderID,
            ProviderID:   req.ProviderID,
            WarehouseID:  req.WarehouseID,
            ShipmentType: "full",
        }
        
        resp, err := b.Create(db, shipmentReq, userID)
        if err != nil {
            results.Failed++
            results.Results = append(results.Results, BatchShipmentResult{
                OrderID: orderID,
                Success: false,
                Message: err.Error(),
            })
            continue
        }
        
        results.Success++
        results.Results = append(results.Results, BatchShipmentResult{
            OrderID:    orderID,
            Success:    true,
            ShipmentNo: resp.ShipmentNo,
            TrackingNo: resp.TrackingNo,
        })
    }
    
    return results, nil
}
```

### 3. 打印面单

```go
// PrintWaybill 打印电子面单
func (b *ShipmentBiz) PrintWaybill(db *gorm.DB, shipmentID uint) (*WaybillData, error) {
    shipment, err := b.GetDetail(db, shipmentID)
    if err != nil {
        return nil, err
    }
    
    // 调用物流商API获取电子面单
    waybillData, err := b.getWaybillFromProvider(shipment)
    if err != nil {
        return nil, err
    }
    
    return waybillData, nil
}
```

## 状态流转

```
pending(待发货) → shipped(已发货) → in_transit(运输中) → delivered(已送达)
                                                     ↓
                                                 returned(已退回)
                ↓
            cancelled(已取消)
```
