# 商品导入导出模块产品需求文档 (PRD)

**项目**: Coolbuy 3.0 B2B电商平台  
**模块**: 商品导入导出 (Product Import/Export)  
**版本**: v1.0  
**撰写日期**: 2025-01-06

---

## 1. 产品概述

### 1.1 功能简介
商品导入导出模块负责商品数据的批量导入和导出，支持Excel格式，提供异步任务处理、错误校验、进度追踪等功能，满足"李宁"、"百丽"、"波司登"等品牌的批量商品管理需求。

### 1.2 业务价值
- 支持批量导入商品数据，提升运营效率
- 减少手工录入错误，提供数据校验机制
- 支持商品数据导出，便于数据分析和备份
- 异步任务处理，避免大批量操作阻塞系统

### 1.3 业务场景

**场景1: 新品上架**
```
李宁2025春季新品发布
├─ 运营人员下载导入模板
├─ 填写500个新品的SPU和SKU信息
├─ 上传Excel文件
├─ 系统异步处理导入任务
├─ 校验数据（品类、属性、价格等）
├─ 导入成功450个，失败50个
└─ 下载失败记录，修正后重新导入
```

**场景2: 商品数据导出**
```
运营人员需要导出所有李宁品牌商品
├─ 设置筛选条件（品牌、品类、状态）
├─ 创建导出任务
├─ 系统异步生成Excel文件
├─ 导出完成后下载文件
└─ 用于数据分析或备份
```

### 1.4 用户角色
- **商品管理员**: 批量导入、导出商品数据
- **运营人员**: 批量上架新品、批量修改商品信息
- **数据分析师**: 导出商品数据进行分析

## 2. 核心功能需求

### 2.1 商品导入

#### 2.1.1 导入流程

**完整流程**:
```
1. 下载导入模板
   ↓
2. 填写商品数据
   ↓
3. 上传Excel文件
   ↓
4. 系统异步解析Excel
   ↓
5. 数据校验（必填项、格式、业务规则）
   ↓
6. 保存成功数据，记录失败数据
   ↓
7. 导入任务完成，通知用户
   ↓
8. 下载失败记录（如果有）
```

#### 2.1.3 数据校验规则

**必填项校验**:
- 款号、商品名称、一级分类、SKU编码、颜色、尺码、吊牌价、库存数量

**格式校验**:
- 款号: 长度不超过50字符
- SKU编码: 长度不超过100字符
- 吊牌价、库存: 必须为正数
- 69码: 必须为13位数字（如果填写）

**业务规则校验**:
1. **唯一性校验**:
   - 款号在系统中不能重复（新增模式）
   - SKU编码在系统中不能重复
   - 同一份Excel中款号、SKU编码不能重复

2. **关联数据校验**:
   - 一级分类、二级分类必须在系统中存在
   - 品牌必须在系统中存在（如果填写）
   - 颜色、尺码等属性值必须符合规范

3. **数据合理性校验**:
   - 吊牌价必须大于0
   - 库存数量必须大于等于0
   - 预警数量不能大于库存数量

**功能描述**: 批量更新SKU的条形码（69码）

## 3. 非功能性需求

### 3.1 性能要求
| 指标 | 目标值 |
|------|--------|
| 单次导入支持数据量 | ≤ 10,000 条SKU |
| 导入速度 | ≥ 500 条/秒 |
| 导出速度 | ≥ 1,000 条/秒 |
| 文件上传大小限制 | ≤ 10 MB |
| 任务超时时间 | 10 分钟 |

### 3.2 可靠性
- 导入任务支持断点续传
- 导入失败自动记录错误日志
- 支持任务重试机制
- 数据校验失败不影响其他数据导入

### 3.3 并发处理
- 支持多用户同时导入
- 异步任务处理，不阻塞用户操作
- 使用消息队列处理导入任务
- 限制单用户并发任务数（最多3个）

### 3.4 数据安全
- 导入文件保存到OSS备份
- 导入记录保留30天
- 导出文件设置访问权限
- 导出文件设置过期时间（7天）

## 4. 数据库设计

### 4.1 核心表结构

#### import_tasks (导入任务表)
```sql
CREATE TABLE import_tasks (
    id UUID PRIMARY KEY,
    task_name VARCHAR(200) NOT NULL,
    task_type VARCHAR(20) NOT NULL,  -- product_import, barcode_import, stock_import
    file_name VARCHAR(500),
    file_url VARCHAR(1000),  -- OSS文件URL
    total_count INTEGER DEFAULT 0,
    success_count INTEGER DEFAULT 0,
    fail_count INTEGER DEFAULT 0,
    status VARCHAR(20) DEFAULT 'pending',  -- pending, processing, completed, failed
    error_file_url VARCHAR(1000),  -- 错误记录文件URL
    company_id UUID NOT NULL,
    created_by UUID,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    started_at TIMESTAMP,
    completed_at TIMESTAMP,
    
    INDEX idx_company_id (company_id),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at)
);

COMMENT ON TABLE import_tasks IS '导入任务表';
```

#### export_tasks (导出任务表)
```sql
CREATE TABLE export_tasks (
    id UUID PRIMARY KEY,
    task_name VARCHAR(200) NOT NULL,
    task_type VARCHAR(20) NOT NULL,  -- product_export, sku_export
    filter_conditions JSONB,  -- 筛选条件（JSON格式）
    total_count INTEGER DEFAULT 0,
    status VARCHAR(20) DEFAULT 'pending',  -- pending, processing, completed, failed
    file_url VARCHAR(1000),  -- 导出文件URL
    expire_at TIMESTAMP,  -- 文件过期时间
    company_id UUID NOT NULL,
    created_by UUID,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    started_at TIMESTAMP,
    completed_at TIMESTAMP,
    
    INDEX idx_company_id (company_id),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at)
);

COMMENT ON TABLE export_tasks IS '导出任务表';
```

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 大批量导入导致系统卡顿 | 高 | 异步任务处理、限制单次导入数量 |
| 数据校验不严格导致脏数据 | 高 | 多层次校验（格式、业务规则）、错误记录 |
| 导入失败丢失数据 | 中 | 文件OSS备份、任务重试机制 |
| 导出文件占用存储空间 | 中 | 设置文件过期时间、定期清理 |

## 8. 附录

### 8.1 业务术语
- **导入模式**: 新增、更新、混合模式
- **异步任务**: 后台处理，不阻塞用户操作
- **69码**: 商品条形码，13位数字
- **断点续传**: 任务失败后可从断点继续

### 8.2 Excel库选择
- **导入**: 使用 EasyExcel（阿里开源，支持大文件流式读取）
- **导出**: 使用 EasyExcel（支持大文件流式写入）
