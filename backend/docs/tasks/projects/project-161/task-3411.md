### 2. API定义完成 ✅

#### 2.1 导出任务API (export.api)

**核心接口**:
- `POST /api/v1/export-tasks` - 创建导出任务
- `GET /api/v1/export-tasks/:taskId` - 查询任务详情
- `GET /api/v1/export-tasks` - 任务列表(分页)

**请求/响应结构**:
```go
// 创建导出任务请求
type CreateExportTaskRequest struct {
    ExportType       string                 // 01:订单 02:商品 03:库存
    FileName         string
    FileFormat       string                 // csv, excel
    FilterConditions map[string]interface{}
}

// 导出任务详情
type ExportTaskDetail struct {
    Id                 string
    FileName           string
    ExportType         string
    ExportStatus       string  // 00:待处理 01:处理中 02:已完成 03:失败
    TotalCount         int64
    ProcessedCount     int64
    ProgressPercentage float64
    TaskUrl            string   // OSS下载地址
    FileSize           int64
    ErrorMessage       string
    CreatedAt          string
    StartExportTime    string
    EndExportTime      string
}
```

#### 2.2 批量任务API (batch.api)

**核心接口**:
- `POST /api/v1/batch-tasks` - 创建批量任务(multipart/form-data)
- `GET /api/v1/batch-tasks/:taskId/progress` - 查询进度
- `GET /api/v1/batch-tasks/:taskId/result` - 下载结果

**请求/响应结构**:
```go
// 批量任务进度
type BatchTaskProgress struct {
    Id                    string
    TaskName              string
    TaskType              string
    BatchStatus           string
    TotalCount            int64
    SuccessCount          int64
    FailedCount           int64
    ProgressPercentage    float64
    EstimatedRemainingTime string
}

// 任务结果
type GetBatchTaskResultResponse struct {
    ResultFileUrl string
    Summary       TaskResultSummary
}
```
