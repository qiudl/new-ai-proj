## 二、API功能对比

### 2.1 客户管理 (Customer)

#### CMS版本 (customer_api.go)
```go
type ReqCreateCustomer struct {
    Code             string       // 客户编码
    Name             string       // 客户名称
    SapCode          string       // SAP编码
    CustomerTypeID   uint64       // 客户类型ID
    Discount         float64      // 折扣
    DefaultContactID uint64       // 默认联系人
    Channels         []api.NameID // 渠道
}
```

#### PaaS版本 (customer.go)
```go
type ReqCreateCustomer struct {
    Name          string  // 客户名称
    Phone         *string // 电话
    Email         *string // 邮箱
    Type          string  // 类型: individual/enterprise
    Source        *string // 来源
    Level         *string // 级别
    Status        string  // 状态: active/frozen/blacklist
    CategoryID    *int64  // 分类ID (替代CustomerTypeID)
    ContactPerson *string // 联系人
}
```

**增强点**:
- ✅ 增加了 `Status` 状态管理（活跃/冻结/黑名单）
- ✅ 增加了 `Level` 级别管理
- ✅ 增加了 `Source` 来源跟踪
- ✅ 直接嵌入联系人信息，简化结构
- ✅ 使用 `CategoryID` 替代 `CustomerTypeID`（更语义化）

### 2.2 价格管理 (Price)

#### CMS版本 (price_api.go)
```go
type ReqCreatePrice struct {
    Code       string    // 价格编码
    Name       string    // 价格名称
    Enabled    bool      // 是否启用
    ChannelID  uint64    // 渠道ID
    CustomerID uint64    // 客户ID
    Discount   float64   // 折扣
    StartDate  date.Date // 开始日期
    EndDate    date.Date // 结束日期
}
```

#### PaaS版本 (customer_price.go)
```go
type ReqCreateCustomerPrice struct {
    Name       string                   // 价格单名称
    CustomerID int64                    // 客户ID
    ChannelID  *int64                   // 渠道ID（可选）
    Discount   float64                  // 折扣
    StartDate  *time.Time               // 开始时间
    EndDate    *time.Time               // 结束时间
    Remark     string                   // 备注
    Items      []ReqCustomerPriceItem   // [NEW] 明细列表
}

// 响应增加审批流
type RespCustomerPrice struct {
    Status     int    // [NEW] 状态: 0草稿 1待审 2通过 3拒绝
    StatusName string // [NEW] 状态名称
    Items      []RespCustomerPriceItem // [NEW] 价格明细
}

// 审批操作
type ReqApproval struct {
    Action  string // approve/reject
    Comment string // 审批意见
}
```

**增强点**:
- ✅ 增加 `Items[]` 支持明细化价格（SKU级别定价）
- ✅ 增加 **审批工作流** (草稿→待审→通过/拒绝)
- ✅ 增加 `Remark` 备注字段
- ✅ 自动生成 `Code`（不再手动输入）

### 2.3 客户商品关系 (CustomerProduct)

#### CMS版本 (customer_spu_api.go)
```go
type ReqCreateCustomerSpu struct {
    ChannelID  int64 // 渠道ID
    CustomerID int64 // 客户ID
    SpuID      int64 // 商品ID
    Type       int   // 类型
}
```

#### PaaS版本 (customer_product.go)
```go
type ReqCreateCustomerProduct struct {
    CustomerID int64  // 客户ID
    ChannelID  *int64 // 渠道ID（可选）
    SpuID      int64  // 商品ID
    Type       int    // 类型: 0禁止购买 1允许购买
    Enabled    bool   // [NEW] 是否启用
    Sort       int    // [NEW] 排序
    Remark     string // [NEW] 备注
}

// 批量操作
type ReqBatchCreateCustomerProduct struct {
    CustomerID int64
    Items      []ReqCustomerProductBatchItem // [NEW] 批量项
}

// 访问权限检查
type ReqCheckAccess struct {
    CustomerID int64 // 客户ID
    SpuID      int64 // 商品ID
}

type RespCheckAccess struct {
    Allowed bool   // 是否允许
    Message string // 提示信息
}
```

**增强点**:
- ✅ 明确 `Type` 语义（0禁止/1允许）
- ✅ 增加 **批量操作** 支持
- ✅ 增加 **访问权限检查** API
- ✅ 增加启用状态、排序、备注字段
