## 迁移策略

### Warehouse模型迁移

#### 老代码结构
```go
type Warehouse struct {
    core.Model             // 嵌入基础字段
    Code       string      // 编码
    Name       string      // 名称
    Status     uint8       // 状态
    SortNumber int         // 排序号
    addr.Addr              // 嵌入地址字段
}
```

#### 新代码结构
```go
type Warehouse struct {
    // 标准字段
    ID        uint           `gorm:"primaryKey;autoIncrement" json:"id"`
    Code      string         `gorm:"type:varchar(50);uniqueIndex" json:"code"`
    Name      string         `gorm:"type:varchar(200);not null" json:"name"`
    Status    uint8          `gorm:"type:tinyint;not null;default:1" json:"status"`
    SortNumber int           `gorm:"type:int;default:0" json:"sort_number"`
    
    // 地址字段（展开）
    AddrCode   string         `gorm:"type:json" json:"addr_code"`       // JSON字符串
    AddrDetail string         `gorm:"type:varchar(500)" json:"addr_detail"`
    AddrFull   string         `gorm:"type:varchar(1000)" json:"addr_full"`
    
    // 时间字段
    CreatedAt time.Time      `json:"created_at"`
    UpdatedAt time.Time      `json:"updated_at"`
    DeletedAt gorm.DeletedAt `gorm:"index" json:"-"`
}
```

## 关键适配点

### 1. 字段类型调整
- `int64` → `uint`（ID字段统一使用uint）
- `*time.Time` → `gorm.DeletedAt`（软删除字段）
- `[]string` → `string`（AddrCode从切片改为JSON字符串）

### 2. 表名调整
- 老: `pms_warehouse` → 新: `warehouses`
- 老: `pms_warehouse_express` → 新: `warehouse_expresses`

### 3. GORM钩子适配
老代码中的 `BeforeSave` 钩子使用了：
- `store.GenerateCode()` - 自动生成编码
- `store.Exists()` - 检查重复
- `addr.Compute()` - 计算完整地址

**适配方案**：
- 编码生成逻辑 → 移到 `BeforeCreate` 钩子中实现
- 重复检查 → 依赖数据库唯一索引 + handler层验证
- 地址计算 → 简化或移到handler层处理

### 4. 依赖调整
```go
// 老依赖
import (
    "coolbuy3.0-backend/internal/core/core"
    "coolbuy3.0-backend/internal/core/datatype/addr"
    "coolbuy3.0-backend/internal/core/store"
)

// 新依赖
import (
    "time"
    "gorm.io/gorm"
)
```

## 技术说明

### 简化原则
新架构采用简化设计：
1. **去除审计字段**: 不需要CreatedUserID/UpdatedUserID
2. **Schema隔离**: 多租户通过Schema隔离，模型无需TenantID
3. **标准化**: 使用GORM标准类型和约定
4. **业务逻辑上移**: 复杂逻辑从Model钩子移到Handler层
