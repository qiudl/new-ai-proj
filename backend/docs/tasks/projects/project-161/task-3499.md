# 物流发货模块API设计文档（Swagger/OpenAPI 3.0）

## API概述

物流发货模块提供完整的RESTful API，支持物流单管理、发货流程、物流跟踪等功能。

## 核心API端点

### 1. 物流单管理

```yaml
/api/v1/shipments:
  get:
    summary: 查询物流单列表
    parameters:
      - name: page
      - name: page_size
      - name: status
      - name: order_no
    responses:
      200:
        description: 成功
        
  post:
    summary: 创建物流单
    requestBody:
      content:
        application/json:
          schema:
            $ref: '#/components/schemas/CreateShipmentRequest'
    responses:
      201:
        description: 创建成功

/api/v1/shipments/{id}:
  get:
    summary: 获取物流单详情
    responses:
      200:
        description: 成功
        
  delete:
    summary: 取消物流单
    responses:
      200:
        description: 取消成功
```

### 2. 物流跟踪

```yaml
/api/v1/shipments/{id}/tracks:
  get:
    summary: 获取物流轨迹
    responses:
      200:
        description: 成功
        
  post:
    summary: 同步物流轨迹
    responses:
      200:
        description: 同步成功
```

### 3. 物流商管理

```yaml
/api/v1/logistics-providers:
  get:
    summary: 查询物流商列表
    responses:
      200:
        description: 成功
```

## 数据模型

```yaml
components:
  schemas:
    Shipment:
      type: object
      properties:
        id:
          type: integer
        shipment_no:
          type: string
        order_no:
          type: string
        provider_name:
          type: string
        tracking_no:
          type: string
        status:
          type: string
          enum: [pending, shipped, in_transit, delivered, returned, cancelled]
        receiver_name:
          type: string
        receiver_phone:
          type: string
        freight_amount:
          type: string
        shipped_at:
          type: string
          format: date-time
```

## 认证与授权

所有API需要携带JWT Token和租户ID：

```
Authorization: Bearer {token}
X-Tenant-ID: 1
```

## 错误码

| HTTP状态码 | 错误场景 |
|----------|---------|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未认证 |
| 404 | 资源不存在 |
| 500 | 服务器错误 |

## 总结

本API文档提供了物流发货模块的完整接口规范，支持物流单管理、跟踪、物流商管理等核心功能。
