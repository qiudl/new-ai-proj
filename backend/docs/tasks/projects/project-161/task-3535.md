## 文档增强内容

每个接口都补充了以下标准化内容:

### 基础注解
- ✅ @Summary: 简短摘要
- ✅ @Description: 详细说明(新增)
- ✅ @Tags: sys-user
- ✅ @Accept: json (新增)
- ✅ @Produce: json (新增)

### 参数文档
- ✅ @Param: 详细的参数说明和约束
- ✅ 参数类型修正 (path vs query)
- ✅ 参数描述优化 (更清晰的中文说明)

### 响应文档
- ✅ @Success: 成功响应 + 数据结构
- ✅ @Failure 400: 请求参数错误 (新增)
- ✅ @Failure 401: 未授权 (新增)
- ✅ @Failure 404: 资源不存在 (新增,适用场景)
- ✅ @Failure 409: 资源冲突 (新增,适用场景)
- ✅ @Failure 500: 内部服务器错误 (新增)

### 安全认证
- ✅ @Security: ApiKeyAuth
- ✅ @Router: 正确的路由路径

## 修复的问题

1. **路径参数类型错误**
   - Get 接口的 @Param id 从 query 改为 path

2. **路由路径不一致**
   - Status 接口: `:id/status` → `{id}/status`
   - CheckUser 接口: `check_username` → `check-username`
   - ChangePassword 接口: 移除多余的 `{id}` 参数

3. **缺少必要的注解**
   - 所有接口添加了 @Accept 和 @Produce
   - 所有接口添加了详细的 @Description
   - 所有接口添加了完整的 @Failure 错误响应

4. **参数描述不清晰**
   - 优化了所有参数的中文描述
   - 添加了默认值说明
   - 添加了取值范围说明
