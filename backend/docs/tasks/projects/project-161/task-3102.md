### 2.2 GenerateCode功能分析

**功能特点**:
- 插入时编码为空则自动生成：`格式 + 时间戳 + 序号`
- 编码格式验证：只允许字母和数字
- 编码唯一性检查（同租户内）
- 编码转大写
- 更新时验证编码（如果修改了code字段）

**生成格式**: `001202510311030450001`
- `001`: 固定前缀
- `20251031103045`: 时间戳（YYYYMMDDHHmmss）
- `0001`: 序号（4位，基于当前记录数+1）

### 3.3 BeforeSave钩子实现

```go
func (e *Express) BeforeSave(tx *gorm.DB) error {
    // 1. 自动生成编码（仅插入时且编码为空）
    if tx.Statement.Schema != nil {
        if _, ok := tx.Statement.Clauses["INSERT"]; ok && e.Code == "" {
            var count int64
            tx.Model(&Express{}).Unscoped().Count(&count)
            timestamp := time.Now().Format("20060102150405")
            e.Code = fmt.Sprintf("001%s%04d", timestamp, count+1)
        }
    }

    // 2. 编码转大写
    e.Code = strings.ToUpper(e.Code)

    // 3. 验证编码格式
    validCode := regexp.MustCompile(`^[A-Z0-9]+$`)
    if !validCode.MatchString(e.Code) {
        return fmt.Errorf("express code must contain only letters and numbers")
    }

    // 4. 检查编码唯一性
    var exists int64
    query := tx.Model(&Express{}).Where("code = ?", e.Code)
    if e.ID > 0 {
        query = query.Where("id != ?", e.ID)
    }
    if err := query.Count(&exists).Error; err != nil {
        return err
    }
    if exists > 0 {
        return fmt.Errorf("express code already exists: %s", e.Code)
    }

    return nil
}
```

**功能特点**:
1. ✅ 自动生成编码（插入时编码为空）
2. ✅ 编码格式验证（只允许大写字母和数字）
3. ✅ 编码唯一性检查（当前Schema内）
4. ✅ 编码转大写
5. ✅ 更新时验证（BeforeUpdate钩子）

### 3.4 BeforeUpdate钩子

```go
func (e *Express) BeforeUpdate(tx *gorm.DB) error {
    // 更新时如果修改了编码，需要重新验证
    if tx.Statement.Changed("Code") {
        return e.BeforeSave(tx)
    }
    return nil
}
```

### 5.1 编码生成算法

**优点**:
- 时间戳保证时序性
- 序号保证唯一性

- **编码唯一性**: 在Schema级别保证（不同租户可有相同编码）
