## 1. 服务概述

### 1.1 服务职责

**业务服务 (Business Service)** 是PaaS平台的核心业务逻辑层,负责处理所有业务领域的功能:

- **主数据管理**: 基础数据(Biz)、客户(CMS)、商品(PRD)
- **业务流程**: 定价(Cool)、订单(Mall)、仓储(Wh)、财务(FMS)
- **扩展点管理**: 品牌差异化扩展(Extension)
- **多租户隔离**: Schema级别的数据隔离
- **事件发布**: 业务事件发布到消息队列

### 1.2 技术栈

```yaml
语言框架:
  - Go 1.23+
  - Gin 1.10+ (HTTP框架)
  - GORM v2 (ORM)
  - gRPC 1.58+ (服务间通信)

数据存储:
  - PostgreSQL 16+ (主数据库)
  - Redis 7+ (缓存)

消息队列:
  - RabbitMQ 3.12+

服务发现:
  - Consul / Kubernetes Service
```
