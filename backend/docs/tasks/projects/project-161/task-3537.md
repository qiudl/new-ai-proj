# 用户头像上传功能技术文档

## 功能概述

实现了完整的用户头像上传功能，包括本地文件上传、图片存储、头像更新等功能。

## 后端实现

### 1. 文件上传服务

**文件**: `/pkg/upload/upload.go`

创建了通用的文件上传服务，支持：
- 文件类型验证（图片格式：jpg, jpeg, png, gif, webp）
- 文件大小限制
- 唯一文件名生成（UUID）
- 按日期分目录存储
- 本地文件存储

```go
type LocalUploader struct {
    BaseDir     string // 基础目录
    MaxFileSize int64  // 最大文件大小（字节）
    URLPrefix   string // URL前缀
}

// 核心方法
func (u *LocalUploader) Upload(file multipart.File, header *multipart.FileHeader, fileType FileType) (string, error)
func (u *LocalUploader) Delete(filePath string) error
func (u *LocalUploader) GetURL(filePath string) string
```

**存储路径规则**: `uploads/images/YYYY/MM/DD/uuid.ext`

### 2. 上传Controller

**文件**: `/internal/common/ctrl/upload.go`

#### UploadImage 接口

- **路由**: `POST /api/v1/upload/image`
- **功能**: 上传图片文件
- **请求**: multipart/form-data，字段名为 `file`
- **响应**:
  ```json
  {
    "url": "/static/uploads/images/2024/01/02/uuid.jpg",
    "path": "uploads/images/2024/01/02/uuid.jpg"
  }
  ```
- **验证**: 
  - 图片格式：jpg, jpeg, png, gif, webp
  - 大小限制：配置文件中的 `storage.allow-size`（默认10MB）

### 3. 用户头像更新

**Controller**: `/internal/auth/ctrl/sys_user.go`

#### UpdateAvatar 方法

- **路由**: `PUT /api/v1/user/self/avatar`
- **功能**: 更新当前登录用户的头像
- **请求体**:
  ```json
  {
    "avatar": "/static/uploads/images/2024/01/02/uuid.jpg"
  }
  ```
- **权限**: 需要登录认证

**Business Logic**: `/internal/auth/biz/sys_user.go`

```go
func (b *SysUserBiz) UpdateAvatar(ctx context.Context, userID int64, avatar string) error {
    // 更新用户avatar字段
    result := b.db.WithContext(ctx).Model(&model.SysUserModel{}).
        Where("id = ?", userID).
        Update("avatar", avatar)
    
    // 错误处理
    if result.Error != nil {
        return result.Error
    }
    if result.RowsAffected == 0 {
        return fmt.Errorf("用户不存在")
    }
    
    return nil
}
```

### 4. 静态文件服务

**文件**: `/internal/router/router.go`

配置静态文件路由，允许访问上传的图片：

```go
r.Static("/static/uploads", storageDir+"/uploads")
```

访问URL示例: `http://localhost:7090/static/uploads/images/2024/01/02/uuid.jpg`

### 5. 配置文件

**文件**: `configs/config.yaml`

```yaml
storage:
  dir: "./storage"           # 存储目录
  allow-size: "10MB"         # 允许的最大文件大小
```

## 前端实现

### 1. API接口定义

**文件**: `/web/src/api/modules/system.ts`

#### 类型定义

```typescript
export interface UploadImageResponse {
  url: string;  // 图片访问URL
  path: string; // 图片存储路径
}
```

#### API方法

**uploadImage** - 上传图片
```typescript
export const uploadImage = async (file: File) => {
  const formData = new FormData();
  formData.append('file', file);
  return handleApiResponse(
    unifiedApi.service('system').post<{ data: UploadImageResponse; count: number }>(
      '/upload/image',
      formData,
      {
        headers: {
          'Content-Type': 'multipart/form-data',
        },
      }
    )
  );
};
```

**updateUserAvatar** - 更新用户头像
```typescript
export const updateUserAvatar = async (avatar: string) => {
  return handleApiResponse(
    unifiedApi.service('system').put<{ data: null; count: number }>(
      '/user/self/avatar', 
      { avatar }
    )
  );
};
```

## 使用流程

### 上传头像流程

1. **用户选择图片**: 通过Upload组件选择本地图片文件
2. **前端上传**: 调用 `uploadImage(file)` 上传到服务器
3. **服务器处理**: 
   - 验证图片格式和大小
   - 生成唯一文件名
   - 保存到 `storage/uploads/images/YYYY/MM/DD/` 目录
   - 返回访问URL和存储路径
4. **更新头像**: 调用 `updateUserAvatar(url)` 更新用户头像字段
5. **显示头像**: 在UI中显示新头像

## 技术亮点

### 后端

1. **模块化设计**: 独立的upload包，可复用

4. **唯一性保证**: UUID文件名，避免冲突
5. **配置灵活**: 支持配置文件大小限制和存储目录

### 前端

1. **TypeScript类型**: 完整的类型定义
2. **错误处理**: 统一的错误处理机制
3. **用户体验**: 进度显示、预览功能

## API文档

### 上传图片

```
POST /api/v1/upload/image
Content-Type: multipart/form-data
Authorization: Bearer {token}

Request:
- file: 图片文件

Response:
{
  "code": 0,
  "message": "success",
  "data": {
    "url": "/static/uploads/images/2024/01/02/uuid.jpg",
    "path": "uploads/images/2024/01/02/uuid.jpg"
  }
}
```

### 更新用户头像

```
PUT /api/v1/user/self/avatar
Content-Type: application/json
Authorization: Bearer {token}

Request:
{
  "avatar": "/static/uploads/images/2024/01/02/uuid.jpg"
}

Response:
{
  "code": 0,
  "message": "success",
  "data": null
}
```
