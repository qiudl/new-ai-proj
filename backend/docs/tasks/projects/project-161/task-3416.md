## 🔑 关键配置

### Docker多阶段构建

```dockerfile
# 构建阶段
FROM golang:1.21-alpine AS builder
RUN CGO_ENABLED=0 GOOS=linux go build -ldflags="-w -s" -o /app/task-api

# 运行阶段
FROM alpine:latest
COPY --from=builder /app/task-api .
```

**优势**:
- 镜像体积小（~20MB vs ~800MB）
- 不包含构建工具，更安全
- 静态编译，无依赖
