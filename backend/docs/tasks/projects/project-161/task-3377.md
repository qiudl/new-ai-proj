# 仓库库存模块API设计文档（Swagger）

## 1. 概述

### 1.1 文档说明

本文档基于 OpenAPI 3.0 规范，详细描述仓库库存模块的所有 RESTful API 接口，包括仓库管理、库存查询、入库管理、出库管理、统计报表等核心功能的完整 API 定义。

### 1.2 设计规范

- **API 版本**: v1
- **基础路径**: `/api/v1`
- **认证方式**: JWT Bearer Token
- **Content-Type**: `application/json`
- **字符编码**: UTF-8
- **HTTP 状态码**: 遵循 RESTful 规范

### 1.3 OpenAPI 基础信息


```yaml
components:
  securitySchemes:

      scheme: bearer
      bearerFormat: JWT

        使用 JWT Token 进行身份认证。
        在请求头中添加: Authorization: Bearer <token>

  - BearerAuth: []
```

```yaml
components:
  parameters:
    TenantID:
      name: X-Tenant-ID
```

## 3. 仓库管理 API

### 3.1 仓库列表查询

```yaml
paths:
  /warehouses:
    get:
      tags:
        - 仓库管理
      summary: 查询仓库列表
      description: 获取仓库列表，支持分页和筛选
      parameters:
        - $ref: '#/components/parameters/TenantID'
        - name: page
          in: query
          schema:
            type: integer
            minimum: 1
            default: 1
        - name: page_size
          in: query
          schema:
            type: integer
            minimum: 1
            maximum: 100
            default: 20
        - name: name
          in: query
          description: 仓库名称模糊搜索
          schema:
            type: string
        - name: code
          in: query
          description: 仓库编码搜索
          schema:
            type: string
        - name: type
          in: query
          description: 仓库类型
          schema:
            type: string
            enum: [normal, transit, return, quarantine]
        - name: is_enabled
          in: query
          description: 启用状态
          schema:
            type: boolean
      responses:
        '200':
          description: 成功
          content:
            application/json:
              schema:
                type: object
                properties:
                  data:
                    type: object
                    properties:
                      count:
                        type: integer
                        example: 50
                      data:
                        type: array
                        items:
                          $ref: '#/components/schemas/Warehouse'
        '400':
          $ref: '#/components/responses/BadRequest'
        '401':
          $ref: '#/components/responses/Unauthorized'
      security:
        - BearerAuth: []
```
