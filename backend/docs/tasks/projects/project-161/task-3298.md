#### 2. PermissionButton - role属性类型冲突
**文件**: `src/components/common/PermissionButton/index.tsx:10`
**错误**: Types of property 'role' are incompatible
**修复**: 使用Omit排除ButtonProps中的role属性
```typescript
// Before
interface PermissionButtonProps extends ButtonProps {
  role?: string | string[];
}

// After
interface PermissionButtonProps extends Omit<ButtonProps, 'role'> {
  role?: string | string[]; // 自定义role属性，用于权限控制（非HTML aria-role）
}
```

#### 3-4. ImportExport - 隐式any类型
**文件**: `src/components/common/ImportExport/index.tsx:133,209`
**错误**: Element implicitly has an 'any' type / Parameter 'ext' implicitly has an 'any' type
**修复**: 为formatConfig添加明确类型定义
```typescript
// Before
const formatConfig = {
  xlsx: { icon: <FileExcelOutlined />, ... }
};

// After
const formatConfig: Record<string, {
  icon: React.ReactElement;
  color: string;
  name: string;
  extensions: string[];
}> = {
  xlsx: { icon: <FileExcelOutlined />, ... }
};

// 为ext参数添加类型
formatConfig[format].extensions.some((ext: string) => ...)
```

## 修复指南

### 1. 隐式any类型修复
```typescript
// ❌ 错误
function search Items(items) {
  return items.filter(...)
}

// ✅ 正确
function searchItems(items: MenuItem[]): MenuItem[] {
  return items.filter(...)
}
```

### 2. 类型不兼容修复
```typescript
// ❌ 错误  
interface Props extends ButtonProps {
  role?: string;  // 与ButtonProps中的role(AriaRole)冲突
}

// ✅ 正确
interface Props extends Omit<ButtonProps, 'role'> {
  role?: string;
}
```

### 3. 缺失属性修复
```typescript
// ❌ 错误
const menu: MenuItem = {

```
