## 技术深度分析

### 架构发现：全局DB模式

**Store层使用模式**:
```go
// pkg/common/store/store.go
var db *gorm.DB  // 全局变量

func Init(gormDB *gorm.DB) { db = gormDB }
func DB() *gorm.DB { return db }
```

**utils.Database嵌入**:
```go
// pkg/common/utils/core_store.go
type Database struct{}

func (s Database) DB() *gorm.DB {
    return store.DB()  // 调用全局DB
}

type Store[T any] struct {
    Database  // 嵌入Database
}
```

**影响**:
- ✅ 简化Store使用（无需传DB参数）
- ⚠️ 测试必须初始化全局DB
- ⚠️ 无法并行运行测试（共享全局状态）

### Biz层Store初始化问题

```go
type SysUserBiz struct {
    db       *gorm.DB
    user     store.SysUserStore      // 零值，依赖全局DB
    tenant   tenantStore.SysTenantStore  // 零值
    city     *store.SysCityStore     // 指针Store
}

func NewSysUserBiz(db *gorm.DB) *SysUserBiz {
    return &SysUserBiz{
        db:   db,  // 只存储局部DB
        city: &store.SysCityStore{},  // 初始化指针Store
        // user和tenant未初始化，为零值
    }
}
```

**发现**: 
- 非指针Store字段依赖全局DB
- 指针Store字段显式初始化（也用全局DB）
