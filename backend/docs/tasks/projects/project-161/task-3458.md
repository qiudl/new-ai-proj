# Coolbuy 3.0 定价模块产品需求文档 (PRD)

## 文档信息
- **文档类型**: Product Requirements Document
- **产品名称**: Coolbuy 3.0 定价模块
- **文档版本**: v1.0
- **创建日期**: 2025-11-05
- **项目优先级**: P1

---

## 1. 产品概述

### 1.1 产品背景

**业务痛点**:
1. **定价效率低**: 手动维护10万+SKU价格，工作量巨大
2. **价格错误率高**: 人工计算折扣易出错，导致客户投诉  
3. **多品牌管理复杂**: 李宁、百丽、波司登定价规则各异
4. **客户体验差**: 价格查询慢（>500ms），购物车计算卡顿

**市场机会**:
- B2B电商市场快速增长，预计2025年GMV突破10亿
- 鞋服品牌数字化转型需求强烈
- 竞品定价功能较弱，存在差异化空间

---

### 1.2 产品目标

**核心目标**:
1. **提升定价效率**: 价格设置效率提升50%
2. **降低错误率**: 价格错误率从5%降至<0.1%
3. **提升性能**: 查询响应时间从500ms降至<100ms (P95)
4. **增强用户体验**: 用户满意度从3.2分提升至4.5分/5.0

**业务指标**:
- 日均价格查询量: 100万次
- 活跃品牌数: 50+
- 活跃客户数: 10000+
- SKU覆盖数: 200000+

---

### 1.3 成功指标

| 指标类别 | 指标名称 | 当前值 | 目标值 |
|----------|----------|--------|--------|
| **效率** | 价格设置效率 | 100条/小时 | 200条/小时 |
| **准确性** | 价格错误率 | 5% | <0.1% |
| **性能** | 查询响应时间 | 500ms | <100ms |
| **满意度** | 用户满意度 | 3.2/5.0 | >4.5/5.0 |

## 2. 用户角色与场景

### 2.1 品牌运营经理
- **年龄**: 28-45岁
- **职位**: 品牌方运营总监/经理
- **技术水平**: 中等，熟练使用Excel

**核心需求**:
1. 为全国代理商设置差异化价格策略
2. 快速调整价格应对市场变化
3. 监控价格执行情况和异常

**使用场景**:
> 李宁品牌运营经理张总需要为冬季促销设置价格。一级代理商7.5折，二级8折，三级8.5折。涉及5000+个SKU，需3天内完成。

---

### 2.2 平台运营专员
- **年龄**: 23-35岁
- **技术水平**: 高，熟练使用后台系统

**核心需求**:
1. 批量导入品牌方提供的价格Excel文件
2. 处理价格导入异常和错误
3. 维护日常价格数据

**使用场景**:
> 运营专员小王收到百丽Q4价格表（8000行）。导入时500条失败，提示"SKU不存在"，需快速定位问题SKU。

---

### 2.3 采购商/经销商
- **年龄**: 25-50岁
- **技术水平**: 低-中等，主要使用手机APP

**核心需求**:
1. 快速查询商品价格
2. 查看专属价格和折扣
3. 对比不同商品价格

**使用场景**:
> 经销商李老板扫码查询李宁跑鞋价格。作为一级代理商，期望看到7.5折价格（吊牌价500元，折后375元）。但系统响应慢，等了15秒。

---

### 2.4 系统管理员
- **年龄**: 25-40岁
- **技术水平**: 高，精通系统运维

**核心需求**:
1. 监控价格系统健康状态
2. 处理价格异常告警
3. 导出价格数据分析

**使用场景**:
> 运维工程师小张收到告警：过去1小时价格异常记录增至200条（正常<10条）。需快速定位哪个品牌、哪些SKU异常。

## 3. 功能需求详细说明

### FR-1: 价格模板管理

#### FR-1.1 创建价格模板

**功能流程**:
1. 进入"价格管理" → "价格模板"
2. 点击"新建模板"
3. 填写信息（客户等级、品牌、模板名称、生效时间）
4. 保存后跳转到明细编辑页

**UI线框图**:
```
┌─────────────────────────────────────┐
│  价格管理 > 新建模板                 │
├─────────────────────────────────────┤
│  客户等级: [一级代理商 ▼]           │
│  品牌:     [李宁        ▼]           │
│  模板名称: [___________________]    │
│  生效时间: [2025-01-01  📅]         │
│                                     │
│  [取消]      [保存并添加明细]        │
└─────────────────────────────────────┘
```

**验收标准**:
- [ ] 模板创建成功，生成唯一ID
- [ ] 操作日志记录创建人和时间
- [ ] 同一品牌+客户等级不允许重复创建

---

#### FR-1.2 编辑价格模板

**功能点**:
- 修改模板名称
- 修改生效时间
- 启用/禁用模板
- 查看创建/修改历史

**约束**:
- 已生效的模板不允许修改客户等级和品牌
- 修改后记录版本号（乐观锁）

---

#### FR-1.3 删除价格模板

**功能点**:
- 软删除（逻辑删除）
- 删除前二次确认
- 同时删除价格明细

### FR-3: 价格查询

#### FR-3.1 单个SKU价格查询

**API接口**:
```http
GET /api/v1/pricing/sku/{sku_id}?company_id={id}&level_id={id}

Response:
{
  "sku_id": "SKU20250001",
  "sale_price": 425.00,
  "market_price": 500.00,
  "discount_rate": 0.85,
  "price_source": "CUSTOMER_LEVEL",
  "customer_level": "一级代理商",
  "calculated_at": "2025-11-05T12:00:00Z"
}
```

**性能要求**:
- P50 < 50ms
- P95 < 100ms
- P99 < 200ms

---

#### FR-3.2 批量价格查询

**API接口**:
```http
POST /api/v1/pricing/batch

Request:
{
  "sku_ids": ["SKU001", "SKU002", ...],  // 最多100个
  "company_id": "company_123",
  "customer_level_id": "level_01"
}

Response:
{
  "prices": [
    {"sku_id": "SKU001", "sale_price": 425.00},
    {"sku_id": "SKU002", "sale_price": 382.50}
  ],
  "total_count": 100,
  "query_time_ms": 85
}
```

**约束**:
- 单次查询最多100个SKU
- 响应时间 < 200ms (P95)
- 支持Redis缓存

### FR-4: 价格异常监控

#### FR-4.1 价格异常记录

**异常类型**:
1. **价格过低**: 销售价 < 成本价
2. **价格过高**: 销售价 > 吊牌价×1.2
3. **折扣异常**: 折扣率 <10% 或 >99%
4. **吊牌价缺失**: 选择"吊牌价折扣"但吊牌价为空
5. **计算错误**: 价格计算过程出错

**监控面板**:
```
┌──────────────────────────────────┐
│  价格异常监控    [刷新] [导出]   │
├──────────────────────────────────┤
│  今日统计                        │
│  总异常: 23  已解决: 15  待处理: 8│
│                                  │
│  异常趋势 [折线图]               │
│                                  │
│  异常列表                        │
│  ┌────────────────────────────┐ │
│  │时间  │类型   │SKU  │操作  │ │
│  ├────────────────────────────┤ │
│  │12:01│价格低│001 │处理  │ │
│  │11:45│折扣异│002 │处理  │ │
│  │11:30│已解决│003 │详情  │ │
│  └────────────────────────────┘ │
└──────────────────────────────────┘
```

---

#### FR-4.2 异常告警

**告警规则**:
- 异常数 > 100/小时 → 邮件/短信告警
- 单品牌异常数 > 50/小时 → 通知品牌运营
- 价格过低异常 → 立即告警（P0）

**告警渠道**:
- 邮件
- 短信（仅P0告警）
- 企业微信/钉钉
- 站内消息

- **系统可用性**: 99.9% (允许每月宕机43分钟)

- **RPO** (数据恢复点): < 5分钟

- **API限流**: 单用户QPS限制50

- **多品牌支持**: 支持50+品牌，每个品牌独立配置
- **新定价策略**: 支持扩展新策略（配置化）

## 7. 附录

### 7.1 术语表

| 术语 | 定义 |
|------|------|
| SKU | Stock Keeping Unit，库存量单位，商品的最小销售单位 |
| 吊牌价 | 商品标签上的官方零售价，也称市场价 |
| 成本价 | 品牌方采购或生产成本 |
| 销售价 | 实际销售给客户的价格 |
| 客户等级 | 一级/二级/三级代理商 |
| 价格模板 | 为某个客户等级预设的价格策略配置 |
| 定价策略 | 计算价格的方法，如固定价、折扣价等 |
