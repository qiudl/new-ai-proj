#### 2.2 分类标准制定
**测试类型分类标准**:
```
FUNC - 功能测试 (蓝色标识)
PERF - 性能测试 (黄色标识)  
SEC - 安全测试 (红色标识)
COMP - 兼容性测试 (绿色标识)
INT - 集成测试 (紫色标识)
UI - 界面测试 (橙色标识)
API - 接口测试 (青色标识)
```

**业务模块分类标准**:
```
SYS - 系统管理 (P0优先级)
PMS - 商品管理 (P0优先级)
OMS - 订单管理 (P0优先级)
CMS - 客户管理 (P1优先级)
FMS - 财务管理 (P1优先级)
WMS - 仓储管理 (P2优先级)
RMS - 报表管理 (P2优先级)
NMS - 通知管理 (P2优先级)
```

**ID生成规则**:
```
格式: TC_[测试类型]_[业务模块]_[序号]
示例: TC_FUNC_SYS_001

序号分配规则:
001-099: 基础功能测试
100-199: 异常场景测试  
200-299: 边界条件测试
300-399: 性能相关测试
400-499: 安全相关测试
500-599: 兼容性测试
600-699: 集成测试
700-799: 界面测试
800-899: 接口测试
900-999: 其他专项测试
```
