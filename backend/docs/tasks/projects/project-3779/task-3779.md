# Figma 设计展示模块开发方案

## 📋 项目概述

### 目标
开发一个能够在 AI Project Management System 中展示和集成 Figma 设计的模块，支持：
- 展示 Figma 设计稿和原型
- 关联设计与开发任务
- 从设计自动生成代码
- 设计变更追踪

### 设计来源
- **Figma Make 项目**: [PasS系统后台管理页](https://www.figma.com/make/jkwzMXlUVRf6TqOQrO9AiW/PasS系统后台管理页?node-id=0-1&t=fuZu5uC4mOQWbMjT-1)
- **文件类型**: Figma Make（交互原型）
- **fileKey**: jkwzMXlUVRf6TqOQrO9AiW

## 🎯 功能需求

### 1. Figma 资源集成
- **Make 项目资源提取**: 支持通过 MCP 从 Figma Make 项目获取设计上下文
- **设计文件展示**: 嵌入 Figma 查看器展示设计稿
- **资源列表**: 列出 Make 项目中的所有文件和组件
- **资源下载**: 下载设计资源用于开发

### 2. 设计与任务关联
- **设计链接绑定**: 任务可以关联多个 Figma 设计链接
- **设计版本管理**: 追踪设计的版本变更
- **设计评审**: 支持对设计进行评论和反馈
- **自动同步**: 设计更新时自动提醒相关开发者

### 3. 代码生成功能
- **组件代码生成**: 从 Figma 节点生成 React/Vue 代码
- **样式提取**: 提取设计系统变量（颜色、字体、间距）
- **设计规范**: 生成设计规范文档
- **组件映射**: 建立 Figma 组件与代码组件的映射关系

### 4. 工作流集成
- **原型 → 任务**: 从 Make 原型自动创建开发任务
- **设计 → 代码**: 一键生成组件代码
- **设计评审流程**: 设计审核通过后自动创建开发任务
- **设计变更通知**: 设计更新时通知相关人员

## 📊 数据库设计

### figma_design_links 表
```sql
CREATE TABLE figma_design_links (
    id SERIAL PRIMARY KEY,
    task_id INTEGER REFERENCES tasks(id),
    figma_url TEXT NOT NULL,
    file_key VARCHAR(100) NOT NULL,
    node_id VARCHAR(50),
    version VARCHAR(50),
    type VARCHAR(20) DEFAULT 'design',
    status VARCHAR(20) DEFAULT 'draft',
    metadata JSONB,
    created_by INTEGER REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### figma_resource_cache 表
```sql
CREATE TABLE figma_resource_cache (
    id SERIAL PRIMARY KEY,
    file_key VARCHAR(100) NOT NULL,
    node_id VARCHAR(50),
    resource_type VARCHAR(50),
    content TEXT,
    metadata JSONB,
    expires_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(file_key, node_id, resource_type)
);
```
