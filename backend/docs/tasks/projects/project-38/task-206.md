# 192-2: 成本录入表格组件开发

## 任务描述
## 任务目标
开发核心的成本录入表格组件，支持多行成本数据的录入和编辑

## 具体工作
1. **表格组件设计**: 使用Ant Design Table组件，支持可编辑单元格
2. **成本项动态配置**: 
   - 燃油费(fuel_cost)
   - 司机费用(driver_fee) 
   - 过路费(toll_fee)
   - 装卸费(loading_fee)
   - 维护费(maintenance_fee)
   - 其他成本(other_cost)
3. **数据结构设计**: 定义CostItem接口，包含成本类型、名称、单价、数量、总金额
4. **输入验证**: 实时验证数字格式、必填项、计算总金额
5. **批量操作**: 支持添加行、删除行、清空表格、批量导入
6. **用户交互优化**: Tab键导航、Enter确认、自动计算

## 技术要求
- TypeScript类型安全
- 响应式表格设计
- 数据双向绑定
- 防抖输入处理
- 金额格式化显示

## 验收标准
- [ ] 表格支持多行数据录入
- [ ] 单价×数量自动计算总金额
- [ ] 输入验证正确提示
- [ ] 批量操作功能完整
- [ ] 用户交互体验良好
- [ ] 支持键盘快捷操作
