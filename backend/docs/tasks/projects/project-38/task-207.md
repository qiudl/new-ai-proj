# 192-3: API集成和数据管理

## 任务描述
## 任务目标
集成后端API，实现成本数据的提交、查询和状态管理

## 具体工作
1. **API服务封装**: 
   - POST /api/v1/waybills/{id}/costs (提交成本数据)
   - GET /api/v1/waybills/{id}/cost-summary (查询成本汇总)
   - 错误处理和重试机制
2. **状态管理**: 使用Pinia管理成本录入状态
   - loading状态管理
   - 数据缓存机制
   - 表单数据持久化
3. **数据验证**: 前端数据校验，与后端保持一致
   - 成本项数量限制(≤50项)
   - 金额范围验证
   - 必填项检查
4. **异步处理**: 
   - 自动保存功能
   - 网络异常处理
   - 并发请求控制
5. **用户反馈**: 
   - 加载状态提示
   - 成功/失败消息
   - 进度指示器

## 技术要求
- Axios封装API请求
- Pinia状态管理
- TypeScript接口定义
- Promise异常处理
- 防重复提交机制

- [ ] 成本数据提交成功
- [ ] API错误处理完善
- [ ] 状态管理正确
- [ ] 用户反馈及时准确
