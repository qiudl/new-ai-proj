# 191-3: 成本汇总查询API实现(GET)

## 任务描述
## 任务目标
完整实现GET /api/v1/waybills/{id}/cost-summary API，提供完善的成本汇总信息。

## 具体工作
1. **成本汇总计算**: 实现总成本、干线成本、补充成本的分类统计
2. **成本分解展示**: 按成本类型分组统计，提供详细的成本构成信息
3. **托运单成本分配**: 展示各托运单的成本分配情况
4. **数据格式优化**: 确保返回的数据结构清晰、完整
5. **缓存优化**: 对复杂查询进行适当缓存
6. **性能测试**: 确保查询响应时间满足要求

## 验收标准
- [ ] 成本汇总计算准确
- [ ] 成本分解信息完整
- [ ] 托运单成本展示正确
- [ ] API响应时间 < 300ms
- [ ] 数据格式规范
