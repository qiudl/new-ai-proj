## 已知问题和注意事项

### 已知限制

1. **邮件发送**:
   - 需要配置SMTP服务器
   - 开发模式下不发送实际邮件
   - Gmail需要使用应用专用密码

2. **速率限制**:
   - 按用户限制，不是按IP
   - 时间窗口为1小时滚动窗口

3. **令牌存储**:
   - 令牌原始值只在创建时可见
   - 数据库只存储哈希值

### 配置要求

**SMTP配置** (生产环境):
```bash
EMAIL_ENABLED=true
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your-email@gmail.com
SMTP_PASSWORD=your-app-password
SMTP_FROM_EMAIL=noreply@aiproj.com
SMTP_FROM_NAME=AI-Proj Team
FRONTEND_URL=https://yourdomain.com
```

**开发模式**:
```bash
EMAIL_ENABLED=false
# 邮件内容会记录到日志
# 重置链接会显示在日志中
```

### 数据库维护

**定期清理过期令牌**:
```sql
-- 清理7天前的过期令牌
DELETE FROM password_reset_tokens
WHERE created_at < NOW() - INTERVAL '7 days'
  AND status IN ('expired', 'used', 'revoked');
```

**定期清理旧密码历史**:
```sql
-- 保留90天内的密码历史
DELETE FROM password_history
WHERE created_at < NOW() - INTERVAL '90 days';
```

### 监控建议

**关键指标**:
1. 密码重置请求数量（每小时/每天）
2. 重置成功率（used tokens / total tokens）
3. 令牌过期率
4. 平均令牌使用时间（从创建到使用）
5. 速率限制触发次数
6. 邮件发送失败次数

**SQL查询**:
```sql
-- 今日重置统计
SELECT
    COUNT(*) as total_requests,
    COUNT(CASE WHEN status = 'used' THEN 1 END) as successful_resets,
    COUNT(CASE WHEN status = 'expired' THEN 1 END) as expired_tokens,
    ROUND(100.0 * COUNT(CASE WHEN status = 'used' THEN 1 END) / COUNT(*), 2) as success_rate
FROM password_reset_tokens
WHERE created_at >= CURRENT_DATE;
```
