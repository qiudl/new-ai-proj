## 📈 数据流程图

### 密码修改审计流程

```
用户 → ChangePassword Handler
  ↓ 验证旧密码
  ↓ 检查密码历史
  ↓ 更新密码
  ↓
  ├─→ 记录到 password_history 表
  │   (包含IP、UA、change_reason)
  │
  └─→ 记录到 audit_logs 表
      (包含user_id、action、IP)
```

### 密码重置审计流程

```
忘记密码 → ForgotPassword Handler
  ↓ 创建令牌
  ↓
  ├─→ 记录到 password_reset_tokens 表
  │   (包含IP、UA、状态)
  │
  ├─→ 记录到 audit_logs 表
  │   (action: password_reset_requested)
  │
  └─→ 发送重置邮件
      (包含链接和安全提示)

重置密码 → ResetPassword Handler
  ↓ 验证令牌
  ↓ 检查密码历史
  ↓ 更新密码
  ↓
  ├─→ 更新 password_reset_tokens 表
  │   (状态: used, reset_ip, reset_ua)
  │
  ├─→ 记录到 password_history 表
  │   (change_reason: admin_reset)
  │
  ├─→ 记录到 audit_logs 表
  │   (action: password_reset_completed)
  │
  └─→ 发送成功通知邮件
      (包含重置时间和IP)
```

## 🔍 审计日志查询示例

### 查询所有密码相关操作

```sql
SELECT
    id,
    user_id,
    action,
    entity_type,
    details,
    ip_address,
    user_agent,
    created_at
FROM audit_logs
WHERE action IN (
    'change_password',
    'password_reset_requested',
    'password_reset_completed'
)
ORDER BY created_at DESC
LIMIT 100;
```

### 查询特定用户的密码历史

```sql
SELECT
    id,
    user_id,
    change_reason,
    ip_address,
    user_agent,
    created_at
FROM password_history
WHERE user_id = 1
ORDER BY created_at DESC
LIMIT 10;
```

### 查询密码重置活动

```sql
SELECT
    id,
    user_id,
    email,
    status,
    created_at,
    expires_at,
    used_at,
    ip_address,
    reset_ip_address
FROM password_reset_tokens
WHERE created_at >= NOW() - INTERVAL '7 days'
ORDER BY created_at DESC;
```
