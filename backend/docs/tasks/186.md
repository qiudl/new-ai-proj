  遇到的特殊情况和解决方案

  1. API响应格式不一致问题
    - 情况: 后端可能返回{data, total}或标准的{data, pagination: {total}}格式
    - 分析: axios拦截器已经解包响应，需要适配多种格式
    - 解决: 通过类型保护检查'pagination' in responseData来适配两种格式
  2. TypeScript严格类型检查错误
    - 情况: Property 'success' does not exist on type 'AxiosResponse'
    - 分析: API拦截器返回的是解包后的数据，不是标准AxiosResponse
    - 解决: 使用as unknown as进行安全的类型断言
  3. Ant Design组件属性兼容性问题
    - 情况: size="small"等属性在某些组件中不支持
    - 分析: 版本差异导致的API变化
    - 解决: 移除不支持的属性，使用默认样式
  4. CSS样式注入问题
    - 情况: styled-jsx语法报错 Type '{ jsx: true; }' is not assignable
    - 分析: TypeScript配置或styled-jsx版本兼容性问题
    - 解决: 改用dangerouslySetInnerHTML注入CSS，保持样式隔离
