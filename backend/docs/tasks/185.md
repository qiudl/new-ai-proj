  B. 循环依赖检测算法
  - 位置: backend/database/task_repository.go:660-696
  - 集成点: backend/main.go:1887-1899

  技术实现:
  WITH RECURSIVE task_hierarchy AS (
      SELECT id, parent_id FROM tasks WHERE id = $1 AND deleted_at IS NULL
      UNION ALL
      SELECT t.id, t.parent_id FROM tasks t
      INNER JOIN task_hierarchy th ON t.parent_id = th.id
      WHERE t.deleted_at IS NULL
  )
  SELECT EXISTS(SELECT 1 FROM task_hierarchy WHERE id = $2)

  C. 层级验证增强

  遇到的特别情况和解决方案

  问题1: 路由匹配冲突
  - 现象: API调用返回"Invalid task ID"错误
  - 原因: projects.GET("/:id/tasks/:taskId", 
  app.getTaskHandler)路由将search-parents误识别为taskId
  - 解决:
  重启Docker容器加载最新代码，Gin框架按注册顺序匹配，具体路由优先于通配符路由

  问题2: 语法错误
  - 现象: Go编译失败，转义字符错误
  - 原因: Echo命令中的转义字符\!=被错误处理
  - 解决: 手动修复转义字符为正确的!=操作符

  问题3: 指针赋值错误
  - 现象: cannot use &intVal (value of type *int) as int value
  - 原因: Task模型中TaskLevel和SortOrder是int类型，不是指针
  - 解决: 直接赋值task.TaskLevel = int(taskLevel.Int64)
